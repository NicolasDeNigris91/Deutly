# 06-B-5 — Promotionsantrag

## 1. Sprachliches Problem

Promotionsantrag = formell-finanzielle Bewerbung um Promotion-Stelle oder -Stipendium. Trifft 3 Hauptformate:

1. **Promotion mit Doktorvater** (informell): Senior-Forscher willigt ein zu betreuen; Promotionskommission an Universität bewilligt.
2. **Promotion in Graduate School / Promotionsprogramm** (formell): Bewerbung mit Exposé + Lebenslauf + Empfehlungsschreiben.
3. **Stipendium-Bewerbung** (DFG / FWF / SNF / DAAD / Studienstiftung / Konrad-Adenauer-Stiftung etc.): Bewerbung um Promotionsstipendium (typisch 1500-1800 EUR/Monat über 3-4 Jahre).

Stage-6-B-5 fokussiert auf Format 2 + 3 (formell-finanziell).

Hindernisse:

- **Antrag ohne klare Forschungsfrage** (= Ablehnung garantiert).
- **Antrag ohne konkretes Gutachter-Profil** (= Stipendien-Geber ohne Kontext).
- **Stipendium falsch gewählt** (DFG ist nicht für jede Disziplin; DAAD ist auslandsfokussiert).
- **Zeitplan unrealistisch** (3-Jahres-Plan im Stipendium muß durchdacht sein).

## 2. Harte Theorie

### 2.1 Stipendien-Inventar DE-Akademie

**DFG (Deutsche Forschungsgemeinschaft)**:
- Größter deutscher Forschungsförderer.
- Promotionsförderung via Graduiertenkolleg (Kollektivantrag) oder Einzelantrag (selten für Promotion).
- Anschluss-Förderung wichtiger als Promotionsförderung.

**FWF (Fonds zur Förderung der wissenschaftlichen Forschung, Österreich)**:
- Österreichischer FWF; analog DFG.
- Wenn Promotion in Wien / Graz / Innsbruck.

**SNF (Schweizerischer Nationalfonds)**:
- Schweiz; analog DFG / FWF.
- Wenn Promotion in Zürich / Basel / Bern / Genf.

**DAAD (Deutscher Akademischer Austauschdienst)**:
- Internationale Mobilität; auch Promotionsstipendien für Ausländer in DE.
- 1500 EUR/Monat über 3-4 Jahre; sehr kompetitiv.

**Studienstiftung des deutschen Volkes**:
- Promotionsstipendium für deutsche + EU-Studierende mit exzellentem Hintergrund.

**Konrad-Adenauer-Stiftung / Friedrich-Ebert-Stiftung / Heinrich-Böll-Stiftung etc.**:
- Politisch orientierte Stiftungen mit Promotionsstipendien für engagierte Studierende.

**Promotionskolleg-Stipendien** (von Universitäten direkt):
- Institutionell organisiert; Bewerbung an Graduate School der Universität.

### 2.2 Antrag-Struktur

Standard-Promotionsantrag:

1. **Anschreiben** (~1 S.): Grußformel + Anlass + Vorstellung.
2. **Lebenslauf akademisch** (~2-3 S.): Tabellarisch + Publikationen + Sprachen + Projekte.
3. **Forschungs-Exposé** (cf. 06-B-1; ~10-30 S.): Forschungsfrage + Stand + Methode + These + Aufbau + Zeitplan + Bibliographie.
4. **Empfehlungsschreiben** (2-3 Schreiben von Senior-Forschern an Universität / Stiftung).
5. **Doktorvater-Bestätigung** (formal: Brief des potenziellen Doktorvaters).
6. **Sprach-Zertifikate** (Goethe C2 / TestDaF wenn ausländischer Bewerber).
7. **Plus stipendien-spezifische Dokumente** (z.B. Stiftungs-spezifische Begründungen, Engagement-Nachweise bei politischen Stiftungen).

### 2.3 Forschungs-Roadmap (5-Jahres-Plan)

Promotion = 3-5 Jahre. Dazu weiterer Plan für:
- **Post-Doc** (Anschlussförderung; 2-3 Jahre).
- **Habilitation oder Karriere-Schritt** (4-7 Jahre nach Promotion).

Stage-6-B-5-Aufgabe: 5-Jahres-Plan formulieren, der über die Promotion hinaus geht. Welche Karriere-Schritte sind antizipiert? Welche Forschungs-Roadmap nach Promotion?

### 2.4 Erfolgs-Quoten + Realistik

- **DFG-Promotionsförderung**: ~10-30% Erfolgsquote (sehr kompetitiv).
- **DAAD-Promotionsstipendium für Ausländer**: ~5-15% Erfolgsquote.
- **Studienstiftung**: ~20-30% nach erstem Auswahlverfahren; ~10% Gesamterfolg.
- **Universitäts-Promotionsstipendien**: variiert stark; oft 30-60%.

**Strategie**: parallel an mehreren Stipendien bewerben + Plan B haben (z.B. Promotion mit Lehrauftrag oder Industrie-Begleitung).

## 4. Sprachliche Aufgabe

**Eigener Promotionsantrag — vollständig:**

(a) **Anschreiben** (~1 S.).
(b) **Akademischer Lebenslauf** (~2-3 S.).
(c) **Forschungs-Exposé** (~15-30 S.; aus 06-B-1 weiter entwickelt).
(d) **Empfehlungsschreiben-Vorbereitung**: Schreiben Sie ein Skizze-Empfehlungsschreiben, das Sie Ihrem Mentor als Vorlage zur Anpassung schicken.
(e) **Doktorvater-Bestätigung-Anfrage**: höfliches Schreiben an einen potenziellen Doktorvater + Bestätigung erbeten.
(f) **5-Jahres-Plan** (~2-3 S.; Promotion + Post-Doc-Antizipation).
(g) **Stipendien-Wahl-Begründung** (~1 S.; warum diese Stiftung?).
(h) **Mini-Antrags-Bericht** (~2000W): Reflexion über die Antrags-Vorbereitung + identifizierte Schwächen + Strategie.
