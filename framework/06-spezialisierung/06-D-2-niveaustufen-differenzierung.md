# 06-D-2 — Niveaustufen-Differenzierung

## 1. Sprachliches Problem

CEFR (Common European Framework of Reference for Languages; dt. GER) unterscheidet 6 Sprachniveaus A1-C2. Jedes Niveau hat distinkte:
- **Lese-, Hör-, Sprech-, Schreibe-Kompetenzen** (4 Skills).
- **Grammatik-Erwartungen**.
- **Lexikon-Volumen**.
- **Pragmatische Kompetenzen**.

DaF-Lehrer muss die Niveaustufen präzise differenzieren + Lehre an die Stufe anpassen.

---

## 2. Harte Theorie

### 2.1 CEFR-Niveau-Übersicht

**A1 — Anfänger**:
- Lerner kann sich + andere vorstellen.
- Einfache Sätze über vertraute Themen.
- Lexikon: ~500-800 Wörter.
- Grammatik: Präsens + Perfekt + einige Modalverben + Akkusativ.

**A2 — Grundlegende Verständigung**:
- Vertraute alltägliche Konversation.
- Lexikon: ~1500-2000 Wörter.
- Grammatik: + Präteritum + Dativ + Subordination einfach.

**B1 — Selbständige Verständigung**:
- Standard-Konversation; Reise-Situation; eigene Erfahrungen erzählen.
- Lexikon: ~3000 Wörter.
- Grammatik: + Konjunktiv II Höflichkeit + komplexere Subordination + Genitiv.

**B2 — Komplexe Verständigung**:
- Akademische + berufliche Themen; Argumentation.
- Lexikon: ~5000 Wörter.
- Grammatik: + Konjunktiv I + Passiv + FVG einfach + Topikalisierung.

**C1 — Effektiver Gebrauch**:
- Komplexe + abstrakte Themen; literarische Texte; subtile Pragmatik.
- Lexikon: ~7000-10000 Wörter.
- Grammatik: vollständig; Stilfiguren; Modalpartikeln; Wissenschaftsdeutsch einfach.

**C2 — Native-like Beherrschung**:
- Quasi-native Kompetenz; alle Register; literarische Stilanalyse.
- Lexikon: ~10000-15000+ Wörter.
- Grammatik: vollständig + plurizentrisch + sub-sprachlich.

### 2.2 Can-Do-Statements

Standardisierte Operationalisierung pro Niveau:

A1: "Ich kann mich, andere und Personen meiner Umgebung vorstellen."

B1: "Ich kann die meisten Situationen bewältigen, denen man auf Reisen im Sprachgebiet begegnet."

C1: "Ich kann ein breites Spektrum anspruchsvoller, längerer Texte verstehen und auch implizite Bedeutungen erfassen."

Vollständig: cf. *Gemeinsamer europäischer Referenzrahmen für Sprachen* (Goethe-Institut + Europarat).

### 2.3 Grammatik-Progression nach Niveau

| Stufe | Grammatik-Schwerpunkt |
|---|---|
| A1 | Präsens + Akkusativ + Modalverben Grundbedeutung + einfache Verbalklammer |
| A2 | + Perfekt + Präteritum (sein/haben/Modalverben) + Dativ + Subordination einfach |
| B1 | + Konjunktiv II (würde + Inf.) + Genitiv + Präteritum vollständig + indirekte Frage (ob) |
| B2 | + Konjunktiv I + Passiv + komplexe Subordination + FVG erste + Topikalisierung |
| C1 | + Modalpartikeln + Stilfiguren + komplexer Konjunktiv + Plurizentrik |
| C2 | + alle Register + literarische Stilanalyse + sub-sprachliche Variation |

### 2.4 Lehrtechniken pro Niveau

**A1-A2**: stark frontaler Unterricht + viel Wiederholung + Drill-Übungen + visuelle Unterstützung; Fehlerkorrektur unmittelbar.

**B1-B2**: kommunikative Übungen + Authentik-Texte + Diskussionen + Aufsatz-Schreiben; Korrektur strukturiert.

**C1-C2**: autonomes Lernen unterstützt + Mentoring + komplexe Texte + Forschungs-Praxis + eigene Stimme.

## 3. Texto-âncora

**CEFR-Standardtext** systematisch lesen:
- *Gemeinsamer europäischer Referenzrahmen für Sprachen* (Goethe-Institut deutsche Fassung).

**Plus DaF-Lehrwerke pro Niveau**:
- A1-A2: *Schritte plus* (Hueber); *Studio d* (Cornelsen); *Aspekte* (Klett).
- B1-B2: *Mittelpunkt* (Klett); *Tangram aktuell* (Hueber).
- C1-C2: *Mittelpunkt C1* + *Aspekte C1* + *Erkundungen* (Schubert).

---

## 4. Sprachliche Aufgabe

(a) **Niveau-Diagnose-Berichte** (~3000W) für 3 hypothetische Lerner — analysieren Sie ihre Output-Probe + diagnostizieren Sie ihr Niveau (A1-C2) + begründen Sie.

(b) **Lehreinheits-Konzept** (~2500W) für eine 90-Min-Stunde auf einem ausgewählten Niveau (z.B. B1 Konjunktiv II Einführung) mit Lehrtechniken + Übungen + Korrektur-Strategie.

(c) **Can-Do-Statement-Drill** (~1000W): formulieren Sie 10 Can-Do-Statements für jedes Niveau A1-C2.
