# 06-C2-2 — Diagnostik-Berichte + Arztbriefe

## 1. Sprachliches Problem

Diagnostik-Berichte + Arztbriefe sind das **operative Kernformat** des klinischen Alltags. Sie übertragen Patienten-Daten zwischen Ärzten + Institutionen. Standardisiert + präzise.

Hauptformate:
- **Anamnese** (Krankengeschichte; Patienten-Erhebung).
- **Befund** (Untersuchungs-Ergebnisse).
- **Diagnose** (klinische + Differential-Diagnose).
- **Therapieplan** (Behandlungs-Strategie).
- **Arztbrief** (Zusammenfassung an überweisenden Arzt).

---

## 2. Harte Theorie

### 2.1 Anamnese-Struktur

Standard-Sektionen:
- **Aktuelle Beschwerden** (Patient-Beschreibung).
- **Eigenanamnese** (Vorerkrankungen, Operationen, Allergien, Medikamente).
- **Familienanamnese** (relevante Erkrankungen in Familie).
- **Sozialanamnese** (Beruf, Lebensumstände, Genussmittel).
- **Vegetative Anamnese** (Schlaf, Stuhl, Wasserlassen, Appetit).

### 2.2 Befund-Struktur

- **Allgemeinzustand** (Größe, Gewicht, BMI, AZ).
- **Vitalparameter** (Blutdruck RR / Puls / Atemfrequenz / Temperatur).
- **Körperliche Untersuchung systematisch** (Kopf, Hals, Thorax, Abdomen, Extremitäten, Neurologisch).
- **Laborwerte** (Blutbild, klinische Chemie).
- **Bildgebung** (Röntgen, CT, MRT, Sonographie).

### 2.3 Diagnose-Stilistik

Klinische Diagnose:
- ICD-10-/-11-Code (international).
- Klartext-Diagnose (DE Fachterminologie).
- Differential-Diagnose (Alternativen erwogen).

Beispiele:
- *I10.9 Essentielle Hypertonie, primär.*
- *J45.9 Asthma bronchiale, nicht näher bezeichnet.*
- *E11.9 Diabetes mellitus Typ 2 ohne Komplikation.*

### 2.4 Arztbrief-Format

Standard-Arztbrief (von Klinik an Hausarzt):
1. Patient-Daten + Aufenthalts-Daten.
2. Aufnahme-/Entlass-Diagnose.
3. Anamnese (kompakt).
4. Befund-Zusammenfassung.
5. Therapie-Verlauf.
6. Entlass-Empfehlung (Medikation, Kontrollen, Nachsorge).

Stilistik: kompakt + präzise + Fachterminologie + Akronyme + Konj. I in Patient-Anamnese.

### 2.5 Akronyme Klinisch DE

- **AZ** = Allgemeinzustand.
- **EZ** = Ernährungszustand.
- **RR** = Riva-Rocci (Blutdruck).
- **HF** = Herzfrequenz.
- **AF** = Atemfrequenz.
- **OA** = Oberarzt.
- **EKG** = Elektrokardiogramm.
- **CT** / **MRT** / **PET-CT**.
- **Z.n.** = Zustand nach.
- **D.D.** = Differentialdiagnose.

---

## 3. Texto-âncora

**5-10 anonymisierte Arztbriefe + Anamnesen + Befunde** (via klinische Lehrbücher oder Online-Ressourcen wie amboss.de) systematisch lesen + analysieren.

---

## 4. Sprachliche Aufgabe

(a) **Anamnese-Bericht** (~2000W) für hypothetischen Patient (vollständige Anamnese-Struktur).

(b) **Befund-Bericht** (~1500W) für denselben hypothetischen Patient.

(c) **Eigener Arztbrief** (~2000W) — Standard-Format an hypothetischen Hausarzt.

(d) **Diagnose-Drill** (~1000W): identifizieren Sie 10 ICD-10-/-11-Codes mit DE-Klartext + 1 Differentialdiagnose pro Code.
