# 06-C3-1 — DIN-Normen-Sprache

## 1. Sprachliches Problem

DIN-Normen (Deutsches Institut für Normung; DIN = "Deutsche Industrie-Norm") sind technische Regelwerke mit eigener Sprachvarietät — präzise, normativ, performativ. Sie regeln Industrieprodukte, Verfahren, Klassifikationen, Sicherheits-Anforderungen.

Track-C3-Lerner muss DIN-Normen lesen + verstehen + bei Bedarf verfassen können. Anwendungsfeld: Ingenieure, technische Übersetzer, Industrie-Manager, Forscher mit Industrie-Bezug.

---

## 2. Harte Theorie

### 2.1 DIN-Normen-Inventar

DIN-Normen-Klassifikation:
- **DIN A** — Anwendungs-Norm (z.B. DIN A4 Papierformat).
- **DIN EN** — Europäische Norm umgesetzt in DE (CEN-Standards).
- **DIN ISO** — Internationale Norm (ISO) umgesetzt in DE.
- **DIN VDE** — Elektrotechnik (Verband der Elektrotechnik).
- **DIN VDI** — Verein Deutscher Ingenieure.

Wichtige Beispiele:
- DIN 1505 — Bibliographische Zitate (für wissenschaftliche Arbeiten).
- DIN A4 — Standard-Papierformat (A4 = 210 × 297 mm).
- DIN EN ISO 9001 — Qualitätsmanagement-Systeme.
- DIN EN 45011 — Konformitätsbewertung.

### 2.2 Normen-Sprache-Konventionen

DIN-Normen-Sprache ist:
- **Normativ-performativ**: *muss / soll / darf / kann* präzise unterschieden:
  - *muss* = Pflicht (verbindlich).
  - *soll* = Empfehlung (stark).
  - *darf* = Erlaubnis.
  - *kann* = Möglichkeit.
- **Definitions-saturiert**: jeder zentrale Begriff der Norm wird in einer Begriffs-Sektion definiert.
- **Strukturiert**: Sektionen + Unter-Sektionen + Verweistechnik systematisch.
- **Verben-Präzision**: *prüfen, anwenden, feststellen, einstellen, kalibrieren, überprüfen, verifizieren, validieren* — distinkte Bedeutungen.

### 2.3 Standardstruktur einer DIN-Norm

1. **Vorwort** — Anlass + Verhältnis zu Vorgänger-Normen.
2. **Geltungsbereich** — was wird geregelt?
3. **Verweise auf andere Normen**.
4. **Begriffe** — alphabetisch geordnete Definitionen.
5. **Anforderungen** — normativer Hauptteil.
6. **Prüfverfahren** — wie wird Konformität geprüft?
7. **Kennzeichnung** — wie sind Produkte zu markieren?
8. **Literaturhinweise**.
9. **Anhänge** (informativ + normativ).

### 2.4 Funktionsverbgefüge in Normen-Sprache

Hyper-Saturation an FVG:
- *zur Anwendung kommen* (= angewendet werden).
- *in Übereinstimmung sein* (= übereinstimmen).
- *Bezug nehmen auf* (= sich beziehen auf).
- *Angabe machen über* (= angeben).
- *Prüfung durchführen* (= prüfen).
- *Konformität herstellen* (= konform sein).

cf. ANHANG G FVG.

### 2.5 Verweistechnik

DIN-Normen verweisen ständig auf andere DIN-/ISO-/EN-Normen. Beispiel: *"Die Prüfung ist nach DIN EN ISO 9001 Abschnitt 7.5 durchzuführen."*

Lerner muss diese Verweise navigieren können (Zugang via Beuth-Verlag oder DIN-Datenbank).

## 3. Texto-âncora

**3-5 ausgewählte DIN-Normen** systematisch lesen + analysieren:
- DIN 1505 (Bibliographische Zitate; einfacher Einstieg).
- DIN A4 + verwandte Papierformat-Normen.
- DIN EN ISO 9001 (Qualitätsmanagement).
- DIN VDE 0100 Teil 410 (Schutz gegen elektrischen Schlag).

Zugang: Beuth-Verlag (beuth.de; oft kostenpflichtig); manche Bibliotheken bieten Zugang.

---

## 4. Sprachliche Aufgabe

(a) **Norm-Analyse-Bericht** (~3000W) zu 1 DIN-Norm: Architektur + Begriffs-Sektion + Anforderungen + Prüfverfahren + Verweistechnik.

(b) **Eigene Norm-Skizze** (~2000W): konstruieren Sie eine hypothetische DIN-Norm-Struktur (z.B. für ein erfundenes Produkt; alle 9 Standard-Sektionen).

(c) **Modal-Verb-Drill** (~1000W): 20 Sätze mit *muss / soll / darf / kann* in normativem Kontext (mit präziser Differenzierung).
