# 06-A-5 — Kulturwissenschaftliche Übersetzung

## 1. Sprachliches Problem

Kulturwissenschaftliche Übersetzung erfordert die Beherrschung von **diskurs-spezifischer Terminologie**:

- *Bildungsbürger* (DE) — kulturhistorischer Begriff mit komplexer Rezeptionsgeschichte; PT-Übersetzung als *burguês culto* verflacht.
- *Lebenswelt* (Habermas-Husserl) — Begriff mit phänomenologischer Resonanz; PT *mundo da vida* trifft, aber Resonanz weniger stark.
- *Habitus* (Bourdieu) — DE/FR-Begriff in Soziologie + Anthropologie; PT *habitus* als Lehnwort üblich.
- *Distinktion* (Bourdieu) — Distinktions-Praktik, die soziale Klassen reproduziert; PT *distinção*.
- *Kulturindustrie* (Adorno) — kritisch-dialektischer Begriff; PT *indústria cultural*.

Stage-6-A-5 fokussiert auf Adorno, Bourdieu (in DE-Übersetzung), Habermas — kulturwissenschaftliche + sozialphilosophische Texte.

Hindernisse:

- **Begriffs-Verflachung** durch unkritische Übersetzung.
- **Mangel an Tradition-Kontextualisierung** (jeder Begriff hat eine Geschichte).
- **Stilbruch zwischen wissenschaftlicher Distanz + kulturkritischer Wendung**.

---

## 2. Harte Theorie

### 2.1 Diskurs-spezifische Terminologie

Zentrale Begriffe der DE-Kultur- + Sozialwissenschaft mit Übersetzungs-Diskussion:

| DE-Begriff | PT-Übersetzung | Diskussion |
|---|---|---|
| *Bildungsbürger* | *burguês culto* / *burguesia educada* | DE-Begriff trägt humboldt-tradition + Adorno-Kritik mit; PT verflacht |
| *Halbbildung* (Adorno) | *semiformação* (Houaiss) | Houaiss-Lösung anerkannt; bewahrt Adornos kritische Pointe |
| *Lebenswelt* (Husserl/Habermas) | *mundo da vida* | Funktional gleich; phänomenologische Resonanz im PT schwächer |
| *Verdinglichung* (Lukács/Adorno) | *coisificação* / *reificação* | Beide existieren; *reificação* (Stenzel) klassisch in PT-Marxismus-Übersetzung |
| *Kulturindustrie* (Adorno) | *indústria cultural* | Standard-PT-Übersetzung; trifft funktional |
| *Anerkennung* (Honneth) | *reconhecimento* | Trifft funktional; Honneth-Tradition in PT-Sozialphilosophie etabliert |
| *Geltungsanspruch* (Habermas) | *pretensão de validade* | Standard; trifft funktional |
| *Habitus* (Bourdieu) | *habitus* (Lehnwort) | Lehnwort-Standard; nicht übersetzen |
| *Distinktion* (Bourdieu) | *distinção* | Trifft funktional; Bourdieu-Tradition in PT-Soziologie etabliert |

### 2.2 Adorno-Übersetzung — kritische Vorsicht

Adornos Stilfiguren (Hyperbaton, Konstellation, Aphoristik, Litotes) sind ins PT besonders schwer zu bewahren. PT-Syntax ist weniger flexibel für Hyperbaton; PT-Prosa-Konvention bevorzugt linearere Argumentation.

Existierende Adorno-PT-Übersetzungen:
- *Dialektik der Aufklärung* — Übersetzung Guido Antonio de Almeida (Rio: Zahar 1985); kritisch rezipiert wegen mancher Verflachungen.
- *Minima Moralia* — Übersetzung Gabriel Cohn (Rio: Beca 1992) + neuere.
- *Negative Dialektik* — Übersetzung Marco Antonio Casanova (Rio: Tempo Brasileiro 2009) — spätere + akademisch anerkannte.

Stage-6-A-5-Aufgabe: Adorno-Auszug eigenständig übersetzen + mit existierenden Übersetzungen vergleichen.

### 2.3 Sub-Tradition-Bewusstsein in Übersetzung

Jeder Begriff trägt eine Sub-Tradition mit (cf. BEGRIFFS-GLOSSAR + 03-09 Lexik III). Übersetzung soll diese Tradition signalisieren — entweder via Begriffs-Wahl oder via Erläuterung.

Beispiel: *Vernunft* trägt Aufklärungs-Tradition (Kant), Hegel-Tradition (Vernunft als Selbstvermittlung), Adorno-Tradition (kritisch-instrumentell). Übersetzung als *razão* trifft alle drei — aber im Kontext muß deutlich werden, welche Sub-Tradition aktiviert ist.
