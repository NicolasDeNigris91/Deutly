# 06-D-6 — Mentoring institutionell

## 1. Sprachliches Problem

DaF-Lehre + Mentoring geschieht in unterschiedlichen institutionellen Kontexten:

- **Universitätslehre** (Sprachzentrum; Master-Programme).
- **Sprachschul-Lehre** (Goethe-Institut; Volkshochschule; Privat).
- **Online-Mentoring** (italki, Preply, Lingoda).
- **1-zu-1-Mentoring** (privat oder als Coaching).
- **Tandem-Programme** (Universitäre + privat).

Jeder Kontext hat eigene Regelungen, Erwartungen, Honorierungen. Track-D-Lerner muss sie kennen + situationen-passend agieren.

---

## 2. Harte Theorie

### 2.1 Universitätslehre

**Sprachzentrum-Position**:
- Stelle: Lektor / wissenschaftlicher Mitarbeiter / Honorar-Lehrkraft.
- Aufgaben: Sprachkurs-Lehre + Beratung + Test-Korrektur + ggf. Forschung.
- Vergütung: TVL/TVÖD-Tarif für feste Stellen; Honorar pro UE für Lehrbeauftragte (~30-50 EUR/UE).

**Master-DaF-Programm-Mitarbeit**:
- Lehraufträge (Bachelor + Master).
- Promotion-Mitbetreuung.
- Forschungs-Beteiligung.

### 2.2 Sprachschul-Lehre

**Goethe-Institut**:
- Höchste Reputation; akkreditierte Lehrer; Honorar überdurchschnittlich.
- Lehrer mit Goethe-DLL-Zertifizierung + meist Master-Niveau.
- Standard-Material (Goethe-Schritte plus, etc.).

**Volkshochschule (VHS)**:
- Kommunale Bildungs-Einrichtung; oft Migration-Integration-Kurse.
- Honorar moderat; pädagogische Freiheit hoch.
- Material-Wahl meist Lehrer-überlassen.

**Privat-Sprachschulen** (Berlitz, Inlingua, Eurocentres):
- Strukturierter; oft eigene Methode (Berlitz-Methode).
- Lehrer-Vergütung niedriger; Volumen höher.

### 2.3 Online-Mentoring

**Italki, Preply, Lingoda, Verbling**:
- Plattform-Provision (~15-30%) abgezogen.
- Lerner-Beziehung individuell; Materialien-Wahl frei.
- Honorar variiert (~15-40 EUR/Stunde je nach Plattform + Lehrer-Reputation).
- Vorteile: Flexibilität; geographische Unabhängigkeit; passive Einkommens-Skalierung möglich.
- Nachteile: keine Festanstellung; abhängig von Plattform-Algorithmen.

### 2.4 1-zu-1-Mentoring (privat / Coaching)

**Privat-Mentoring**:
- Honorar individuell verhandelt (~30-80 EUR/Stunde).
- Stark personalisiert; Lerner-Bedarf-zentriert.
- Höchste pädagogische Effektivität (1-zu-1 ist Goldstandard).

**Akademisches Coaching** (für Promovenden + Postdocs):
- Wissenschaftsdeutsch-Coaching.
- Aufsatz-/Vortrag-Vorbereitung.
- Honorar premium (~80-150 EUR/Stunde).

### 2.5 Tandem-Programme

**Universitäre Tandem**:
- Universitäten organisieren Tandem-Partner für Studierende.
- Kostenlos für Lerner; Lehrer als Vermittler (oft mit kleinem Honorar oder ehrenamtlich).
- Pädagogisch reich (Authentik + soziale Integration).

**Tandem-Apps** (Tandem, HelloTalk, etc.):
- Selbst-organisierte Tandem-Beziehungen.
- Lehrer kann Tandem-Coaching anbieten.

### 2.6 Mentor-Rollenverständnis pro Kontext

(cf. MENTOR.md)

- **Universität**: Lehre + Beratung + Forschungs-Bezug.
- **Sprachschule**: standardisierter Unterricht; Loop der Verfeinerung weniger intensiv.
- **Privat-Mentoring**: Loop der Verfeinerung voll anwendbar; Stage-1-bis-5-Lerner-Begleitung möglich.
- **Online**: standardisierter; oft kürzere Lerner-Beziehungen.
