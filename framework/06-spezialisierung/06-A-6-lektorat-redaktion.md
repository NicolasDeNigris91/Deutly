# 06-A-6 — Lektorat + Redaktion

## 1. Sprachliches Problem

Professionelle Übersetzung endet nicht mit der ersten Übersetzungs-Version. Sie umfasst:

1. **Eigenes Lektorat** (Selbst-Korrektur nach Pause + frischem Blick).
2. **Peer-Review** (Senior-Übersetzer + Sprach-Native).
3. **Verlagslektor-Korrektur** (vor Druck).
4. **Druck-Korrektur** (nach Satz; Tippfehler-Phase).

Stage-6-A-6 fokussiert auf die professionelle **Lektorats-Praxis** — ein zentraler Kompetenz-Bereich, der in Stage 5 nur am Rande gestreift wurde.

Hindernisse:

- **Selbstüberschätzung** der ersten Übersetzungs-Version.
- **Mangel an systematischer Lektorats-Methode** (zufälliges Korrigieren).
- **Konflikt mit Verlagslektor** ohne professionelle Argumentations-Strategie.

---

## 2. Harte Theorie

### 2.1 Lektorats-Phasen

**Phase 1 — Eigenes Lektorat (24-48h nach Übersetzung):**
- Quelltext + Übersetzung Satz-für-Satz vergleichen.
- Loop der Verfeinerung anwenden (cf. MENTOR §1) — auf eigene Übersetzung wie auf fremdes Material.
- Kategorisieren: BLOCKING / MAJOR / NIT.
- Korrigieren in der Reihenfolge: BLOCKING zuerst.

**Phase 2 — Peer-Review:**
- Senior-Übersetzer (mit Erfahrung) prüft Übersetzung kritisch.
- Sprach-Native (DE oder PT) prüft Idiomatik + Stil.
- Eigene Begründung jeder strittigen Entscheidung dokumentieren.

**Phase 3 — Verlagslektor-Korrektur:**
- Verlagslektor schlägt Änderungen vor (oft viele).
- Übersetzer prüft jede Änderung kritisch — übernimmt nur, was übersetzungs-theoretisch begründet ist.
- Strittige Punkte werden im Dialog mit Lektor verhandelt.

**Phase 4 — Druck-Korrektur:**
- Nach Satz (gesetzt im Verlag) erneut Korrektur.
- Tippfehler + Satz-Fehler markieren.
- Letzte Stilkorrektur möglich, aber begrenzt (Verlagsdruck-Termin).

### 2.2 Argumentations-Strategie mit Verlagslektor

Konflikt-Situationen typisch:

- Lektor schlägt Einbürgerung vor, Übersetzer hält an Verfremdung fest.
- Lektor moniert "schwer verständliche" Wendung, Übersetzer hat sie bewusst gewählt (Stilfigur des Originals).
- Lektor ändert Begriffs-Wahl ohne Rücksprache; Übersetzer reklamiert.

**Strategie:**
1. Eigene Übersetzungs-Position theoretisch verankert (cf. 06-A-1) als Argumentations-Basis.
2. Konkrete Belege (Quelltext + Sub-Tradition + bestehende Übersetzungen) für jede Entscheidung.
3. Höflich-fest-formuliert; nicht polemisch; dem Verlagslektor seine eigene Expertise nicht absprechen.
4. Wenn unauflösbar: Übersetzer-Vermerk im Lektorats-Brief; ggf. Verlag wechseln (radikal).

### 2.3 Übersetzer-Lektor-Kommunikation

**Standard-Format:**
- Begründungs-Brief (1-2 Seiten) mit Liste übernommener + abgelehnter Änderungen.
- Pro abgelehnter Änderung: Begründung mit Bezug auf Übersetzungs-Position + Quelltext.
- Höflichkeitskonventionen DE-Verlagsverkehr.

## 4. Sprachliche Aufgabe

**Lektorats-Werkstatt:**

(a) Wählen Sie eine eigene Übersetzung aus 06-A-2, 06-A-3, 06-A-4, oder 06-A-5 (~5-10 Seiten).
(b) Wenden Sie alle 3 Lektorats-Phasen systematisch an:
   - Phase 1: Eigenes Lektorat (~5h Arbeit; Issues kategorisiert + korrigiert).
   - Phase 2: Peer-Review (Senior-Übersetzer + 1 Sprach-Native; ~2h Diskussion).
   - Phase 3: Simulierte Verlagslektor-Korrektur — bitten Sie einen Peer, in der Rolle des Lektors Änderungen vorzuschlagen; verfassen Sie Antwort-Brief (~1500W).
(c) Dokumentieren Sie den gesamten Prozess in einem Lektorats-Bericht (~3000W):
   - §1 Phase-1-Issues + Korrekturen.
   - §2 Phase-2-Feedback + Reaktion.
   - §3 Phase-3-Lektor-Konflikte + Argumentations-Strategie.
   - §4 Reflexive Schluss-Sektion: was haben Sie gelernt?
