# 06-B-1 — Forschungsfrage-Entwicklung

## 1. Sprachliches Problem

Track B (Germanistische Forschung) bereitet auf Promotion vor. Erste + grundlegendste Aufgabe: **eine Promotion-würdige Forschungsfrage formulieren**.

Was unterscheidet eine Promotion-Frage von einer Stage-3-Aufsatz-Frage oder einer Stage-4-Begriffsanalyse?
- **Originalität**: leistet einen erkennbaren Beitrag zur Forschung (= nicht bereits 5× untersucht).
- **Fokussierung**: ist konkret + bearbeitbar in 3-5 Jahren.
- **Methodische Konsistenz**: hat eine identifizierbare Methode (hermeneutisch / korpusbasiert / komparativ / etc.).
- **Anschlussfähigkeit**: schließt an mindestens 2-3 Forschungs-Linien an.

Stage-6-B-1 fokussiert auf die Praxis der Forschungsfrage-Entwicklung — nicht abstrakt, sondern als konkretes Promotion-Exposé.

Hindernisse:

- **Zu groß** ("Aufklärung in der Moderne") — nicht in Promotion bearbeitbar.
- **Zu klein** ("Modalpartikel *doch* in einem Bernhard-Roman") — Promotion ist mehr als Detailstudie.
- **Bereits beackert** ("Habermas-Adorno-Kontroverse") — keine Originalität.
- **Methodisch unsauber** (mischt Hermeneutik + Korpus + Diskursanalyse ohne klare Verortung).

---

## 2. Harte Theorie

### 2.1 Promotion-Exposé — Standard-Struktur

In DE-Germanistik / Philosophie / Komparatistik: Promotion-Exposé typisch ~15-30 Seiten, mit Sektionen:

1. **Problemstellung + Forschungsfrage** (~3 S.).
2. **Forschungsstand kompakt** (~5 S.).
3. **Methodische Verortung** (~3 S.).
4. **Konkrete These / Hypothese** (~2 S.).
5. **Aufbau in Kapiteln** (~3 S.).
6. **Zeitplan** (~1 S.).
7. **Vorläufige Bibliographie** (~3 S.).

Plus: persönlicher Hintergrund + Vorpublikationen + Sprach- + Forschungs-Kompetenzen.

### 2.2 Forschungsfrage-Kriterien

**(a) Originalität:**
- Existieren < 10 wissenschaftliche Publikationen zu dieser Frage?
- Erweitert die Frage existierende Forschung (= geht über sie hinaus)?
- Verknüpft sie Forschungs-Linien, die noch nicht systematisch verbunden wurden?

**(b) Bearbeitbarkeit:**
- Ist die Frage in 3-5 Jahren mit den verfügbaren Quellen bearbeitbar?
- Sind die Quellen zugänglich (Archive, Korpora, etc.)?
- Sind die nötigen Sprach-Kompetenzen vorhanden (= über DE hinaus, falls nötig)?

**(c) Methodische Konsistenz:**
- Welche Methode (oder Methoden-Kombination)?
- Wie wird die Methode beschrieben + begründet?
- Welche Beschränkungen hat die Methode (Methodenkritik antizipiert)?

**(d) Anschlussfähigkeit:**
- An welche existierenden Forschungs-Linien schließt die Frage an?
- Welche Forscher / Schulen / Traditionen sind die Hauptbezugspunkte?

### 2.3 Promotion-Exposés exemplarisch

5-10 publizierte Promotion-Exposés ausgewählter Germanisten / Philosophen / Komparatisten lesen + analysieren:

- Honneth (1991 *Kritik der Macht* — habilitatorisch, aber strukturell ähnlich).
- Forst (Promotion + Habilitation — Suhrkamp publiziert).
- Junghegelianische Studien (vergleichende Lektüre).

## 4. Sprachliche Aufgabe

**Eigenes Promotion-Exposé verfassen** (~15-30 Seiten).

**Anforderungen:**

- Forschungsfrage präzise formuliert + auf den 4 Kriterien (Originalität, Bearbeitbarkeit, Methodik, Anschlussfähigkeit) verteidigt.
- Forschungsstand kritisch + kompakt (3 Hauptlinien).
- Methodische Verortung explizit.
- These + Aufbau klar.
- Bibliographie: 50+ Werke (Primär + Sekundär).
- Stil: Wissenschaftsdeutsch hoch (akademisch + präzise; cf. 03-07 + 05-02).

## 6. Konzeptuelles Tor (Beispielfragen)

1. Was unterscheidet eine Promotion-Forschungsfrage von einer Stage-4-Begriffsanalyse?
2. Erläutern Sie die 4 Kriterien einer Promotion-würdigen Forschungsfrage.
3. Welche Methode wenden Sie auf Ihre Frage an? Begründen Sie.
4. Welche 3 Forschungs-Linien sind Ihre Hauptbezugspunkte? Wie schließen Sie an sie an?
5. Was sind die Grenzen Ihrer Forschungsfrage (Methodenkritik antizipiert)?
