# 06-C1-2 — Urteils-Deutsch

## 1. Sprachliches Problem

Urteilstexte (Bundesgerichtshof + Bundesverfassungsgericht) operieren in eigenem Stil-Subregister. Sie verbinden:
- **Tatbestand-Bericht** (Sachverhalts-Wiedergabe; Konj. I durchgängig).
- **Entscheidungs-Begründung** (Rechtsprüfung mit Auslegungs-Methodik).
- **Tenor** (formal-knappe Entscheidungs-Formel).
- **Leitsatz** (höchstrichterliche Aussage als Präzedenz-Marker).

Lese- + Verstehens-Kompetenz von Urteilen ist zentrale Track-C1-Kompetenz.

---

## 2. Harte Theorie

### 2.1 Urteil-Architektur

Standard-Urteilstext (BGH, BVerfG):

1. **Rubrum** — Verfahrens-Beteiligte + Daten + Aktenzeichen.
2. **Tenor** — Entscheidung formal (z.B. "Die Revision wird zurückgewiesen.").
3. **Tatbestand** — Sachverhalt + bisherige Verfahrens-Stationen (Konj. I in Zeugen-Aussagen-Wiedergabe).
4. **Entscheidungs-Gründe** — Hauptteil; rechtliche Würdigung (= Subsumtion + Auslegung).
5. **Leitsatz** (bei höchstrichterlichen Entscheidungen) — verallgemeinerte Aussage.

### 2.2 Konj. I in Tatbestand-Berichten

Tatbestand operiert mit Konj. I systematisch:
- *Der Kläger trägt vor, der Beklagte habe ihm das Geld geliehen.* (NICHT: hat ihm geliehen.)
- *Die Zeugin sagt aus, sie habe den Vorfall beobachtet.*

Distanzierung markiert: Gericht zitiert; übernimmt nicht die Wahrheit.

### 2.3 Rechtsprüfungs-Sprache

- *Es ist zu prüfen, ob ...*
- *Die Voraussetzungen des § X liegen vor / liegen nicht vor.*
- *Es ist davon auszugehen, dass ...*
- *Die Würdigung ergibt, dass ...*
- *Mithin / folglich / demnach ...* (akademische Konnektoren typisch).

### 2.4 Tenor-Formeln

- *Die Klage wird abgewiesen.*
- *Die Berufung wird zurückgewiesen.*
- *Die Verfassungsbeschwerde wird verworfen.*
- *Auf die Revision des Klägers wird das Urteil aufgehoben + an das Berufungsgericht zurückverwiesen.*

## 3. Texto-âncora

**3 BGH-Urteile + 2 BVerfG-Urteile** systematisch lesen + analysieren. Frei zugänglich:
- bundesgerichtshof.de (BGH-Urteils-Datenbank).
- bundesverfassungsgericht.de.

Empfohlene Erstlektüren:
- BVerfGE 7, 198 — Lüth-Urteil (1958; Grundrechts-Drittwirkung).
- BVerfGE 39, 1 — Schwangerschafts-Urteil (1975).
- BGH-Urteil zum allgemeinen Persönlichkeitsrecht (z.B. Caroline-von-Monaco-Reihe).

## 4. Sprachliche Aufgabe

**Urteils-Analyse-Werkstatt:**

(a) **Urteils-Bericht** zu 1 BGH + 1 BVerfG-Urteil (~5000W gesamt): Architektur + Tatbestand-Wiedergabe + Entscheidungs-Begründung kritisch nachvollzogen + Leitsatz erläutert.

(b) **Eigene Urteils-Stilistik-Übung** (~2000W): verfassen Sie eine Tenor + Entscheidungs-Begründungs-Skizze für einen hypothetischen Fall (Stil-konform).

(c) **Konj.-I-Drill** (~1000W): bauen Sie 10 Tatbestands-Sätze um (von direkter Rede zu Konj.-I-Indirekt-Rede).
