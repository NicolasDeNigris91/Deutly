# 06-C2-1 — Anatomie + Physiologie auf Deutsch

## 1. Sprachliches Problem

Medizinisches Deutsch operiert über zwei verbundene Lexikon-Schichten:
- **Lateinisch-griechische Fachterminologie** (international standardisiert; Anatomia / Pathologia / Pharmacologia).
- **Deutsche Patienten-Sprache** (umgangssprachliche Äquivalente; *Knochenbruch* statt *Fraktur*; *Bauchschmerzen* statt *Abdominalbeschwerden*).

Track-C2-Lerner muss beide Schichten beherrschen + zwischen ihnen wechseln können (Arzt-Arzt-Diskurs vs. Arzt-Patient-Kommunikation).

Hindernisse:

- **Fachterminologie-Lücken** (jede Anatomie-Region eigene Termini).
- **Latein-Aussprache** in DE-Konvention (Stress-Pattern + Lautwerte).
- **Patient-Compliance-Sprache** (verständlich + nicht-verängstigend).

---

## 2. Harte Theorie

### 2.1 Anatomie-Lexikon Grundbegriffe

**Skelett-System:**
- DE Standard / Latein:
  - Schädel / Cranium.
  - Wirbelsäule / Columna vertebralis.
  - Brustbein / Sternum.
  - Rippen / Costae.
  - Schulterblatt / Scapula.
  - Oberarmknochen / Humerus.
  - Elle + Speiche / Ulna + Radius.
  - Oberschenkelknochen / Femur.
  - Schienbein / Tibia.

**Muskel-System:**
- Oberarmbeuger / Musculus biceps brachii.
- Großer Brustmuskel / Musculus pectoralis major.
- Bauchmuskeln / Musculi abdominis.

**Inneres:**
- Herz / Cor.
- Lunge / Pulmo.
- Leber / Hepar.
- Niere / Ren.
- Magen / Ventriculus.
- Darm / Intestinum (Dünndarm / Dickdarm).

### 2.2 Physiologie-Begriffe

- Herzschlag / Frequenz / Puls.
- Atmung / Respiration.
- Verdauung / Digestion.
- Stoffwechsel / Metabolismus.
- Hormonsystem / endokrines System.
- Nervensystem / zentrales + peripheres N.

### 2.3 Pathologie-Grundbegriffe

- Entzündung / Inflammatio (Endung *-itis*: Bronchitis, Hepatitis, Arthritis).
- Tumor / Neoplasma (gut-/bösartig: benigne / maligne).
- Bruch / Fraktur.
- Blutung / Hämorrhagie.
- Infektion / Infektionskrankheit.

### 2.4 Patienten-Sprache vs. Fachsprache

| Patienten-Sprache | Fachsprache |
|---|---|
| Bauchschmerzen | Abdominalbeschwerden |
| Knochenbruch | Fraktur |
| Magenkrankheit | Gastritis / Gastroenteritis |
| Herzinfarkt | Myokardinfarkt |
| Schlaganfall | Apoplex / zerebraler Insult |
| Krebs | Karzinom / Neoplasma |

Arzt-Patient-Kommunikation erfordert systematisches Wechseln: Diagnose in Fachsprache (intern + Schreiben); Erklärung an Patient in Standard-DE (mit Klärung der Fachbegriffe).

## 4. Sprachliche Aufgabe

(a) **Anatomie-Glossar PT-DE-Latein** (~200 Begriffe; ~3000W) zu einem Körper-System Ihrer Wahl (z.B. Herz-Kreislauf-System).

(b) **Patienten-Sprache-vs.-Fachsprache-Liste** (~50 Paare; ~2000W) mit kontextuellen Verwendungs-Hinweisen.

(c) **Eigenes Erklär-Schreiben** (~2000W) für hypothetischen Patienten zu einer einfachen Diagnose (z.B. Bluthochdruck, Diabetes Typ 2, Migräne) — Fachsprache + Patientensprache gemischt.
