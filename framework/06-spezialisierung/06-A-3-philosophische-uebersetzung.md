# 06-A-3 — Philosophische Übersetzung

## 1. Sprachliches Problem

Philosophische Übersetzung erfordert Beherrschung von:
- Begriffs-Architektur des Quellautors (cf. BEGRIFFS-GLOSSAR).
- Re-Etymologisierung (Heidegger: *Sein → seinhaft*; *Wahrheit → Un-verborgenheit*).
- Hyphenkomposita (Heidegger: *In-der-Welt-sein*, *Sich-vorweg-sein*).
- Tradition-Anschluss (philosophischer Begriff trägt Wirkungsgeschichte mit).

Stage-6-A-3 fokussiert auf **Heidegger nach PT** — paradigmatischer Fall philosophischer Übersetzung mit drei rivalisierenden PT-Übersetzungen (Beibehaltung *Dasein*; Sá Cavalcante *Pre-sença*; Verflachung *Existência*).

Hindernisse:

- **Übersetzung als rein lexikalische Operation** (= verfehlt Tradition).
- **Re-Etymologisierung mechanisch nachbilden** (= Pseudo-Heidegger im PT).
- **Anti-Heideggerianische Übersetzung** (Bedeutung verflachen aus Skepsis).

---

## 2. Harte Theorie

### 2.1 Heideggers Begriffs-Strategie

Heidegger arbeitet systematisch mit:

**(a) Re-Etymologisierung**: Verben + Substantive werden auf ihre etymologischen Wurzeln zurückgeführt + reaktiviert.
- *Wahrheit* < ahd. *wārheit* < idg. *wēr-* "treu, vertrauenswürdig" → Heidegger reaktiviert via griech. *aletheia* "Un-verborgenheit".
- *Existenz* < lat. *ex-sistere* "heraus-stehen" → Heidegger schreibt *Ek-sistenz* (Bindestrich macht Etymon sichtbar).

**(b) Hyphenkomposita**: zusammengesetzte Begriffe werden via Bindestriche analytisch gemacht.
- *In-der-Welt-sein* (eines der grundlegenden Existenziale).
- *Sich-vorweg-sein* (Struktur der Sorge).
- *Vor-handenheit / Zu-handenheit* (Begegnungsmodi der Dinge).

**(c) Inversionen + Hyperbaton**: syntaktische Markierungen, die den Leser zwingen innezuhalten.

### 2.2 Drei PT-Übersetzungs-Wege für *Dasein*

| Weg | Übersetzung | Theoretische Verortung | Vorteile | Nachteile |
|---|---|---|---|---|
| **1. Beibehaltung** | *Dasein* (mit Erläuterung) | Schleiermacher-verfremdend; Berman-Treue; Venuti-Foreignization | Bewahrt Spezifik vollständig | Erfordert Glossar; Fremdkörper im PT-Text |
| **2. Pre-sença** (Schuback) | *pre-sença* (mit Bindestrich) | Kreative Übersetzung; ehrt Heideggers Re-Etymologisierungs-Prinzip | Macht Begriff PT-funktional + bewahrt etymologisch-analytische Schicht | Neologismus; Leser muß sich an Konvention gewöhnen |
| **3. Existência** | *existência* | Schleiermacher-einbürgernd | PT-Leser versteht spontan | Verflacht Heideggers Spezifik; *Existenz* hat in *SuZ* eigene Bedeutung (≠ *Dasein*) |

**Diskussion** (cf. Sá Cavalcante 2012, *Cuidado da palavra*; Castelo-Branco 2007 *Sobre a tradução de Heidegger*).

### 2.3 Eigene Übersetzungs-Position für Heidegger

**Aufgabe Stage-6-A-3**: nach Lektüre + Übersetzung bestimmter Heidegger-Passagen eine eigene Position formulieren — welcher Weg + warum + wann?

Empfehlung: Mischung aus 1 (Beibehaltung) + 2 (kreative Übersetzung mit Bindestrich) — typisch in akademischer PT-Heidegger-Übersetzung. Weg 3 (Existência) für populäre Übersetzungen vorbehalten.

## 4. Sprachliche Aufgabe

**Übersetzungs-Werkstatt:**

1. Übersetzen Sie *SuZ* §§1–7 (~10-15 Seiten) ins PT — eigene Übersetzung (~3000W Quelltext + ~3500W Übersetzung).
2. Übersetzen Sie *SuZ* §31 *Das Verstehen* (~5 Seiten) ins PT — als Detail-Studie.
3. Verfassen Sie einen Übersetzungs-Begleitkommentar (~5000W):
   - §1 Stilfeature-Analyse Heidegger.
   - §2 Übersetzungs-Strategie + Verortung (Schleiermacher-Achse + Berman-Bezug).
   - §3 Konkrete Übersetzungs-Entscheidungen (mit Zitaten + 12+ Begriffe diskutiert).
   - §4 Vergleich mit Schuback + früheren Übersetzungen.
   - §5 Reflexive Schluss-Sektion.
