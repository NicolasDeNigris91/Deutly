# 06-D-4 — Materialien + Curriculum

## 1. Sprachliches Problem

DaF-Lehrer arbeitet zwischen zwei Polen:
- **Lehrwerk-Adoption**: bestehende Lehrwerke (Hueber, Cornelsen, Klett, Schubert) verwenden.
- **Materialien-Eigenentwicklung**: maßgeschneiderte Materialien für spezifische Lerngruppen.

Beide haben Vor- + Nachteile. Track-D-Lerner muss beides beherrschen + situativ wählen können.

---

## 2. Harte Theorie

### 2.1 Etablierte DaF-Lehrwerke

**Hueber-Verlag**:
- *Schritte plus* (A1-B1; Standard-Erwachsenen-DaF).
- *Tangram aktuell* (A1-B1).
- *Sicher!* (B1-C1).

**Cornelsen-Verlag**:
- *Studio d* (A1-B1; populär in Goethe-Instituten).
- *Studio: Express* (Berufs-DaF).

**Klett-Verlag**:
- *Aspekte neu* (B1-C1).
- *Mittelpunkt neu* (B1-C1).
- *Erkundungen* (B2-C2; akademisch).

**Schubert-Verlag**:
- *Erkundungen B2/C1/C2* (linguistisch dichter; akademisch-orientiert).
- *Wirtschaftskommunikation Deutsch* (Berufs-DaF).

### 2.2 Lehrwerk-Adoption — Kriterien

- **Niveau-Passung** (CEFR-Stufe).
- **Adressat-Passung** (allgemein vs. Berufs-DaF vs. Migration).
- **Aktualität** (jüngere Auflage; aktuelle Themen).
- **Authentik-Anteil** (Real-Texte vs. didaktisierte).
- **Multimedia-Integration** (Audio + Video + Online-Plattform).
- **Kosten** (für Lerner + Institution).

### 2.3 Materialien-Eigenentwicklung

Wann eigene Materialien?
- Lerngruppen mit spezifischer Berufs-/Forschungs-/Migrations-Situation.
- Themen ohne adäquate Lehrwerk-Abdeckung.
- Authentik-Texte aus Lokal-Kontext.
- Stage-6-Spezialisierung (Tracks C + D selbst).

**Komponenten eigener Materialien**:
1. **Authentik-Text** (Original-Quelle).
2. **Vor-Verstehens-Aufgaben** (Aktivierung Vorwissen + Lexikon).
3. **Verstehens-Aufgaben** (während des Lesens / Hörens).
4. **Nach-Verstehens-Aufgaben** (Vertiefung; produktive Anwendung).
5. **Glossar** mit Schlüsselbegriffen.
6. **Lehrer-Anmerkungen** (Methode + Variation + Schwierigkeits-Marker).

### 2.4 Curriculum-Komponenten Standard

Vollständiges Curriculum:
1. **Bedarfs-Analyse** (welche Lerngruppe? welche Ziele?).
2. **Niveau-Definition** (Eingangs-/ Ausgangsniveau CEFR).
3. **Lernziele operationalisiert** (Can-Do-Statements).
4. **Inhalts-Plan** (Themen + Grammatik + Lexikon + Pragmatik per Niveaustufe).
5. **Materialien-Liste**.
6. **Stundenplan** + Phasen.
7. **Bewertungs-Schema** (formativ + summativ).
8. **Evaluation** (Lerner-Feedback + eigene Reflexion).

### 2.5 Open Educational Resources (OER) DaF

Frei zugänglich:
- **Goethe-Institut Online-Lernen** (goethe.de/lernen).
- **DW Deutsch Lernen** (Deutsche Welle; dw.com/de/lernen-deutsch).
- **Hörspiele für DaF** (Goethe).
- **YouTube-Kanäle DaF** (Easy German, Learn German with Anja, etc.).
- **DaF-Lehrer-Materialien-Plattformen** (z.B. DLL Goethe-Materialien).

## 4. Sprachliche Aufgabe

(a) **Lehrwerk-Vergleich-Bericht** (~3000W): 3 Lehrwerke nach Adoption-Kriterien systematisch vergleichen + Empfehlung für hypothetische Lerngruppe.

(b) **Eigene Materialien-Einheit** (~3000W): authentischer Text + 5 Aufgaben + Glossar + Lehrer-Anmerkungen.

(c) **Curriculum-Skizze** (~3000W): vollständiges Curriculum für eine 60-Stunden-DaF-Modul (Niveau Ihrer Wahl).
