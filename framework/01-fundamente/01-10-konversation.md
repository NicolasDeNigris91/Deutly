# 01-10, Konversation Stage 1 — Replik-Praxis und Tandem-Vorbereitung

> **Modul-Spezifikum:** dieses ist das einzige Stage-1-Modul, das **non-substituierbar** durch reine Lektüre + Anki ist. Es **muss** durch Tandem-Praxis (Modus B) ergänzt werden. Theoretisches Curriculum unten ist *Vorbereitung* + *Skripte* + *Diagnostik*; das eigentliche Lernen erfolgt im Sprechen.

---

## 1. Sprachliches Problem

Das FATHOM-Deutsch-Framework ist stark auf **schriftliche + akademische Aufgaben** fokussiert: Tagebuch, Aufsatz, Vortrag-Skript. Was bisher fehlt, ist die **systematische Vorbereitung auf alltägliche Konversation** — die Sphäre, in der Aussprache, Réplik-Geschwindigkeit, Modalpartikeln und Pragmatik real getestet werden.

PT-falantes adultos travam in mündlicher Konversation in **fünf systematischen Punkten**:

1. **V2-Verletzung in Nebensätzen** (PT-Substrat: SVO bleibt in Nebensätzen): `*Ich gehe nicht ins Kino, weil ich bin müde` (statt `weil ich müde bin`).
2. **Akk./Dat.-Konfusion bei Wechselpräpositionen** in real-time: `*Ich gehe in der Stadt` (für direcionale Bewegung).
3. **Modalpartikel-Mangel** — DE klingt ohne `doch / ja / halt / mal / eigentlich` flach; PT hat kein systematisches Pendant.
4. **Pausen-Wörter als L1-Interferenz**: `então / tipo / é` mitten im DE-Satz.
5. **Tempo-Druck** — Lerner kann den Satz **schreiben**, aber nicht **sagen** unter Zeitdruck.

Sem este módulo:
- Aluno lê Adorno wunderbar, kann aber im Späti nichts bestellen.
- Schriftlicher Aufsatz exzellent; oraler Tandem-Versuch frustrierend (V2-Verletzungen, Modalpartikel-Mangel).
- Aussprache (cf. 01-08) wird nicht reaktiviert in real-time; bleibt dans Theorie.

Dieses Modul stellt **die Lücke zwischen schriftlicher Korrektheit und mündlicher Reaktivität** systematisch ein.

## 2. Harte Theorie

> 📚 **Phrase-Inventar mit ~150 Skripten** (Telefon, Service, Small Talk, Behörden, Notfälle): [ANHANG K — Alltagskommunikation](../00-meta/anhaenge/ANHANG-K-ALLTAGSKOMMUNIKATION.md). Esta seção apresenta a Methodologie; o Anhang é referência consultável.

### 2.1 Three Modi der L2-Konversations-Praxis (cf. MENTOR.md §0)

```
Modus A — Mentor (humano, professional):  
  Sprachschule + Privat-Lehrer + Goethe-Institut. Beste Quelle. 
  Hochpreisig, aber mit qualifiziertem Feedback.

Modus B — Peer (Tandem, native Sprecher):  
  Tandem-Apps (Tandem.net, HelloTalk, Speaky), Sprachcafés, 
  Stammtische in DE-sprachigen Städten. Kostenlos oder günstig. 
  Feedback-Qualität variabel.

Modus C — Self-Mentor (Aussprache + Self-Talk):  
  Self-Talk laut + Aufnahme + Selbstkritik. Für Phonetik (cf. 01-08) 
  brauchbar; für Konversation insufficient.
```

**Stage-1-Empfehlung:** mindestens 2× pro Woche Modus B (~1h pro Session). Modus A optional + ergänzend.

### 2.2 Output-Hypothesis (Swain 1985)

Merrill Swain's *Output Hypothesis* (gegen Krashen's Input-Only-Theorie): produktiver Output unter Zeitdruck ist **condicio sine qua non** für L2-Automatisierung. Lerner kann nicht durch Input-Konsum allein automatisieren; produktiver Output zwingt zur kognitiven Verankerung von Strukturen.

Auf das FATHOM-Deutsch angewandt: schriftliches Output (Tagebuch, Aufsatz) aktiviert Output-Hypothesis nur partiell — dort fehlt der **Zeitdruck**. Konversations-Output unter Echtzeit ist die andere Aktivierung. Beide sind notwendig.

### 2.3 Replik-Frasen — die Bausteine

Idiomatische Antwortphrasen, die isoliert gelernt + reaktiv eingesetzt werden:

#### Antwort-Bausteine (universal)

```
"Ja, genau." / "Genau!"           — Bestätigung
"Stimmt." / "Das stimmt."          — Bestätigung
"Ja, wirklich." / "Wirklich?"      — Bestätigung + Erstaunen
"Echt?"                            — informelles "Wirklich?"
"Klar." / "Selbstverständlich."    — Bestätigung mit Selbstverständlichkeit
"Auf jeden Fall." / "Auf keinen Fall." — Verstärkung
"Vielleicht." / "Möglich."         — Vorbehalt
"Eigentlich nicht."                — vorsichtige Negation
"Nein, leider nicht."              — höfliche Negation
"Tut mir leid, das weiß ich nicht." — höfliche Wissens-Negation
```

#### Verständnis-Bausteine (universal)

```
"Ich verstehe."                   — neutral
"Aha, ich sehe."                  — informelles "Ich verstehe"
"Wie bitte?" / "Was?"             — Frage nach Wiederholung (höfl. / informal)
"Können Sie das wiederholen?"     — formelle Wiederholung
"Was meinst du?" / "Wie meinst du das?" — Klarstellung
"Ich verstehe nicht."             — Unverständnis
"Tut mir leid, ich habe das nicht verstanden." — höfliches Unverständnis
"Können Sie etwas langsamer sprechen?" — Tempo-Bitte
"Können Sie das einfacher erklären?"   — Lexik-Bitte
```

#### Pausen-Wörter (zentral!)

```
"Also, ..."                       — Übergang zur Pointe
"Naja, ..."                       — leichte Einschränkung
"Tja, ..."                        — Pause der Resignation oder Reflexion
"Hmm."                            — Reflexion
"Äh / Ähm."                       — Hesitation-Filler
"Wie soll ich sagen..."           — Zeit gewinnend
"Sozusagen."                       — Ungefähr-Markierung (= "so to say")
"Eigentlich."                      — leichte Vorbehalt-Markierung
"Im Prinzip."                      — Generalisierung mit Spielraum
```

(Erinnern an [ANHANG D — Konnektoren](../00-meta/anhaenge/ANHANG-D-KONNEKTOREN.md) §3 — Konjunktionaladverbien.)

### 2.4 Repliken-Skripte — vorformulierte Sequenzen

Hochfrequente Konversation-Sequenzen, die als Skripte memorisiert + variiert werden.

**Beispiel-Skript: Restaurantbestellung**

```
1. Eintreten:           "Guten Abend, einen Tisch für zwei bitte."
2. Setzen:              "Vielen Dank."
3. Getränke-Bestellung: "Ich hätte gern ein großes Pils."
4. Speisen-Bestellung:  "Für mich bitte das Schnitzel mit Pommes."
5. Während Essen:       "Es schmeckt sehr gut, danke."
6. Rechnung:            "Die Rechnung bitte."
7. Bezahlung:           "Zusammen / Getrennt? — Zusammen, bitte."
8. Trinkgeld:           "Stimmt so." / "[X] Euro, bitte."
9. Verabschiedung:      "Schönen Abend noch."
```

(Vollständige Skripten in [ANHANG K](../00-meta/anhaenge/ANHANG-K-ALLTAGSKOMMUNIKATION.md).)

**Anwendung:** Skript memorieren, dann mit Tandem-Partner durchspielen, dann variieren (Vegetarier? Allergie? Alkoholfrei? Kindergedeck?).

### 2.5 Modalpartikel-Reaktivierung — die DE-spezifische Lücke

Modalpartikeln (cf. 01-07 + 03-05) sind in mündlicher DE-Sprache **omnipräsent**. PT-falantes lassen sie **systematisch weg** — und produzieren dadurch flaches, fremdartiges DE.

#### Die 5 unverzichtbaren Modalpartikeln Stage 1

```
1. doch    — Verstärkung mit Insistenz
   "Komm doch mit!"        (statt "Komm mit!")
   "Das ist doch klar."    (statt "Das ist klar.")
   
2. ja      — Bestätigung mit Erstaunen / Selbstverständlichkeit
   "Du bist ja schon hier!" (Erstaunen)
   "Das ist ja schön!"     (positive Surprise)
   
3. mal     — Aufforderung leichter
   "Komm mal her."         (statt "Komm her.")
   "Schau mal!"            (statt "Schau!")
   
4. denn    — Frage mit Neugier / Anteil
   "Was ist denn los?"    (statt "Was ist los?")
   "Wie heißt du denn?"   (Frage höflicher)
   
5. eigentlich — leichte Vorbehalt
   "Eigentlich nicht."
   "Wie heißt du eigentlich?"  (höfliche Frage; "actually")
```

**Anki-Cards** für jede Modalpartikel + 3-5 Sätze. Bei Tandem-Praxis: **bewusst** eine Modalpartikel pro Replik einsetzen — Übung in real-time.

### 2.6 Pausen-Wörter-Reaktivierung — Alternative zu PT-Filler

```
PT-Pausen-Wort   →   DE-Äquivalent
─────────────────────────────────
"então..."        →   "also..."
"tipo..."         →   "sozusagen..." / "so etwa..." 
"é..."            →   "mhm..." / "naja..."
"sabe..."         →   "weißt du..." / "verstehst du..."
"acho que..."     →   "ich glaube..." / "ich denke..."
"meio que..."     →   "irgendwie..." / "so ein bisschen..."
"como assim?"     →   "wie meinst du das?" / "in welchem Sinne?"
```

**Übung:** in der Tandem-Session bewusst PT-Filler eliminieren + DE-Filler reaktivieren. Wer "também" mitten in DE-Satz produziert, fällt ins PT-Substrat.

### 2.7 Tempo-Erwartung Stage 1

```
Native-Tempo (alltäglich):       150-180 W/min
Native-Tempo (akademisch):       120-140 W/min  
Native-Tempo (Tagesschau):       140-160 W/min

Stage-1-Lerner-Tempo (Tandem):    80-110 W/min   (50-70% Native)
Stage-2-Lerner-Tempo:             100-130 W/min
Stage-3-Lerner-Tempo:             120-150 W/min
Stage-4-5-Lerner-Tempo:           140-170 W/min  (sehr nahe Native)
```

**Lehre:** Tempo-Reduktion ist **methodisch korrekt**, kein Defizit. Wer auf Native-Tempo drängt vor Stage 3, fällt zurück ins PT-Substrat. Tempo wächst linear mit Stage; Erzwingen führt zu Fossilisierung.

### 2.8 Diagnostik — wie merke ich, dass mein Konversations-Stage 1 läuft?

```
Stage-1-Konversations-Niveau erreicht, wenn:

1. ich eine Restaurantbestellung machen kann (Skript memorisiert + variabel angewandt)
2. ich eine Frage nach dem Weg verstehen + beantworten kann
3. ich den eigenen Namen + Wohnort + Beruf in 30 Sek. sagen kann
4. ich Modalpartikel "doch" + "mal" in 50% meiner imperative Frasen einsetzte
5. ich PT-Filler ("então", "tipo") nicht mehr in DE-Konversation produziere
6. ich V2-Verletzung in Nebensätzen ("weil ich bin") aktiv bemerke + korrigiere
7. ich Wechselpräpositionen-Diagnostik (Wo? = Dat. / Wohin? = Akk.) automatisch anwende
8. ich Tempo ~80-110 W/min halten kann ohne PT-Backsliding
```

(Tor-Kriterien: cf. §3 unten.)

## 3. Schwelle der Meisterschaft

Você passa o **Konzeptuelles Tor** se, **sem consultar**:

1. Listar **5 Modalpartikeln** (`doch / ja / mal / denn / eigentlich`) mit jeweils einem Beispielsatz.
2. Listar **6 Replik-Frasen-Bausteine** (Bestätigung, Klarstellung, Pause).
3. **Restaurant-Skript** in 9 Schritten reproduzieren.
4. **Telefon-Skript** Eröffnung + Verbinden + Termin vereinbaren in 5 Schritten reproduzieren.
5. Erklären die **3 Hauptinterferenzen** PT-DE in Konversation + Anti-Beispiele dafür.
6. Erklären den **Output-Hypothesis** + warum Tandem-Praxis non-substituierbar ist.
7. Tempo-Erwartung Stage 1-5 nennen können.

## 4. Sprachliche Aufgabe — Tandem-Diagnostik

### Vorbereitung

1. **Tandem-Partner finden** (Modus B):
   - Tandem.net Account erstellen.
   - Profil mit Lernziel + Niveau (A2/B1) + Interessen.
   - 2-3 Tandem-Partner für mehrwöchige Praxis.

   Alternativ:
   - Goethe-Institut Sprachcafé (fast alle Goethe-Institutos haben dies).
   - Stammtisch in deutscher Stadt (cf. Trilha G).
   - Univ.-Sprachenzentrum (oft kostenlos).

### Durchführung — 3 Sitzungen á 60 min

**Sitzung 1 — Restaurant-Skript**

```
- 30 min PT (Tandem-Partner Lerner → Sie sind Coach).
- 30 min DE: Sie + Tandem-Partner führen Restaurant-Konversation 
  (Sie als Gast). 3-5 Mal durchspielen, mit Variationen 
  (vegetarisch, Allergie, etc.).
- Aufnahme machen + selbst nachhören.
- 5 wichtigste Fehler in Fehlerprotokoll registrieren.
```

**Sitzung 2 — Small Talk**

```
- 30 min PT.
- 30 min DE: Small Talk über Wetter / Wochenende / Beruf / Familie.
  Tandem-Partner stellt Fragen; Sie antworten.
- Bewusst 5 Modalpartikeln einsetzen (doch / ja / mal / denn / eigentlich).
- Bewusst PT-Filler (então / tipo / é) eliminieren.
- Aufnahme.
```

**Sitzung 3 — Telefon-Simulation**

```
- 30 min PT.
- 30 min DE: Telefon-Skript durchspielen (in echter Telefonsituation oder am 
  Smartphone-Lautsprecher) — Restaurantreservierung, Arzttermin, Auskunftsfrage.
- Aufnahme.
- Tempo: peilen Sie 80-100 W/min an.
```

### Output

```
- 3 Aufnahmen (≥60 min DE-Konversation total).
- Fehlerprotokoll-Tabelle:
  | Sitzung | PT-Substrat-Erro | DE-Korrektur | Wiederholung in Anki |
  | 1       | "ich gehe in der..."  | "in die..."     | Card erstellt        |
  | 1       | "...então..."         | "also..."        | Card erstellt        |
  | 2       | (...)                 |                  |                      |
- Selbst-Bewertung in 8 Punkten (cf. §2.8 Diagnostik).
```

Após terminar, peça o **Praktisches Tor**.
