# 01-09 — Grundwortschatz (Deutsche Fassung)

> Parallel-Adaptation. v3.0.

## 1. Sprachliches Problem

Grundwortschatz = ~2000 hochfrequente Lemmata, die ~80% der DE-Alltagskommunikation abdecken. Stage-1-Aufbau zentrale Aufgabe; Anki-basierter Aufbau empfohlen.

## 2. Harte Theorie

### 2.1 Frequenz-basierte Wort-Listen

Standardquellen:
- **Goethe-Institut Wortliste A1-A2** (frei via goethe.de).
- **Profile Deutsch** (Glaboniat et al., Langenscheidt 2005).
- **Häufigkeitswörterbuch** (Tschirner: *Grundwortschatz Deutsch*, Klett 2008).
- **DWDS-Wortprofil** für Frequenz-Validierung.

### 2.2 Wortschatz-Struktur

**Inhaltlich**:
- ~500 hochfrequente Verben (mit Stammformen + Hilfsverb-Wahl).
- ~700 hochfrequente Substantive (mit Genus + Plural).
- ~300 hochfrequente Adjektive.
- ~200 Funktionswörter (Präp, Konj, Partikel).
- ~300 alltägliche Phrasen + Kollokationen.

**Lern-Sequenz**:
- Wochen 1-4: Top 500 Lemmata.
- Wochen 5-12: Top 500-1500 Lemmata.
- Wochen 13-20: Top 1500-2000 + abgeleitete Komposita.

### 2.3 Anki-basierter Aufbau

(cf. ANKI-FRAMEWORK + STUDY-PROTOCOL §2)

**Karten-Format** für Stage 1:
- **Vorderseite**: Beleg-Satz mit Lücke; Bild wenn möglich.
- **Rückseite**: Vollständige Antwort + Genus + Plural + IPA + Beispiel-Verwendung.

**Beispiel**:
```
V: "Ich bin müde + möchte ___ ein Bett."  
R: in das (in + Akk lokativ direktional)  
   Substantiv-Beleg: das Bett /bɛt/, Pl. die Betten.
```

**Frequenz**: 20-40 neue Karten/Woche; tägliche Reviews.

### 2.4 Kontextueller Aufbau

Wortschatz nicht isoliert, sondern **frasal** lernen:
- Aus Lehrwerk-Texten.
- Aus authentischen einfachen Texten (FAZ-Schule; Tagesschau-Skripte).
- Aus eigener Konversation (was fehlt mir? → Karte).

### 2.5 Domäne-Differenzierung

Stage-1-Kerngebiete:
- **Alltag**: Familie, Wohnung, Essen, Einkaufen, Verkehr.
- **Arbeit**: Beruf, Tätigkeiten, Werkzeuge.
- **Reise**: Hotel, Restaurant, Sehenswürdigkeiten.
- **Gesundheit**: Körperteile, Symptome, Arzt.
- **Schule/Bildung**: Lehrer, Schüler, Fächer.

Vertiefung in Stage-2-Lexik II (operational + akademisch) + Stage-3-Lexik III (geisteswissenschaftlich).

## 3. Texto-âncora

Tschirner, Erwin: *Grundwortschatz Deutsch*. Stuttgart: Klett 2008. + ANKI-FRAMEWORK.

## 4. Sprachliche Aufgabe

(a) Anki-Karten-Aufbau für 500 Top-Lemmata in 4 Wochen.
(b) Eigene Frasal-Karten aus 5 Belegtexten.
(c) Wortschatz-Diagnose: 100 Top-Lemmata + Test-Selbstdiagnose Sprach-Ebene.
