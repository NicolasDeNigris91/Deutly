# 01-04 — Nominalflexion (Deutsche Fassung)

> **Hinweis:** Parallel-Adaptation von [01-04-nominalflexion.md](01-04-nominalflexion.md). PT-BR-Original Referenz.
>
> **Status:** v3.0 (2026-05-10).

## 1. Sprachliches Problem

DE-Nomen werden flektiert für **Genus** (m/f/n), **Numerus** (Sg/Pl) und (bei Adjektiv-Modifikation) für **Kasus**. PT hat 2 Genus + Numerus, aber keine Adjektivflexion-Komplexität — daher der häufigste Stage-1-Fehler: falsche Adjektiv-Endung oder falscher Plural.

## 2. Harte Theorie

### 2.1 Genus

**3 Klassen**: maskulin (der), feminin (die), neutrum (das).

**Phonologisch-semantische Tendenzen**:
- Suffix -ung, -keit, -heit, -schaft, -ität, -tät, -ion → fast immer **fem**.
- Suffix -chen, -lein → immer **n** (das Mädchen, das Häuschen).
- Suffix -er (Personen) → meist **m** (der Lehrer).
- Tageszeiten, Jahreszeiten, Monate → **m** (der Tag, der Sommer, der März).

PT-falante-Risiko: PT-Genus übertragen ("*die Sonne" stimmt; "*der Mond" stimmt; aber "*die Auto" falsch — das Auto).

### 2.2 Plural-Bildung (5 Hauptpattern)

| Pattern | Beleg | Genus-Tendenz |
|---|---|---|
| **-(e)** | Tag → Tage | m + n |
| **-(e) + Umlaut** | Mann → Männer; Vater → Väter | m + n |
| **-er + Umlaut** | Buch → Bücher; Haus → Häuser | n + einige m |
| **-(e)n** | Frau → Frauen; Bote → Boten | f + schwache m |
| **-s** (Lehnwörter) | Auto → Autos; Hotel → Hotels | jedes Genus |

### 2.3 Adjektivdeklination — 3 Patterns

**(a) Schwach** (nach Definitart-/Demonstrativ-Pron + Possessiv-Pron mit eindeutiger Markierung): Adj nimmt **-e** (Nom.Sg.) oder **-en** (alles andere).

> *Der gute Mann.* / *Den guten Mann.* / *Mit dem guten Mann.*

**(b) Stark** (ohne Artikel): Adj trägt die volle Kasus-Markierung wie ein Artikel.

> *Guter Mann!* / *Gutes Wetter.* / *Trotz schlechten Wetters.*

**(c) Gemischt** (nach unbestimmt. Artikel + kein- + mein-): Mischung — schwach in markierten, stark in unmarkierten Positionen.

> *Ein guter Mann.* (= *guter* trägt Marker, da *ein* nicht). / *Einen guten Mann.* (= *guten* schwach).

cf. ANHANG E Adjektivdeklination vollständig.

### 2.4 Sonderfälle

- **-er/-el/-en-Endung-Adjektive**: Tilgung des -e- in flektierter Form (dunkel → ein dunkler Raum; teuer → das teure Auto).
- **hoch → hoh-** in flektierter Form (das hohe Haus, nicht *das hoche Haus).
- **lila / rosa**: invariabel (das lila Kleid).
- **Substantivierte Adjektive**: nehmen Adjektiv-Flexion (der Deutsche, ein Deutscher).

## 3. Texto-âncora

Eisenberg Bd. 1, Kap. 7 *Nominale Wortformen*. + ANHANG E Adjektivdeklination.

## 4. Sprachliche Aufgabe

(a) Adjektiv-Endung-Drill für 30 Sätze (alle 3 Patterns × 4 Kasus).
(b) Plural-Bildung-Übung für 30 Substantive.
(c) Genus-Identifikation für 50 Substantive + Suffix-Regel-Begründung.
