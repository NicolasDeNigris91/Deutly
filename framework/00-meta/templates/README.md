## Strukturlogik der Templates

Jedes Template enthält:

1. **Frontmatter** (YAML) com metadados estruturados.
2. **Strukturschema** com Sektionen + relativem Wortanteil.
3. **Sektion-für-Sektion-Hinweise** com Bausteine + Stilexpektativas.
4. **Korrekturschleife** (loop von 2-4 rounds, je nach Capstone).
5. **Anti-Patterns** (was nicht zu tun).
6. **Bewertungsraster** (Verweis auf RUBRIC.md mit Sektion).
7. **Cross-references** zu Modulen + Anhängen.

---

## Princípios dos Templates

1. **Scaffold, nicht Korsett.** Template apresenta estrutura padrão; aluno pode (e deve) negociar com a estrutura conforme conteúdo.
2. **Zeigen, nicht Diktieren.** Onde possível, mostrar Beispiel completo (cf. Tagebuch-Template Beispieleintrag) — não apenas regra abstrata.
3. **Stilexpektativas explízit.** Cada Template lista Stilforderungen (Konj. I + Konj. II + FVG + Modalpartikel etc.) por Niveau.
4. **Korrekturschleife eingebaut.** Loop von Camadas (Grammatik → Lexik → Stil → Native erudite) é parte do Template, não opcional.
5. **RUBRIC integriert.** Bewertungsraster não é separado; aluno vê desde o início como será avaliado.

---

## Como usar um Template — Workflow

```
1. Lesen: Template komplett durchlesen (das gehört zum CAPSTONE-Vorbereitung).
2. Frontmatter ausfüllen: Metadaten der eigenen Arbeit.
3. v1 schreiben: erste Fassung folgend Strukturschema, mit Lücken erlaubt.
4. v2 Eigenkorrektur: 4 Camadas (Grammatik / Lexik / Stil / Native erudite).
5. v3 Externe Korrektur: Mentor / Peer / Tandempartner.
6. Optional v4: nach substantiellem externem Feedback.
7. Abschluss: PROGRESS.md aktualisieren; CAPSTONE-X DONE.
```
