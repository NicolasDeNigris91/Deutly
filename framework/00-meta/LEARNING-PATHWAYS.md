# LEARNING-PATHWAYS — Trilhas alternativas

> Documento operacional cross-stage. Nem todo aluno percorre o framework do mesmo modo. Este documento define **5 trilhas legítimas** + 1 trilha exploratória, com cronogramas distintos conforme objetivo.

---

## 1. Princípio

A trilha **canônica** do FATHOM-Deutsch (Stages 1-2-3-4-5 sequenciais com todos módulos) é o **default mais rigoroso**. Mas alunos com objetivos específicos podem percorrer trilhas modificadas — desde que respeitem **não-negociáveis**:

```
1. Cada módulo seguido tem 3 Tore obrigatórios.
2. Pré-requisitos são bloqueantes (não pular).
3. Capstones encadeados (Erkenntnisprojekt v0→v4).
4. Anki + Tagebuch + leitura sustentada cross-stage.
```

Trilhas alternativas modificam **escopo, ordem, ou ênfase** — não rebaixam rigor.

---

## 2. Trilha A — Canônica (default)

### Perfil

Aluno generalista que busca C2+ World Class equilibrado em todos os domínios.

### Sequência

```
Stage 1 (todos 9 módulos + Capstone-1)
   ↓
Stage 2 (todos 9 + Capstone-2)
   ↓
Stage 3 (todos 9 + Capstone-3)
   ↓
Stage 4 (todos 10 + Capstone-4)
   ↓
Stage 5 (módulos 05-01 a 05-06 + 05-07 opcional + Capstone-5)
```

### Tempo total estimado

**~2-5 mil horas** distribuídas em **5-10 anos** com 10-15h/semana sustentadas.

### Para quem

- Aprendiz adulto que tem horizonte de longo prazo.
- Não tem urgência específica (PhD, publicação, certificação).
- Valoriza domínio integral.

## 3. Trilha B — Geisteswissenschaft (filosofia + germanística)

### Perfil

Aluno orientado para Filosofia, Germanística, Hermenêutica. Objetivo: ler Kant, Hegel, Heidegger, Adorno, Habermas em DE original; produzir Aufsatz acadêmico.

### Modificações vs. canônica

#### Stages 1-2: completos (sem cortes)

Sistema operacional + sintaxe complexa são prerequisitos universais.

#### Stage 3: ênfase reforçada

```
Prioridade alta:    03-01, 03-06, 03-07, 03-09 (Stil filosófico-acadêmico)
Prioridade média:   03-02, 03-04, 03-05 (registro + pragmatik + Modalpartikeln)
Prioridade reduzida: 03-08 (Journalistischer Stil — opcional para esta trilha)
```

#### Stage 4: ênfase em Hermeneutik

```
Prioridade alta:    04-01, 04-02, 04-10 (Historische Linguistik + Etymologie + Hermeneutik)
                    04-04 (Generative Syntax — base teórica)
                    04-05 (Formale Semantik — base lógica)
Prioridade média:   04-08 (Korpuslinguistik para Capstone-4)
                    04-09 (Kontrastive PT-DE)
Prioridade reduzida: 04-03 (Variationslinguistik — pode ser leitura passiva)
                    04-06 (Diskursanalyse — pode ser leitura passiva)
                    04-07 (Textlinguistik — leitura passiva)
```

#### Stage 5: foco em publicação acadêmica

```
Prioridade alta:    05-02 (Wissenschaftssprache: Habermas, Luhmann, Adorno)
                    05-04 (Eigene Stimme — Stilbildung)
                    05-05 (Public Output — Aufsatz + Vortrag)
                    Capstone-5 (publicação em revista filosófica DE/AT/CH)
Prioridade média:   05-03 (Übersetzungstheorie — útil para tradução de Begriffe)
                    05-06 (Mentoring — útil para construir comunidade)
Opcional:            05-01 (Politische Sprache — só se tema do Begriff é político)
                    05-07 (Goethe C2 — útil se busca PhD)
```

### Capstone-5 alvo

Publicação em revista filosófica/acadêmica DE/AT/CH:
- *Deutsche Zeitschrift für Philosophie*
- *Zeitschrift für philosophische Forschung*
- *Internationales Jahrbuch für Hermeneutik*
- *Mittelweg 36*
- *Mervkur* (cultural)

### Tempo estimado

**~2.5-4.5 mil horas** em **5-9 anos**.

## 4. Trilha C — Linguistik (germanística + linguística aplicada)

### Perfil

Aluno orientado para Linguística, Germanistik, Sprachwissenschaft empírica. Objetivo: análise linguística sistemática + corpus + análise sintática.

### Modificações vs. canônica

#### Stages 1-2: completos (com ênfase analítica)

Cada módulo é exercício de análise linguística sistemática, não apenas adquisição prática.

#### Stage 3: redução parcial

```
Prioridade alta:    03-01, 03-02, 03-05 (Stil + Register + Modalpartikeln)
Prioridade média:   03-03, 03-04 (Idiomatik + Pragmatik)
Prioridade reduzida: 03-06, 03-07 (Stilfiguren + Wissenschaftliches Schreiben — leitura)
                    03-08, 03-09 (Journalistischer Stil + Lexik III — leitura)
```

#### Stage 4: ênfase máxima — núcleo da trilha

```
Prioridade alta:    TODOS os módulos do Stage 4.
Especialmente:      04-04 (Generative Syntax)
                    04-08 (Korpuslinguistik)
                    04-09 (Kontrastive Linguistik PT-DE)
                    04-03 (Variationslinguistik)
                    04-07 (Textlinguistik)
                    04-05 (Formale Semantik)
                    04-06 (Diskursanalyse)
```

#### Stage 5: foco em publicação linguística + ferramenta

```
Prioridade alta:    05-04 (Eigene Stimme)
                    05-05 (Public Output em ZGL/ZfS)
                    Capstone-5 (publicação em revista de linguística)
Prioridade média:   05-02 (Wissenschaftssprache; ler Eisenberg, Wöllstein, Reis)
                    05-06 (Mentoring)
Opcional:            05-01 (Politische Sprache — só se tema KDA)
                    05-03 (Übersetzungstheorie — opcional)
                    05-07 (TestDaF preferível a Goethe C2 se PhD-DE)
```

### Capstone-5 alvo

Publicação em revista de linguística DE:
- *Zeitschrift für Sprachwissenschaft (ZfS)*
- *Zeitschrift für Germanistische Linguistik (ZGL)*
- *Deutsche Sprache*
- *Linguistische Berichte*
- *Sprache und Literatur*

### Tempo estimado

**~3-5 mil horas** em **6-10 anos**.

## 5. Trilha D — Tradução PT↔DE (Übersetzungswissenschaft)

### Perfil

Aluno orientado para tradução literária ou filosófica entre PT e DE. Objetivo: produzir traduções publicáveis + reflexão teórica.

### Modificações vs. canônica

#### Stages 1-2: completos

#### Stage 3: ênfase em estilística + idiomatik

```
Prioridade alta:    03-01 (Nominaler vs. verbaler Stil)
                    03-02 (Register)
                    03-03 (Idiomatik + Phraseologismen)
                    03-06 (Stilfiguren)
                    03-07 (Wissenschaftliches Schreiben — para Aufsatz teórico)
                    03-09 (Lexik III — Begriffe filosóficos)
Prioridade média:   03-04, 03-05, 03-08
```

#### Stage 4: ênfase em kontrastive Linguistik

```
Prioridade máxima:  04-09 (Kontrastive Linguistik PT-DE) — núcleo absoluto.
                    04-04 (Generative Syntax — base tipológica)
                    04-02 (Etymologie — para tradução de Begriffe)
                    04-10 (Hermeneutik — para tradução de textos clássicos)
Prioridade média:   04-01 (Historische Linguistik)
                    04-08 (Korpuslinguistik PT-DE corpora paralelos)
                    04-07 (Textlinguistik)
Prioridade reduzida: 04-03, 04-05, 04-06
```

#### Stage 5: foco em Übersetzungstheorie + Praxis

```
Prioridade máxima:  05-03 (Übersetzungstheorie und -praxis) — núcleo da trilha.
                    05-04 (Eigene Stimme — em DE e em PT)
                    Capstone-5 (tradução publicada como output principal)
Prioridade média:   05-02 (Wissenschaftssprache para apresentar tradução teorizada)
                    05-05 (Vortrag sobre tradução; podcast sobre tradução)
                    05-06 (Mentoring de tradutores aprendizes)
Opcional:            05-01, 05-07
```

### Capstone-5 alvo

Tradução publicada (literária ou filosófica) com aparelho crítico:
- Revista *Akzente* (Hanser).
- *Lettre International*.
- *Schreibheft*.
- Edição em editorial DE (Suhrkamp, Hanser, Reclam UB) ou PT (Companhia das Letras, Cosac Naify, Editora 34).

### Tempo estimado

**~2.5-4.5 mil horas** em **5-9 anos**.

## 6. Trilha E — Berufsdeutsch (uso profissional)

### Perfil

Aluno que precisa de DE **profissional** sólido (B2-C1 estável) sem ambição acadêmica. Objetivo: trabalhar em Bundesländer, comunicar profissionalmente, escrever relatórios, dar apresentações.

### Modificações vs. canônica

#### Stage 1-2: completos

(Sem atalhos — sistema operacional + sintaxe complexa são universais.)

#### Stage 3: ênfase profissional

```
Prioridade alta:    03-02 (Register — saber escolher Hochsprache vs. coloquial)
                    03-04 (Pragmatik — Höflichkeit em e-mail comercial, telefone)
                    03-05 (Modalpartikeln — para fala fluente)
                    03-07 (Wissenschaftliches Schreiben — para relatórios)
                    03-08 (Journalistischer Stil — para acompanhar mídia profissional)
Prioridade média:   03-01, 03-03
Prioridade reduzida: 03-06, 03-09 (Stilfiguren + Lexik III filosófico — opcional)
```

#### Stage 4: redução substancial

```
Prioridade média:   04-09 (Kontrastive PT-DE)
                    04-03 (Variationslinguistik — para reconhecer Plurizentrik)
Opcional:            04-01, 04-02 (Historische + Etymologie)
                    04-08 (Korpuslinguistik para Begriffsanalyse profissional?)
Prioridade reduzida: 04-04, 04-05, 04-06, 04-07, 04-10
```

#### Stage 5: foco em uso profissional

```
Prioridade alta:    05-04 (Eigene Stimme — para comunicação profissional consistente)
                    05-05 (Public Output — Vortrag profissional, presentation)
                    05-07 (TestDaF mais relevante que Goethe C2; ou apenas Goethe-Zertifikat C1
                            se objetivo é integração profissional sem ambição acadêmica)
Prioridade média:   05-01 (Politische Sprache — para integração civil)
                    05-06 (Mentoring opcional)
Reduzido:            05-02, 05-03 (Wissenschaftssprache + Übersetzungstheorie — opcionais)
                    Capstone-5 pode ser projeto profissional, não necessariamente publicação acadêmica.
```

### Capstone-5 alvo (modificado)

- **Apresentação profissional gravada** + **relatório técnico publicado** (interno ou no setor).
- Ou: TestDaF TDN 5 + integração profissional documentada.
- (Não precisa ser publicação em revista; foco prático.)

### Tempo estimado

**~1.5-3 mil horas** em **3-6 anos**.

## 7. Trilha F — PhD-DE acelerada

### Perfil

Aluno que precisa de **TestDaF TDN 5 + Capstone-3 (5000 W)** em ~2-3 anos para admissão em programa PhD em DE-instituição. Objetivo: TestDaF + Aufsatz acadêmico defensável + integração universitária.

### Modificações vs. canônica

#### Stages 1-2: acelerados mas completos

Ritmo máximo (15-20h/semana sustentado). 18-24 meses.

#### Stage 3: focado

```
Prioridade alta:    03-01, 03-02, 03-04, 03-07, 03-09 (Stil + Register + Pragmatik + Aufsatz + Lexik III)
Prioridade média:   03-03, 03-05, 03-06
Prioridade reduzida: 03-08
```

#### Stage 4: redução estratégica para PhD

```
Prioridade alta:    04-08 (Korpuslinguistik — útil para Capstone-4)
                    04-10 (Hermeneutik klassischer Texte — base de PhD)
                    04-09 (Kontrastive PT-DE)
                    04-04 (Generative Syntax)
Prioridade média:   04-01, 04-02 (Historische + Etymologie)
                    04-05, 04-06, 04-07
Prioridade reduzida: 04-03 (Variationslinguistik — apenas leitura passiva)
```

#### Stage 5: TestDaF + Capstone-5 como demonstração

```
Prioridade alta:    05-07 (TestDaF — preparação focada)
                    05-04 (Eigene Stimme)
                    05-05 (Public Output)
                    Capstone-5 (publicação ou apresentação acadêmica como prova)
Prioridade média:   05-02 (Wissenschaftssprache para entrar em sub-tradição)
                    05-06 (Mentoring opcional)
                    05-01 (Politische Sprache — opcional)
Reduzido:            05-03 (Übersetzungstheorie — apenas se relevante para tese de PhD)
```

### Capstone-5 alvo

- **TestDaF TDN 5** em todos 4 módulos.
- **Capstone-5** com publicação em revista acadêmica (mesmo que parcial; prova de competência).
- **Vortrag** apresentado em conferência (graduação avançada).

### Tempo estimado

**~2-3 mil horas** em **2-3 anos** (intensivo).

## 8. Como escolher a trilha

### Auto-pergunta inicial

```
1. Qual meu objetivo de longo prazo (5-10 anos)?
   - Acadêmico: Stage 4-5 plenos (Trilha A, B, ou C).
   - Profissional não-acadêmico: Trilha E.
   - Tradução publicada: Trilha D.
   - PhD-DE rápido: Trilha F.
   - Generalista: Trilha A canônica.

2. Quanto tempo posso dedicar / semana?
   - 5-8h: Trilha E (uso profissional realista).
   - 10-15h: Trilha A, B, C, D (canônicas em ritmo médio).
   - 15-25h: Trilha F (intensiva, 2-3 anos).

3. Que tipo de output me motiva?
   - Aufsatz acadêmico: A, B, C, F.
   - Tradução publicada: D.
   - Apresentação profissional: E.
   - Vortrag + Podcast + comunidade: A, B, qualquer trilha com Stage 5 completo.

4. Quão importante é Plurizentrik / Mhd. para mim?
   - Muito (germanística histórica): A, B, C com Stage 4 completo.
   - Pouco (uso prático): E.
```

### Trilha exploratória (transitar entre trilhas)

Não é obrigatório fixar trilha desde o início. Após Stage 1-2 completos, aluno pode reavaliar:

```
- Após Capstone-2 (Aufsatz 1500 W): qual orientação ressoa mais? Filosófica? Linguística? Tradução?
- Após Capstone-3 (Aufsatz 5000 W): qual sub-tradição me orienta? Habermas? Luhmann? Adorno?
- Após Capstone-4 (korpusbasierte Begriffsanalyse): que veículo de publicação prepara melhor o Capstone-5?
```

Trilha pode ser **modificada com Audit retrospectivo + DECISION-LOG entry justificando**.

## 9. Não-negociáveis comuns a todas trilhas

```
1. Stages 1-2 completos sem cortes (sistema operacional + sintaxe complexa são universais).
2. 3 Tore por módulo seguido (não pular Tor algum).
3. Pré-requisitos são bloqueantes (estrutural).
4. Anki sustentado (deck saturado por Stage adequado).
5. Tagebuch em DE em algum momento (Stage 3 ou 4 mínimo).
6. Capstones encadeados (Erkenntnisprojekt v0→v4 mesmo se trilha modifica volume v4).
7. Pelo menos 1 canal externo após 6 meses solo (anti-isolamento gate, MENTOR.md §10.5).
8. Audit honesto trimestral (Fehlerprotokoll + PROGRESS.md).
```

---

## 10. Auditoria de trilha

A cada 6-12 meses, audit:

```
□ Estou na trilha que escolhi?
□ Trilha ainda corresponde aos meus objetivos?
□ Volume de trabalho é sustentável?
□ Lacunas detectáveis em módulos pulados?
□ Sub-tradição emergente consistente?
□ Capstone-evolution está progredindo?
```

Se 3+ red flags: **DECISION-LOG entry** + reavaliar trilha. Mudança de trilha é legítima; abandono sem reflexão não é.
