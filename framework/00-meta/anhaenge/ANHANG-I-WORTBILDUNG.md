# ANHANG I — Wortbildung-Patterns (Komposition + Derivation)

> Referência consolidada para [01-06 Wortbildung I](../../01-fundamente/01-06-wortbildung.md) + transversal Stages 1-4 (decomposição de Komposita em Adorno, Heidegger, juristisches Deutsch).
>
> Sistematização dos **3 Wortbildungs-Verfahren** principais do DE: **Komposition**, **Derivation**, **Konversion**. Cada um com Patterns produktiv + Restriktionen + Beispiele canônicos. **Inclui catálogo dos sufixos derivacionais com Genus + Wortart-Resultat + produtividade**.

---

## 1. Übersicht — die 3 Wortbildungs-Verfahren

```
1. Komposition:    Stamm + Stamm        →  Schreibtisch, Aufklärungsphilosophie
                   (frequenten in DE; klasse offen)

2. Derivation:     Stamm + Affix         →  Lehrer (Stamm leh + Suff. -er)
                   (Präfix + Stamm, Stamm + Suffix, Präfix + Stamm + Suffix)

3. Konversion:     Wechsel der Wortart   →  laufen → das Laufen (Verb→Subst.)
                   ohne morphologische Markierung
```

Das DE ist ein hochproduktives Sprachsystem für **Komposition** — Komposita unterschiedlicher Länge (`Donaudampfschifffahrtsgesellschaftskapitän`) sind regelmäßig formbar; nicht idiosynkratisch. Diese Produktivität ist eines der zentralen typologischen Merkmale gegenüber PT (analytisch).

---

## 2. Komposition

### 2.1 Strukturelle Klassen — 4 Typen

#### A) Determinativkomposita (frequenten)

**Pattern:** Determinans + Determinatum. Determinatum trägt Genus + Numerus + Flexionsklasse + Hauptbedeutung; Determinans modifiziert.

```
Schreibtisch         (n.)  =  schreiben + Tisch (Tisch ist Determinatum)
Hauptstraße          (f.)  =  Haupt + Straße
Bundeskanzler        (m.)  =  Bund + Kanzler
Aufklärungsphilosophie (f.)  =  Aufklärung + Philosophie (Genus: f.)
```

**Genus:** Determinatum.
**Akzent:** auf Determinans (initial).
**Pluralbildung:** des Determinatums.

#### B) Kopulativkomposita (selten)

**Pattern:** Beide Konstituenten sind gleichwertig; semantisch auf gleicher Hierarchie.

```
schwarzweiß           (Adj.)
Hosenrock             (m.)  =  Hose + Rock — beides
Süd-Nord-Schiebung    (f.)  =  Süd + Nord (Bindestrich!)
Rumpfregierung-Liste  (f.)  =  beide Komponenten gleichrangig
```

**Selten in DE produktiv**; meist in Adjektiv-Bereichen.

#### C) Possessivkomposita / Bahuvrihi (gehoben)

**Pattern:** Komposita, die ein Drittes bezeichnen, dessen Eigenschaft im Kompositum genannt wird.

```
Rotkäppchen           = die "ein rotes Käppchen Habende" (Mädchen mit rotem Käppchen)
Langfinger            = "einer mit langen Fingern" (Dieb)
Großmaul              = "einer mit großem Maul" (Angeber)
Dickschädel           = "einer mit dickem Schädel" (Sturkopf)
Schlaukopf            = "einer mit schlauem Kopf"
```

**Idiomatisch fixiert**; nicht produktiv.

#### D) Verbalkomposita

**Pattern:** Substantiv/Adjektiv + Verb.

```
teilnehmen            = teil + nehmen          (trennbar; "teil" als Akzent)
fernsehen             = fern + sehen           (trennbar)
gefangen nehmen       = gefangen + nehmen      (Adjektiv + Verb; trennbar)
```

Cf. [01-03 Verbalsystem §2.6](../../01-fundamente/01-03-verbalsystem.md) für trennbar/untrennbar.

### 2.2 Fugenelement (Linker Konnektor)

In Determinativkomposita zwischen Determinans + Determinatum erscheint manchmal ein **Fugenelement**: `-s-`, `-(e)n-`, `-(e)r-`, `-e-`, `-∅-`.

| Fuge | Beispiele | Distribution |
|---|---|---|
| `-s-` | Aufklärung**s**philosophie, Liebe**s**brief, Schaden**s**ersatz | Nach Determinans-Endung -ung, -heit, -keit, -schaft, -tum, -tion, -ion, Komposita mit Ge-Prefix; FNotwendig vor bestimmten Determinata |
| `-en-` | Strahl**en**therapie, Gedank**en**gang, Frau**en**rechte | Nach Substantiven mit Plural -en oder Schwacher Maskulinen |
| `-er-` | Kind**er**garten, Wört**er**buch, Bild**er**buch | Nach Substantiven mit Plural -er |
| `-e-` | Tag**e**buch, Tag**e**lohn, Hund**e**futter | Nach Substantiven mit Plural -e (alt; oft auch ohne Fuge: Tagbuch unzulässig, aber Tagblatt OK) |
| `-∅-` | Schreibtisch, Hausschuh, Küchenmesser | Default em maioria absoluta dos Komposita |

**Heuristik:** Fugenelement nicht arbiträr — segue Plural-Pattern do Determinans (~60-80% korrelação) oder phonologische Regeln (Vermeidung von Hiat, von schwierigen Konsonant-Cluster).

### 2.3 Komposita-Kette (Hyper-Komposition)

DE permite Komposita mit > 2 Konstituenten:

```
3 Konstituenten:
  Schreib + tisch + lampe    →  Schreibtischlampe

4 Konstituenten:
  Donau + dampf + schiff + fahrt  →  Donaudampfschifffahrt
  Aus + bildungs + phase + plan   →  Ausbildungsphasenplan

5+ Konstituenten:
  Donau + dampf + schiff + fahrts + gesellschaft + s + kapitän
  →  Donaudampfschifffahrtsgesellschaftskapitän
```

**Linguistisch berechtigt** — não é arbitrário; cada nível tem Determinans-Determinatum-Beziehung válida.

**Pragmatisch limitiert** durch Lesbarkeit. Norm acadêmica: > 4 Konstituenten geralmente unwirtschaftlich; Zeitungs-Stil tolera 3-4.

## 3. Derivation

### 3.1 Präfix-Derivation

Präfixe (≠ Konjugationsverben-Präfixe) modifizieren Bedeutung des Stamms.

#### Untrennbare Präfixe (cf. 01-03 §2.6 + ANHANG A)

```
be-, ge-, er-, ver-, zer-, ent-, emp-, miss-
```

(Para Verben-Konjugation; cf. ANHANG A.)

#### Substantiv-/Adjektiv-Präfixe

| Präfix | Bedeutung | Beispiele |
|---|---|---|
| **un-** | Negation | Unmündigkeit, Unglück, unwahr, unerwartet |
| **miss-** | falsch / missrat. | Misserfolg, missverstanden, Misstrauen |
| **ur-** | original / Stamm-Urs- | Ursprung, Urvater, urig |
| **erz-** | Verstärkung pejor. | Erzfeind, Erzbischof |
| **bei-** | nebenstehend | Beisitzer, Beifahrer, Beipack |
| **mit-** | gemeinsam | Mitarbeiter, Mitgefühl, Mitschüler |
| **vor-** | räumlich/zeitlich vor | Vorgang, Vorgesetzter, Vorbild |
| **nach-** | räumlich/zeitlich nach | Nachfolger, Nachmittag, Nachwirkung |
| **gegen-** | entgegen | Gegenargument, Gegensatz, Gegenstand |
| **ober-** | hierarchisch über | Oberst, Oberlehrer, Obergeschoss |
| **unter-** | hierarchisch unter | Unterricht, Untertan, Unterführer |
| **über-** | räumlich/quantitativ über | Übergang, Überschuss, übertragen |
| **inter-** | zwischen (Lehnpräfix) | International, Interaktion, Intervention |
| **anti-** | gegen | Antisemitismus, Antikrieg, antikapitalistisch |
| **non-** | nicht (Lehnpräfix) | Nonkonformismus, Non-Stop |
| **proto-** | erster | Prototyp, Protokoll, Protozoa |

### 3.2 Suffix-Derivation — die produktivsten Suffixe

#### A) Substantiv-erzeugende Suffixe

| Suffix | Genus | Bedeutung | Beispiele |
|---|---|---|---|
| **-ung** | f. | Verbalsubstantiv (Aktion / Resultat) | Erklärung, Bedeutung, Forschung, Lösung, Aufklärung — von schwachen Verben |
| **-heit** | f. | abstr. Substantiv von Adj. | Gesundheit, Freiheit, Schönheit, Wahrheit |
| **-keit** | f. | abstr. Substantiv (nach -ig, -lich, -bar) | Möglichkeit, Tätigkeit, Sterblichkeit, Mündigkeit |
| **-schaft** | f. | Kollektiv / abstrakt | Wissenschaft, Freundschaft, Bauernschaft, Gesellschaft |
| **-tum** | n. (m. selten) | Stand / Kollektiv / Abstrakt | Eigentum, Christentum, Bürgertum, Reichtum |
| **-er** | m. | Akteur / Werkzeug / Bewohner | Lehrer, Schreiber, Bohrer, Berliner — vom Verb-Stamm oder Subst.-Stamm |
| **-erin** | f. | weibl. Akteur | Lehrerin, Schreiberin, Berlinerin |
| **-ling** | m. | Akteur / Pflegling | Liebling, Flüchtling, Lehrling, Sterbling |
| **-chen** | n. | Diminutiv | Mädchen, Häuschen, Bübchen — alt/idiomatisch |
| **-lein** | n. | Diminutiv (poet./südd.) | Vöglein, Brüderlein, Stündlein |
| **-nis** | n. (f. selten) | abstr. Substantiv | Erlebnis, Erkenntnis (f.), Ergebnis, Bündnis |
| **-sal** | n. | Resultat (gehoben) | Schicksal, Mühsal, Drangsal, Trübsal |
| **-tum** | n. | Stand / Kollektiv | (cf. oben) |
| **-(at)ion** | f. | abstr. Lehnsuffix | Information, Demonstration, Funktion |
| **-ität** | f. | abstr. Lehnsuffix | Realität, Identität, Universalität |
| **-ismus** | m. | Doktrin / Tendenz (Lehnsuffix) | Idealismus, Positivismus, Marxismus |
| **-ist** | m. | Anhänger (Lehnsuffix) | Idealist, Marxist, Polizist |
| **-or** | m. | Akteur (Lehnsuffix) | Direktor, Diktator, Reaktor |
| **-eur** | m. | Akteur (frz. Lehnsuffix) | Ingenieur, Friseur, Saboteur |

#### B) Adjektiv-erzeugende Suffixe

| Suffix | Bedeutung | Beispiele |
|---|---|---|
| **-ig** | charakter. Eigenschaft | klug, mutig, kräftig, holzig |
| **-lich** | charakter. Eigenschaft | freundlich, mündlich, gefährlich |
| **-bar** | passiv. Möglichkeit (= "können -t werden") | machbar, hörbar, lesbar, fragwürdig |
| **-haft** | charakter. (zugehörig zu) | krankhaft, jugendhaft, ehrenhaft |
| **-isch** | zugehörig zu / charakter. | europäisch, geographisch, historisch |
| **-los** | ohne | sinnlos, mutlos, sprachlos |
| **-arm** | wenig | nährstoffarm, einfühlungsarm |
| **-reich** | viel | erfolgreich, kraftreich, kinderreich |
| **-frei** | ohne (positiv konnotiert) | bleifrei, glutenfrei, anstandslos |
| **-fest** | dauerhaft | wetterfest, säurefest, biegfest |
| **-mäßig** | gemäß / typisch | regelmäßig, planmäßig, ordnungsgemäß |
| **-würdig** | wertig | sehenswürdig, lobenswürdig, fragwürdig |
| **-fähig** | imstande | leistungsfähig, anpassungsfähig |
| **-sam** | charakter. (gehoben) | mühsam, sparsam, einsam, ratsam |
| **-iv** | charakter. (Lehnsuffix) | aktiv, intensiv, produktiv |
| **-ell** | charakter. (Lehnsuffix) | aktuell, traditionell, intellektuell |
| **-ent / -ant** | charakter. (Lehnsuffix) | intelligent, eminent, dominant |

#### C) Verb-erzeugende Suffixe

| Suffix | Bedeutung | Beispiele |
|---|---|---|
| **-(e)n** | Default-Verb-Suffix | machen, gehen, sehen, lesen, ...  |
| **-ieren** | Lehn-Verbsuffix (lat./frz.) | studieren, telefonieren, regieren, fotografieren |
| **-(s)ieren** | Lehn-Verbsuffix produkt. | informieren, materialisieren, idealisieren |
| **-eln** | iter./diminutiv | klingeln, lächeln, näseln, häufig |
| **-ern** | iter. | klappern, plätschern, hämmern, blättern |

#### D) Adverb-erzeugende Suffixe

| Suffix | Bedeutung | Beispiele |
|---|---|---|
| **-weise** | Modus | normalerweise, ausnahmsweise, schrittweise |
| **-erweise** | Stufe-Adverb | dummerweise, glücklicherweise, freundlicherweise |
| **-lich** | Adverb-Adjektiv (oft) | absichtlich, wissentlich, neulich |
| **-s** | Adverb (z.T.) | tags, abends, montags, links |

### 3.3 Präfix + Suffix kombinationen (zirkumfix-ähnlich)

| Pattern | Beispiele |
|---|---|
| `Ge- + Stamm + -e` | Gerede, Geschrei, Gesumme, Gedächtnis |
| `un- + Adj. + -bar` | unhaltbar, undenkbar, unbeschreiblich |
| `un- + Subst. + -ig` | (selten produktiv) |

## 4. Konversion (Wechsel der Wortart ohne Affigierung)

### 4.1 Verb → Substantiv

Infinitiv direkt als Substantiv (Genus: **n.**), capitalized:

```
laufen          →  das Laufen          ("die Bewegung des Laufens")
schreiben       →  das Schreiben       ("die Tätigkeit / der Akt des Schreibens")
verstehen       →  das Verstehen       ("die Hermeneutik")
sein            →  das Sein            ("Heideggers zentraler Begriff")
denken          →  das Denken
lesen           →  das Lesen
```

**Hochproduktiv** — jedes Verb kann substantiviert werden.

### 4.2 Adjektiv → Substantiv

Adjektiv direkt als Substantiv, capitalized + dekliniert:

```
gut             →  das Gute, der Gute, die Gute (cf. ANHANG E)
schön           →  das Schöne, die Schöne, der Schöne
fremd           →  der Fremde, die Fremde
deutsch         →  der/die Deutsche, das Deutsche
arbeitslos      →  der/die Arbeitslose
abgeordnet      →  der/die Abgeordnete
```

**Genus**: m./f. für Personen-Bezug, n. für abstrakte/sächliche Bezüge.

### 4.3 Substantiv → Verb (selten)

```
Hammer          →  hämmern (mit Suffix-Zugabe)
Kopf            →  köpfen
Salz            →  salzen
Drücken         →  drücken (kein Konversion; verb. Stamm)
```

**Unproduktiv** ohne Suffix-Hilfe.

### 4.4 Wortart-Wechsel ohne Markierung

```
laut (Adj.) → Laut (Subst.)
schwer (Adj.) → schwer-arbeiten (Adv. → Verb)
über (Präp.) → das Über (Subst., gehoben)
ja (Partikel) → das Ja (Subst.)
```

## 5. Diagnostik-Pipeline für Komposita-Dekomposition

Para Stage 1+ análise de Adorno / Heidegger / Habermas / juristisches DE:

```
1. Identificar Determinatum (último Element) → Genus + Numerus + Hauptbedeutung
2. Decompor da direita para a esquerda em Determinans-Determinatum-Pares:
   Donaudampfschifffahrtsgesellschaftskapitän
   = [[[[[Donau][dampf]][schiff]]fahrts][gesellschaft]s]kapitän
   = "Kapitän der Gesellschaft, die Schiffsfahrt mit Dampfschiffen
      auf der Donau betreibt"
3. Identificar Fugenelemente:
   `-s-`, `-(e)n-`, `-(e)r-`, `-e-`, `-∅-`
4. Identificar Suffixe + ihre Wortart-Resultat:
   `-keit`, `-heit`, `-ung`, `-tum`, etc.
5. Identificar Präfixe + ihre Bedeutung:
   `un-`, `ur-`, `vor-`, etc.
```

### Beispiel: *Selbstverschuldungsdialektik* (gemischt aus Adorno-Tradition)

```
Selbst + verschulden + -ungs + Dialektik
   |        |             |        |
   refl.    Verb          Fuge    Determinatum
   Stamm                  -s-     (f.)

= "Dialektik der Selbstverschuldung"
= dialektisch verstandene Eigenschuld (Aufklärungs-Adornoesch)
```

## 6. Produktivität — produktive vs. unproduktive Patterns

### Hochproduktiv

```
Komposition (Determinativ): unbegrenzt produktiv
Substantivierung von Verben: das Verb-en
Substantivierung von Adjektiven: das/der/die Adj-e
Suffix -ung: nahezu jedem schwachen Verb anhängbar
Suffix -bar: jedem trans. Verb (machbar, hörbar, lesbar)
Suffix -keit (auf -ig/-lich/-bar): produktiv
Präfix un-: jedem Adj. + vielen Subst.
Lehnsuffixe -ieren, -ität, -ismus: für Lehnwortstämme
```

### Mittel-produktiv

```
Suffix -er (Akteur): meist trans. Verben (Schreiber, Lehrer; nicht *Wisser)
Suffix -nis: nur restringiert (Erlebnis, Erkenntnis; nicht *Sehnis)
Diminutiva -chen / -lein: archaisch / idiomatisch
Suffix -tum: produktiv für Klassen-Substantive (Bürgertum, Christentum)
```

### Unproduktiv

```
Possessivkomposita (Bahuvrihi): idiomatisch fixiert
Suffix -sal: gehoben, idiomatisch
Suffix -ling: meist pejorativ-diminutiv
```

## 7. PT-falante-spezifisches

### Häufige Fehler

```
*Lampe von Schreibtisch (PT-Übers.) → Schreibtischlampe (DE-Komposition)
*Tisch zum Schreiben → Schreibtisch
*Information über (...) → Informationsbroschüre / -text / etc.
```

PT-falante adulto resiste à Komposition — produz analytisch. **Stage 1 Aufgabe**: forçar Komposition em todas frases que envolvam Substantiv+Substantiv-Beziehung.

### Strategie

```
1. Dekomposition (Lesen): treinieren ad nauseam.
2. Komposition (Schreiben): forçar; iniciem com 2 Konstituenten,
   após Stage 2 escalar a 3-4.
3. Anki: cards mit 3-4-Konstituent-Komposita aus Adorno / Habermas
   ad nauseam memorisieren.
```
