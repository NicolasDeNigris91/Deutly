## Princípios dos Anhänge

1. **Densidade > prosa.** Anhang é tabela + lista + Beispiele curtos. Prosa explicativa fica em módulo.
2. **Cross-reference back.** Cada Anhang aponta de volta ao módulo de origem (seção específica).
3. **Quellen explícitas.** Cada Anhang lista as fontes canônicas (Eisenberg, Helbig/Buscha, Duden, IDS-Grammis).
4. **Atualizável separadamente.** Anhang pode evoluir em cadência distinta do módulo (correções, exemplos novos) sem risco de regressão pedagógica.
5. **Auswahl, não exhaustividade absoluta.** Anhang cobre o **núcleo operacional** (~80-95% da frequência atestada em DWDS-Kernkorpus); resíduo de 5-20% fica fora — usuário avançado consulta Eisenberg / IDS-Grammis para casos limite.

## Como contribuir com correções a um Anhang

1. **Ortografia / typo simples**: PR direto.
2. **Adição de entry**: PR com justificativa de relevância (Frequenz em DWDS, ou status canônico em fonte primária).
3. **Reorganização estrutural**: Issue + discussão + DECISION-LOG entry antes de PR.
4. **Erro factual** (ex.: Stammform errada): Issue com Beleg de fonte canônica (Duden/Eisenberg/IDS) → PR.
