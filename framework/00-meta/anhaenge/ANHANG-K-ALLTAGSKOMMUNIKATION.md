# ANHANG K — Alltagskommunikation

> Referência consolidada para [01-10 Konversation Stage 1](../../01-fundamente/01-10-konversation.md) + transversal para Trilha G (Auswandern) + Modul 03-04 (Pragmatik).
>
> **Schließt die Konversations-Lücke** des Frameworks: das, was zwischen Adorno-Lektüre und Späti-Konversation in Berlin liegt. **5 Bereiche** mit kanonischen Phrasen + Skripten + Beispiel-Dialogen + Stilstufen-Markierung.
>
> **Dieser Anhang ist nicht-substituierbar durch Markdown allein** — er bereitet *vor*, aber Fluência conversacional verlangt Tandem-Praxis (cf. 01-10) + Immersion (cf. Trilha G).

## Konvention

- **Stilstufe:** `H` höflich-formell / `N` neutro / `I` informal / `J` jugendsprachlich.
- **Beispiel-Dialoge:** A = du / B = Gegenüber. Skripten zum Memorisieren + Variieren.
- **🎧** = Hörbeispiel-Hinweis (cf. AUDIO-VIDEO-CANON für authentische Quellen).

## 1. Telefon-Gespräche

### 1.1 Eröffnung — wie man sich meldet

**Privat (deutsch ungewohnt):**

```
Anrufer:    "Schmidt, guten Tag."         (Standard: Nachname + Begrüßung)
Angerufene: "Hallo, hier ist Müller."     (Antwort: Name nennen)
```

**Geschäftlich:**

```
"Firma Schmidt, Müller, guten Tag."       (Firma + Nachname + Begrüßung)
"Müller-Beratung, hier spricht Schmidt."   (gehoben)
```

**Hinweis:** in DE meldet sich der Angerufene **mit Nachname**, nicht mit "Hallo" wie in PT-BR. Sich nicht zu melden ist als unhöflich empfunden.

### 1.2 Anrufer identifiziert sich

```
"Guten Tag, hier ist [Name]. Könnte ich bitte mit Herrn/Frau X sprechen?"  (H)
"Hallo, hier Müller. Ist Frau Schmidt da?"                                   (N)
"Hi, ich bin's [Name]. Hast du kurz Zeit?"                                  (I)
```

### 1.3 Verbinden / Warten

```
"Einen Moment bitte, ich verbinde Sie."                          (H, Geschäft)
"Bleiben Sie bitte am Apparat."                                  (H)
"Frau Schmidt ist gerade nicht da. Kann ich etwas ausrichten?"   (H)
"Soll ich ihr ausrichten, dass Sie angerufen haben?"             (H)
"Möchten Sie eine Nachricht hinterlassen?"                       (H)
```

### 1.4 Termin vereinbaren

```
A: "Ich hätte gern einen Termin bei Dr. Schmidt."
B: "Wann würde es Ihnen passen?"
A: "Wäre Donnerstag um zehn Uhr möglich?"
B: "Donnerstag zehn Uhr — ja, das geht. Auf welchen Namen darf ich es eintragen?"
A: "Auf [Name]."
B: "In Ordnung. Bis Donnerstag dann."
A: "Vielen Dank. Auf Wiederhören."
```

### 1.5 Verständigungsprobleme

```
"Könnten Sie das bitte wiederholen?"          (H)
"Können Sie bitte etwas langsamer sprechen?"  (H)
"Tut mir leid, ich habe Sie nicht verstanden." (H/N)
"Was haben Sie gesagt?"                       (N)
"Wie bitte?"                                  (N — Frage-Standardform)
"Hä?"                                          (I — sehr informal, riskant!)
```

### 1.6 Verabschiedung am Telefon

```
"Auf Wiederhören."                            (H — Standard Telefon)
"Tschüs / Tschüss."                           (I)
"Wir hören uns."                              (I)
"Bis dann!"                                   (I)
"Mach's gut."                                 (I)
```

### 1.7 Beispiel-Dialog vollständig

```
B: "Praxis Dr. Schmidt, Schneider, guten Tag."
A: "Guten Tag, hier ist [Müller]. Ich hätte gerne einen Termin."
B: "Ja, was ist denn der Anlass?"
A: "Ich habe seit ein paar Tagen Halsschmerzen."
B: "Mhm. Sind Sie schon Patient bei uns?"
A: "Nein, ich war noch nicht da."
B: "Dann brauche ich erst einmal Ihre Versicherungskarte. Können Sie 
   morgen früh um neun vorbeikommen, dann legen wir die Akte an?"
A: "Morgen neun Uhr — ja, das passt."
B: "Ihre Versichertennummer haben Sie zur Hand?"
A: "Einen Moment... ja, [Nummer]."
B: "In Ordnung. Bis morgen dann, Herr Müller."
A: "Vielen Dank. Auf Wiederhören."
B: "Auf Wiederhören."
```

## 2. Service-Interaktion

### 2.1 Restaurant

#### Eröffnung

```
Kellner:  "Guten Abend, haben Sie reserviert?"
Gast:     "Nein, einen Tisch für zwei bitte."
Kellner:  "Innen oder außen?"
Gast:     "Außen, bitte."
Kellner:  "Folgen Sie mir bitte."
```

#### Bestellung

```
Kellner:  "Was möchten Sie trinken?"
Gast:     "Ich hätte gern ein großes Bier."                      (H/N)
Gast:     "Für mich bitte ein Wasser ohne Kohlensäure / mit Kohlensäure / Sprudel."
Gast:     "Ein Pils vom Fass, bitte."

Kellner:  "Haben Sie schon gewählt?"  (= sind Sie schon mit der Speisekarte fertig?)
Gast:     "Ich nehme das Schnitzel mit Pommes, bitte."
Gast:     "Ich hätte gern die Suppe als Vorspeise und dann den Rinderbraten."
Gast:     "Kann ich die Pasta auch ohne Pilze bekommen?"
Gast:     "Was würden Sie heute empfehlen?"

Kellner:  "Wie hätten Sie das Steak?"
Gast:     "Medium / Medium-rare / Englisch / Durchgebraten / Well done."
```

#### Beim Essen

```
Kellner:  "Hat es Ihnen geschmeckt?"
Gast:     "Ja, sehr gut, danke."
Gast:     "Hervorragend!"

Kellner:  "Möchten Sie noch eine Nachspeise?"
Gast:     "Ja, was haben Sie zur Auswahl?"
Gast:     "Nein, danke. Bringen Sie mir bitte die Rechnung."
```

#### Bezahlung

```
Gast:     "Die Rechnung bitte."  ODER  "Zahlen, bitte."
Kellner:  "Zusammen oder getrennt?"
Gast:     "Zusammen, bitte."
Gast:     "Getrennt, bitte."

Kellner:  "Das macht 47,80 Euro."
Gast:     "50 Euro, stimmt so."  (Trinkgeld inkludiert; 4-5% ist üblich)
Gast:     "Machen Sie 52 Euro daraus."  (52€ inklusive Trinkgeld)
```

#### Trinkgeld-Konvention DE

```
- 5-10% Trinkgeld bei guter Bedienung Standard.
- Im Bargeld zahlen: dem Kellner sagen, was zu kassieren ist 
  (incl. Trinkgeld), Wechselgeld nicht zurück nehmen.
- Mit Karte zahlen: bei der Karte sagen "55 Euro" (statt 52,80) 
  → Trinkgeld inkludiert.
- "Stimmt so" = Wechselgeld als Trinkgeld behalten.
- Kein Trinkgeld bei Selbstbedienung / Imbiss.
```

### 2.2 Einkaufen (Geschäft / Supermarkt)

#### Beratung suchen

```
Kunde:    "Entschuldigung, können Sie mir helfen?"
Verkäufer: "Ja, was suchen Sie?"
Kunde:    "Ich suche [Artikel] in Größe [...]."
Kunde:    "Haben Sie das auch in Blau?"
Kunde:    "Wo finde ich [Artikel]?"
Kunde:    "Können Sie mir das vorführen?"
```

#### Anprobe

```
"Kann ich das anprobieren?"
"Haben Sie Umkleidekabinen?"
"Es passt nicht — haben Sie eine größere / kleinere Größe?"
"Es ist mir zu eng / zu weit."
```

#### Bezahlung

```
Kassierer: "Möchten Sie eine Tüte?"            (oft kostenpflichtig in DE)
Kunde:    "Ja, eine Tüte bitte."
Kunde:    "Nein, danke, ich habe selbst eine."
Kassierer: "Bar oder mit Karte?"
Kunde:    "Mit Karte, bitte."
Kunde:    "Bar."

Kunde:    "Haben Sie es auch kleiner?" (= passendere Banknote)
Kassierer: "Bitte schön, hier ist Ihre Quittung."
Kunde:    "Schönen Tag noch."
```

### 2.3 Arzt

#### Anmeldung

```
Patient:  "Guten Tag, mein Name ist [Müller]. Ich habe einen Termin um 10 Uhr 
          bei Dr. Schmidt."
Empfangs- "Guten Tag. Ihre Versicherungskarte bitte."
mitarb.:  "Bitte setzen Sie sich, Sie werden gleich aufgerufen."

Patient:  "Wo ist hier das Wartezimmer?"
Patient:  "Wie lange dauert das ungefähr?"
```

#### Beim Arzt

```
Arzt:     "Was kann ich für Sie tun? / Was führt Sie zu mir?"
Patient:  "Ich habe seit drei Tagen [Symptom]."
Patient:  "Mir ist schlecht / schwindelig / übel."
Patient:  "Ich habe Schmerzen [Lokalisation]: Kopfschmerzen, Bauchschmerzen, 
          Rückenschmerzen, Halsschmerzen, Zahnschmerzen."
Patient:  "Es tut weh, wenn ich [Bewegung] mache."
Patient:  "Ich habe Fieber: 38,5 Grad."
Patient:  "Ich kann nicht richtig schlafen."

Arzt:     "Seit wann haben Sie das?"
Arzt:     "Wo genau tut es weh?"
Arzt:     "Strahlt der Schmerz aus?"
Arzt:     "Atmen Sie tief ein und aus."
Arzt:     "Machen Sie sich frei bis zur Hüfte."
Arzt:     "Nehmen Sie Medikamente?"
Arzt:     "Sind Sie gegen etwas allergisch?"
```

#### Diagnose + Rezept

```
Arzt:     "Ich verschreibe Ihnen [Medikament]. Nehmen Sie es 
          dreimal täglich nach den Mahlzeiten."
Arzt:     "Ich schreibe Sie für eine Woche krank."             (Krankschreibung!)
Arzt:     "Sie sollten viel trinken und sich schonen."
Arzt:     "Wenn es schlimmer wird, kommen Sie sofort wieder."

Patient:  "Brauche ich eine Krankschreibung?"
Patient:  "Wie lange muss ich das nehmen?"
Patient:  "Hat das Nebenwirkungen?"
Patient:  "Wann soll ich wiederkommen?"
```

#### Apotheke

```
Apotheker: "Was darf es sein?"
Kunde:    "Ich hätte gerne [Medikament]."
Kunde:    "Hier ist mein Rezept."
Apotheker: "Möchten Sie das günstigste Generikum?"  (für gesetzliche Krankenkasse)
Apotheker: "Das macht zusammen [...] Euro."
Apotheker: "Nehmen Sie eine Tablette dreimal täglich."
```

### 2.4 Friseur

```
Friseur:  "Was darf's sein?"
Kunde:    "Schneiden, bitte."
Kunde:    "Schneiden und föhnen."
Kunde:    "Ich hätte gerne nur die Spitzen geschnitten."
Kunde:    "Bitte etwa zwei Zentimeter abschneiden."
Kunde:    "An den Seiten kürzer, oben länger."
Kunde:    "Ich hätte gerne einen Pony." (= franja em PT)
Kunde:    "Bitte nicht zu kurz."
Kunde:    "Färben, bitte. Die Farbe wie auf diesem Foto."
```

### 2.5 Bank / Geld

```
Kunde:    "Ich möchte ein Konto eröffnen."
Kunde:    "Ich möchte Geld abheben."
Kunde:    "Wo ist hier ein Geldautomat?"
Kunde:    "Ich habe meine EC-Karte verloren / vergessen."
Kunde:    "Ich möchte eine Überweisung tätigen."
Kunde:    "Welcher Wechselkurs ist heute?"
Kunde:    "Wie hoch sind die Kontoführungsgebühren?"
```

## 3. Small Talk

### 3.1 Begrüßung + Eröffnung

```
H/N: "Guten Tag." / "Guten Morgen." / "Guten Abend." / "Hallo!"
H:   "Wie geht es Ihnen?"
N:   "Wie geht's?"
I:   "Was geht?" (jugendsprachlich, 20-30er)

Antwort:
H:   "Danke, gut. Und Ihnen?"
N:   "Danke, gut. Und dir?"
I:   "Geht so." / "Naja, geht."  (zurückhaltend ehrlich)
I:   "Top!" / "Bombe!"  (sehr positiv)
```

### 3.2 Wetter (DE-Klassiker)

```
"Schönes Wetter heute!"
"Ja, endlich wieder Sonnenschein."
"Hoffentlich bleibt das so."
"Ja, aber für morgen ist Regen angesagt."

"Was für ein Sauwetter!"  (negativ — Schimpfwort-Element "Sau-")
"Ist das ein Mistwetter heute!"
"Mir ist schon ganz kalt."
"Zieh dich warm an, draußen schneit es."
```

### 3.3 Wochenende / Freizeit

```
"Was machst du am Wochenende?"
"Hast du was Schönes vor?"

"Ich bleibe einfach zu Hause."
"Wir fahren nach Berlin."
"Ich treffe Freunde zum Brunchen."
"Ich gehe ins Kino."
"Wir machen einen Ausflug ins Grüne."
"Eigentlich nichts Besonderes."
```

### 3.4 Sport

```
"Treibst du Sport?"
"Spielst du Fußball?"
"Gehst du oft ins Fitnessstudio?"

"Ich gehe zweimal die Woche joggen."
"Wir spielen jeden Samstag Fußball."
"Mit dem Sport hapert's bei mir."
"Letzte Woche habe ich angefangen Yoga zu machen."
```

### 3.5 Familie

```
"Hast du Geschwister?"
"Sind deine Eltern auch in Deutschland?"
"Hast du Kinder?"
"Wie heißt deine Frau / dein Mann?"

"Ich habe eine Schwester und einen Bruder."
"Wir leben in Brasilien, aber ich bin schon seit drei Jahren hier."
"Nein, ich habe keine Kinder."  (in DE oft direkter Frage; antworten OK)
```

### 3.6 Beruf

```
"Was machst du beruflich?"
"In welcher Branche arbeitest du?"
"Wie lange machst du das schon?"

"Ich bin Lehrer / Ingenieur / Arzt."
"Ich arbeite als Software-Entwickler in einer Berliner Firma."
"Ich studiere noch — Germanistik im fünften Semester."
"Ich bin gerade arbeitssuchend."
```

### 3.7 Kultur / Freizeit

```
"Liest du gerne?"
"Was für Filme magst du?"
"Hörst du Musik? Welche?"
"Gehst du oft ins Theater?"

"Ich lese gerade ein Buch von Bernhard Schlink."
"Tatort gucke ich jeden Sonntag — das ist Tradition."
"Ich höre vor allem Klassik. Mahler, Brahms."
"Im Theater war ich seit einer Ewigkeit nicht mehr."
```

### 3.8 Themen vermeiden in Small Talk

```
DE-Konvention (anders als PT-BR):
- Politische Meinung NUR wenn man sich gut kennt.
- Religion ähnlich.
- Geld / Gehalt ist sehr privat (PT-BR offener).
- Krankheiten erst nach engerer Bekanntschaft.
- Persönliche Sorgen NUR mit Freunden, nicht mit Bekannten.
```

## 4. Behörden

### 4.1 Einwohnermeldeamt — Anmeldung

(Pflicht für jeden, der > 3 Monate in DE wohnt — Anmeldung innerhalb 14 Tage nach Einzug.)

```
Beamter:  "Guten Tag. Was kann ich für Sie tun?"
Sie:      "Ich möchte mich anmelden. Ich bin neu in [Stadt]."
Beamter:  "Haben Sie Ihren Pass und die Wohnungsgeberbestätigung dabei?"
Sie:      "Ja, hier sind beide Dokumente."

Beamter:  "Wie lange werden Sie hier wohnen?"
Beamter:  "Sind Sie verheiratet? Haben Sie Kinder?"
Beamter:  "Hier ist Ihre Anmeldebestätigung. Bewahren Sie sie gut auf."

Sie:      "Wann muss ich mich beim Bürgeramt wieder melden?"
Sie:      "Wo bekomme ich eine Steueridentifikationsnummer?"
```

#### Documentos necessários (typisch)

```
- Reisepass / Personalausweis (für EU-Bürger).
- Wohnungsgeberbestätigung (Vermieter füllt aus, unterschreibt).
- Anmeldeformular (Bürgeramt-Website downloadbar).
- Eheurkunde, Geburtsurkunden der Kinder (falls anwesend).
```

### 4.2 Aufenthaltstitel (für Nicht-EU-Bürger)

```
Sie:      "Ich möchte einen Aufenthaltstitel beantragen."
Beamter:  "Welcher Aufenthaltsgrund?"
Sie:      "Ich habe einen Arbeitsvertrag." / "Ich möchte hier studieren." 
          / "Ich bin verheiratet mit einer EU-Bürgerin."

Beamter:  "Bringen Sie bitte folgende Unterlagen mit:
           - Reisepass
           - Arbeitsvertrag / Hochschulzulassung
           - Krankenversicherungs-Nachweis  
           - Mietvertrag / Anmeldebescheinigung
           - Lebenslauf
           - Finanzierungsnachweis (Sperrkonto / Stipendium)"
```

### 4.3 Krankenversicherung

```
Sie:      "Ich möchte mich gesetzlich versichern."
Berater:  "Sind Sie angestellt oder selbstständig?"
Sie:      "Angestellt bei [Firma]."
Berater:  "Dann werden die Beiträge automatisch vom Gehalt abgezogen.
           Welche Krankenkasse möchten Sie? Wir haben Standard-Sätze."

Sie:      "Was ist der Unterschied zwischen gesetzlich und privat?"
Sie:      "Welche Leistungen sind alle inkludiert?"
Sie:      "Brauche ich eine Zusatzversicherung?"
```

### 4.4 Steuern

```
Sie:      "Ich möchte meine Steuererklärung abgeben."
Beamter:  "Online über ELSTER oder per Papier?"

Sie:      "Was kann ich von der Steuer absetzen?"
Sie:      "Wo bekomme ich meine Lohnsteuerbescheinigung?"
Sie:      "Welche Steuerklasse habe ich?"
```

#### Steuerklassen (für Anfänger)

```
- Klasse I:    Ledig.
- Klasse II:   Alleinerziehend.
- Klasse III:  Verheiratet, höher verdienender Partner.
- Klasse IV:   Verheiratet, beide ähnlich verdienend.
- Klasse V:    Verheiratet, weniger verdienender Partner (Komplement zu III).
- Klasse VI:   Zweiter Job (Steuerklasse für Nebenjob).
```

### 4.5 Ausländerbehörde — typische Phrasen

```
"Ich möchte einen Termin vereinbaren."
"Ich brauche eine Verlängerung meines Aufenthaltstitels."
"Wo bekomme ich die Formulare?"
"Welche Unterlagen muss ich mitbringen?"
"Wie lange dauert die Bearbeitung?"
"Kann ich den Termin verschieben?"
```

## 5. Notfälle

### 5.1 Notrufnummern

```
110 — Polizei
112 — Feuerwehr / Rettungsdienst
116 117 — Ärztlicher Bereitschaftsdienst (außerhalb der Sprechzeiten)
116 116 — Sperrnotruf für gestohlene EC-/Kreditkarten
115 — Behördennummer (allgemeine Behörden-Auskunft)
```

### 5.2 Polizei-Anruf (110)

```
Polizei:  "Notruf, Polizei. Wo ist der Notfall?"
Sie:      "Ich bin in [Adresse] in [Stadt]. Es gab einen Einbruch / 
          einen Unfall / einen Diebstahl."
Polizei:  "Was ist passiert? Sind Verletzte zu beklagen?"
Sie:      "[Beschreibung]. Es gibt [keine] Verletzten."
Polizei:  "Bleiben Sie am Telefon. Wir sind gleich da."
```

#### Wichtige Phrasen

```
"Hilfe!"  (= Help!)
"Ich brauche Hilfe!"
"Es gab einen Unfall."
"Jemand ist verletzt."
"Ich wurde überfallen."
"Mein Geldbeutel wurde gestohlen."
"Mein Auto wurde aufgebrochen."
"Es brennt!"
"Wir brauchen einen Krankenwagen."
```

### 5.3 Krankenhaus / Rettungsdienst (112)

```
Sanitäter: "Notruf, Rettungsleitstelle."
Sie:       "Hallo, ich brauche einen Krankenwagen. 
           Ich bin in [Adresse] in [Stadt]."
Sanitäter: "Was ist passiert?"
Sie:       "Mein Mann hat plötzlich Brustschmerzen / hat das Bewusstsein 
           verloren / ist gestürzt und blutet."
Sanitäter: "Bleiben Sie am Telefon. Sind Sie erreichbar unter dieser Nummer?"
Sie:       "Ja."
Sanitäter: "Wir kommen sofort. Bitte gehen Sie ans Auto, um uns Einweisung 
           zu geben."
```

### 5.4 Verloren / Diebstahl

```
"Ich habe meinen Pass / meine Bankkarte / mein Handy verloren."
"Mein Geldbeutel wurde gestohlen."
"Ich möchte den Verlust melden."
"Wo kann ich Anzeige erstatten?"
"Ich brauche eine Verlustanzeige."
```

### 5.5 Auto / Verkehr

```
"Mein Auto springt nicht an."
"Ich habe eine Panne."
"Ich brauche einen Abschleppdienst."
"Mein Autoschlüssel ist im Auto eingeschlossen."
"Es gab einen Unfall."  (= acidente)
```

### 5.6 Versicherung melden

```
"Ich möchte einen Schaden melden."
"Es ist ein Unfall passiert. Ich brauche die Versicherung."
"Hier ist meine Police-Nummer."
"Wann kommt der Gutachter?"
```

## 6. Routineformeln gehoben + neutral + informal — Vergleich

### Begrüßung

| Stilstufe | Form |
|---|---|
| H | Sehr geehrte Damen und Herren |
| H | Guten Tag, [Frau/Herr Nachname] |
| N | Guten Tag |
| N | Hallo |
| I | Hi / Servus / Moin |

### Verabschiedung

| Stilstufe | Form |
|---|---|
| H | Mit freundlichen Grüßen / Hochachtungsvoll (E-Mail) |
| H | Auf Wiedersehen (Person) / Auf Wiederhören (Telefon) |
| N | Tschüs / Tschüss |
| I | Mach's gut / Bis dann / Bis später |
| I | Tschö / Tschüssi (norddeutsch) |

### Bitte / Danke

| Stilstufe | Form |
|---|---|
| H | Wenn Sie so freundlich wären / Mit Ihrer Erlaubnis |
| H | Würden Sie bitte... |
| N | Bitte / Bitte schön / Vielen Dank |
| N | Können Sie bitte... |
| I | Kannste mal / Geht das? / Cool, danke! |

### Entschuldigung

| Stilstufe | Form |
|---|---|
| H | Verzeihen Sie bitte / Es tut mir leid |
| N | Entschuldigung / Tut mir leid |
| I | Sorry / Tschuldigung |
