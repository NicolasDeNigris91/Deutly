# ANHANG L — Dialekte + Soziolekte

> Referência consolidada para [04-03 Variationslinguistik](../../04-system/04-03-variationslinguistik.md) + [03-02 Register](../../03-stil/03-02-register.md) + Modul 03-10 (Hörverstehen colloquial).
>
> **Schließt die Variations-Lücke** des Frameworks: das, was zwischen Hochsprache (das Framework lehrt) und gelebter regionaler/sozialer DE-Realität liegt. **Sechs Dialekte** + **drei Soziolekte** mit kanonischen Phrasen + Lautmerkmalen + Hörbeispielen + Wortlisten.
>
> **Wichtig:** Lerner muss nicht alle Dialekte aktiv produzieren. Ziel: **passives Hörverstehen** + Identifikation regionaler Färbungen + Vermeidung von Missverständnissen.

---

## 1. Plurizentrik DE/AT/CH — Übersicht

DE ist *plurizentrische* Sprache mit drei Vollzentren:

```
Bundesdeutsch (DE):    Hauptzentrum; ~83 Mio. Sprecher.
Österreichisches DE:   Wiener Norm + regionale Varianten; ~9 Mio. Sprecher.
Schweizer DE:          Schwyzerdütsch (mündlich) + Schweizer Hochdeutsch (schriftlich); ~5 Mio.
```

Plus regionale Färbungen innerhalb der drei Zentren — die wichtigsten unten.

## 2. Berlinerisch (Berlin + Brandenburg)

### 2.1 Lautliche Eigenheiten

```
- /g/ → /j/:           "ne jute Idee" (eine gute Idee), "ick jeh" (ich gehe)
- /ich/ → /ick/:       "ick" (ich), "icke" (Verstärkung)
- /das/ → /det/:       "det jeht" (das geht), "det is wat" (das ist was)
- /was/ → /wat/:       "wat is los?" (was ist los?), "wat'n?" (was denn?)
- Konsonanten-Verkürzung: "isses" (ist es), "wars" (war es)
- /au/ → /oo/:         "ooch" (auch), "oogen" (Augen)
```

### 2.2 Lexikalische Eigenheiten

```
Späti                 = Spätkauf (Kiosk-Geschäft)
Dit                   = das (Demonstrativ)
ick / icke            = ich (Personalpronomen)
nu / nö               = nun / nein  
jut / jute            = gut / gute
wat / det / dit        = was / das / das
Bulle                 = Polizist (pejorativ; auch andere Regionen)
Schrippe              = Brötchen (= "pãozinho"; im Süden "Semmel")
Stulle                = belegtes Brot
Kiez                  = Stadtviertel (mit Berliner Konnotation)
```

### 2.3 Klassische Phrasen

```
"Wat'n det?"                          = Was ist das?
"Ick liebe dir!"                      = Ich liebe dich!  
                                        (klassisch — Akk./Dat.-Konfusion 
                                         in Berlinerisch normal!)
"Berliner Schnauze"                   = ruder, direkter Tonfall
"Watt brauchste?"                     = Was brauchst du?
"Det jeht jut."                       = Das geht gut.
"Hamse mal ne Mark?"                  = Haben Sie mal eine Mark? 
                                        (alt-Berlin, vor Euro)
"Ick globs nich."                     = Ich glaube es nicht.
"Wa! Det iss'n Ding!"                 = Wow! Das ist was Besonderes!
```

### 2.4 Beispiel-Dialog (Berliner Späti)

```
Verkäufer: "Wat brauchste?"
Kunde:    "Ick hätt jerne 'n Bier und ne Schrippe."
Verkäufer: "Welch Bier? Pils, Hefeweizen, oder wat?"
Kunde:    "Pils, klein."
Verkäufer: "Macht zwei fuffzig."
Kunde:    "Hier biste."
Verkäufer: "Schön'n Tach noch."
```

### 2.5 🎧 Hörbeispiele

- **Tatort Berlin** (Abschnitte mit nicht-Profi-Sprechern, e.g., Zeugen-Befragungen).
- **Berlin — Tag und Nacht** (RTL II Soap; sehr berlinerisch markiert).
- **Babylon Berlin** (Serie 2017-): historisches Berlinerisch der 1920er.
- **YouTube-Kanal "Berliner Pflanze"** für authentic Berlinerisch.
- **Wikipedia: Berlinerisch** für phonetische Übersicht.

### 2.6 Diagnostik für Lerner

```
Wenn jemand "ick", "wat", "det" sagt → wahrscheinlich Berlin/Brandenburg.
Wenn /g/ als /j/ realisiert → fast sicher Berlinerisch.
Berliner verwenden oft Dat./Akk. inkonsistent ("ick liebe dir" — Standard wäre 
"ich liebe dich"). NICHT als Modell übernehmen!
```

## 3. Bayrisch (Bayern + tlw. Sachsen)

### 3.1 Lautliche Eigenheiten

```
- /a/ → /o/:           "i bin oa Bayer" (ich bin ein Bayer)
- /-er/ → /-a/:         "der Bauer" → "dea Baua"
- /st/ → /scht/:        "des Häusla is jut" (das Häuschen ist gut)
- Doppelnegation:       "Des kannst niet net machn"  (das kannst du nicht nicht machen 
                         = das kannst du auf keinen Fall machen)
- Diminutiv mit -erl:   "Bierla / Wirsherl / Sackerl"
- /ein/ → /a/:           "kein" → "koa", "ein" → "a", "mein" → "mei"
```

### 3.2 Lexikalische Eigenheiten

```
Servus                 = Hallo (Begrüßung) / Tschüs (Verabschiedung); auch 
                         österr.
Pfiat di / Pfiad di    = Tschüs (Dat./Akk.); kontrahiert von "Behüte Dich Gott"
Grüß Gott              = höfliche Begrüßung (auch bei Atheisten Standard!)
Brezn                  = Brezel
Semmel                 = Brötchen (≠ Berlin "Schrippe")
Wirtshaus / Beisl       = Restaurant, Kneipe
Maß                     = 1-Liter-Bierkrug (Oktoberfest-Standard)
fei                     = Modalpartikel ("freilich, schon"; sehr bayrisch)
gell?                   = "stimmt's? / nicht wahr?" (Frage-Endpartikel; auch 
                         schwäbisch + österr.)
des / dees              = das
Bub                     = Junge (norddt.: "Junge")
Madl                    = Mädchen
Bua                     = Junge (Diminutiv → Buberl)
```

### 3.3 Klassische Phrasen

```
"Servus!"                              = Hallo!
"Grüß Gott."                           = Höflicher Gruß.
"Pfiat di / Pfiat Gott!"               = Tschüs!
"Bayern is fei a schöns Land, gell?"   = Bayern ist wirklich ein schönes Land, 
                                          nicht wahr?
"I mog di."                             = Ich mag dich. (mit "moo-g")
"Des is doch koa Problem net!"         = Das ist doch kein Problem!
"Servus mit oa Maß!"                   = Hallo, mit einer Maß Bier!
"Hawitschl mei!"                        = "Au weh!" (Schreckens-Ausruf)
```

### 3.4 Beispiel-Dialog (München, Wirtshaus)

```
Wirtin:   "Servus! Was darf's denn sein?"
Gast:     "Ein Helles bitte und a Brez'n."
Wirtin:   "A Maß oder a Halbe?"
Gast:     "Eine Halbe reicht."
Wirtin:   "Kommt sofort."
[später]
Wirtin:   "Schmeckt's?"
Gast:     "Wunderbar! Wo kommt das Bier eigentlich her?"
Wirtin:   "Aus Augsburg, eigene Brauerei."
Gast:     "Pfiat di! Bis bald."
```

### 3.5 🎧 Hörbeispiele

- **Tatort München / Tatort Bayern** (jeweils mit bayrischer Sprache markiert).
- **Eberhofer-Krimis** (Filme; bayrisch-volkstümlich).
- **YouTube "Eberhofer Bayern"** + diverse bayrische Komiker (z.B. Maxi Schafroth).
- **Bayerischer Rundfunk Mediathek** — Volksmusik-Sendungen.
- **Hörbuch: Markus Söder "Mei Bayern"** (CDU-Politiker, bayrisch markiert).

## 4. Wienerisch (Wien + Niederösterreich)

### 4.1 Lautliche Eigenheiten

```
- /a/ → /o/:            "i bin a Weana" (ich bin ein Wiener)
- L-Vokalisierung:      "vüü" (viel), "Foid" (Feld)
- /-en/ → /-an/ oder /-n/: "ich gehen" → "I geh"
- Besonderheit: "Wiener Schmäh" — sarkastische, charmante Ausdrucksweise
- Endkonsonanten weicher: /t/ → /d/: "Saud" (Saat)
```

### 4.2 Lexikalische Eigenheiten — typisch österreichisch

```
oida / olda            = "Mensch" / "Alter" (sehr informal; jugendsprachlich)
                          [Achtung: oida hat in WIENERISCH viele Funktionen — 
                           Anrede, Verstärker, Frage, Erstaunen]
leiwand                = super, klasse (Adjektiv)
geil                   = super (Jugendsprache, beide Länder)
deppat                 = blöd, dumm
Beisl                  = Kneipe (≠ "Wirtshaus" baierisch)
Gschropp               = junges Kind  
Nockerl                = Knödel-Variante
Eitrige                = Wiener Frankfurter Wurst
Fiaker                 = Pferdekutsche (Wien-Tradition)
Heuriger               = Wein-Lokal (Wein-Region Wien)
Sackerl                = Beutel, Tüte (≠ "Tüte")
Marille               = Aprikose (≠ DE "Aprikose")
Paradeiser             = Tomate (≠ DE "Tomate")
Erdäpfel               = Kartoffeln (≠ DE "Kartoffeln")
Karfiol                = Blumenkohl
```

### 4.3 Klassische Phrasen — Wiener Schmäh

```
"Servus!"                              = Hallo (auch dort)
"Grüß Gott."                            = höflich
"Servas, oida!"                         = Hallo, Alter! (Jugendsprache)
"Geh, lass mi in Ruh!"                  = Lass mich in Ruhe! 
                                          (mit charakteristischem Tonfall)
"Schau, dass du weiterkommst!"          = Verschwinde!
"Des is leiwand!"                       = Das ist super!
"Es geht eh."                           = Es geht schon. (Resignation)
"Na geh!"                               = "Komm schon!" (Erstaunen oder Drängen)
"Wos host gsogt?"                       = Was hast du gesagt?
```

### 4.4 Beispiel-Dialog (Wiener Beisl)

```
Wirt:     "Servas. Wos darfs sein?"
Gast:     "Ein Achtel Roten, bitte. Und eine Eitrige."
Wirt:     "Mit Senf und Krenn?"
Gast:     "Beides, danke."
[...]
Gast:     "Zahln, bitte!"
Wirt:     "Macht zwölf-fünfzig."
Gast:     "Hier — und stimmt so."
Wirt:     "Vergelts Gott."
Gast:     "Servus, oida!"
```

### 4.5 🎧 Hörbeispiele

- **Tatort Wien** (= "Tatort: Wien"; mit Wiener Schmäh).
- **Filme von Michael Haneke** in Wien (z.B. *Das weiße Band*).
- **Helmut Qualtinger** — *Der Herr Karl* (Wiener-Klassiker).
- **YouTube "Wiener Dialekt"** — Tausende Videos.
- **Falco** — Songs auf Wienerisch (*Der Kommissar*, *Rock Me Amadeus*).
- **Ostbahn-Kurti** — Liedermacher mit starkem Wienerisch.

## 5. Schweizerdeutsch (Schweiz, deutsche Schweiz)

### 5.1 Strukturelle Eigenheit

**Schweizerdeutsch ist NICHT identisch mit Schweizer Hochdeutsch.** Diglossie:

```
Schweizerdeutsch (Schwyzerdütsch):
  - Gesprochene Sprache (alltäglich, in TV-/Radio-Talkshows, in der Familie).
  - KEINE einheitliche Schreibweise.
  - Stark dialektisch (von Region zu Region unterschiedlich).
  - Lerner mit Standard-DE versteht es zu ~50-70%.

Schweizer Hochdeutsch:
  - Geschriebene Standardsprache (Bücher, Zeitungen, offizielle Dokumente).
  - Sehr nah an Bundesdeutsch.
  - Ein paar lexikalische Unterschiede ("Velo" = Fahrrad; "Tram" = Straßenbahn).
  - In offiziellem Sprechen (Tagesschau Schweizer Radio + Fernsehen) verwendet.
```

### 5.2 Lautliche Eigenheiten Schwyzerdütsch

```
- /k/ → /ch/ (am Wortanfang):  "Kind" → "Chind", "klein" → "chli"
- /s/ → /sh/:                  "Stein" → "Schtai"
- /ei/ → /ai/:                 "ein" → "ai", "klein" → "chli"
- Diminutiv -li statt -chen:    "Briefli" (Briefchen), "Hösli" (Höschen)
- Hauchige Konsonanten:         viele Affrikate (kch, pf)
- Vokal-Längen flexibler:       "Boue" (Bauer), "Frou" (Frau)
```

### 5.3 Lexikalische Eigenheiten

```
Schwyzerdütsch / Schweizer Hochdeutsch / Bundesdeutsch:

grüezi              = Guten Tag (Standardgruß CH)         |   Guten Tag       |   Guten Tag
merci               = Danke                                 |   merci/danke    |   danke (DE: "merci" wirkt französisch)
salü                = Hallo (informal)                      |   Hallo          |   Hallo
Velo                = Fahrrad                               |   Velo           |   Fahrrad
Tram                = Straßenbahn                           |   Tram           |   Straßenbahn (auch Tram in DE)
Zmorge              = Frühstück                             |   Frühstück      |   Frühstück
Znüni               = Vormittagspause                       |   Znüni          |   Vormittagspause
Zmittag             = Mittagessen                           |   Mittagessen    |   Mittagessen
Zvieri              = Nachmittagsjause                      |   Zvieri          |   Nachmittagsjause (=Nachmittagskaffee)
Znacht              = Abendessen                            |   Abendessen     |   Abendessen
Coiffeur            = Friseur (frz. Lehnwort, in CH 
                       häufig)                              |   Coiffeur        |   Friseur
Trottoir            = Gehweg, Bürgersteig                   |   Trottoir       |   Gehweg / Bürgersteig
Billet              = Fahrkarte (Französische Form)         |   Billet          |   Fahrkarte
```

### 5.4 Klassische Phrasen

```
"Grüezi!"                              = Hallo (Standard CH).
"Merci viu mau."                       = Vielen Dank. (= Merci vielmals)
"Es het mir gfreut."                   = Es hat mich gefreut.
"Säg mau!"                             = Sag mal!
"Wie gohts?"                            = Wie geht's?
"Mir gohts guet, danke."                = Mir geht's gut, danke.
"Tschüss / Adieu / Salü!"              = Tschüs! (Verabschiedung)
"Tschauääsi!"                           = Tschüs! (sehr informal)
```

### 5.5 Beispiel-Dialog (Zürich, Bäckerei)

```
Verkäuferin: "Grüezi! Was darfs sii?"
Kunde:      "Es Brötli und e Gipfeli, bitte."
Verkäuferin: "Welches Brötli? Mir hend Bürli, Schoggibrötli und Käsbrötli."
Kunde:      "Es Bürli."
Verkäuferin: "Macht zwei Franken zwanzig."
Kunde:      "Hier biete'sich..."
Verkäuferin: "Merci, e schöne Tag wunschi."
Kunde:      "Adieu!"
```

(Translation: "Grüezi! Was darfs sii?" = Hallo! Was darfs sein? — Bürli = kleines Brötchen, Gipfeli = Croissant)

### 5.6 🎧 Hörbeispiele

- **Schweizer Radio und Fernsehen (SRF)** — Mediathek; "Tagesschau" auf Schweizer Hochdeutsch.
- **Talksendungen auf SRF** wie "Schawinski" — Schwyzerdütsch.
- **Schweizer Filme** — *Heidi* (Klassiker, Schweizerdeutsch markiert), *Achtung, fertig, Charlie!*.
- **YouTube-Kanal "Schweizer Dialekte"** — Übersicht über regionale Variationen.
- **Schweizer Pop / Mundart-Rock** — Mani Matter, Stiller Has, Lovebugs.

### 5.7 Hinweis für Lerner

```
Beim Reisen in der Schweiz:
- Schweizer verstehen Standard-DE (Bundesdeutsch) zu 100%.
- Sie sprechen aber im Alltag Schwyzerdütsch.
- Wenn man höflich Standard-DE spricht, antworten viele Schweizer 
  in Schweizer Hochdeutsch — manche jedoch in Schwyzerdütsch.
- "Können Sie bitte etwas langsamer sprechen?" ist akzeptabel und üblich.
- KEINE Erwartung, dass Lerner Schwyzerdütsch lernt — passive Verständnis 
  ist Ziel.
```

## 6. Plattdeutsch (Norddeutschland)

### 6.1 Status

Plattdeutsch ist **eigene Sprache** (nicht nur Dialekt), gesprochen vor allem in Hamburg, Bremen, Schleswig-Holstein, Niedersachsen, Mecklenburg-Vorpommern. Heute weitgehend von Hochdeutsch verdrängt; aber alltagsfärbend.

### 6.2 Charakteristische Merkmale

```
- /k/ → /k/ (NICHT /ch/ wie Schwyzerdütsch): "Kind" bleibt "Kind"
- /p/ → /p/ (NICHT /pf/ wie Bayrisch): "Apfel" → "Appel"
- /t/ → /t/ (NICHT /ts/): "Wasser" → "Water"
- "ick" für "ich" (wie Berlinerisch)
- Prätérito-Bewahrung stärker als im Süden
```

### 6.3 Wenige typische Wörter

```
Moin                  = Hallo (Standardgruß Norddeutschland; 
                         im NORDEN den ganzen Tag)
Tschüss               = Tschüs (Hauptverabschiedung)
Spitze!               = Super!
Schnack               = Geschwätz, Plauderei
büschen               = ein bisschen
ne / nö               = nein (nordddt.)
Plattdeutsch / Platt   = Sprache selbst
```

## 7. Soziolekte zentral

### 7.1 Jugendsprache (alle DE-Regionen, 14-30 Jahre)

```
Wortschatz dynamisch — wechselt schnell:

krass                  = außergewöhnlich (positiv oder negativ)
bombe                  = super
geil                   = super
abgefahren             = außergewöhnlich
nice                   = gut, schön (englisch entlehnt)
chillen                = entspannen (englisch entlehnt)
swiped                 = swipe-Aktion (Tinder etc.)
gönn dir               = gönne dir was Gutes
diggi / digga          = "Alter" (Anrede)
Ehrenmann / -frau       = Person mit Integrität
sus                     = suspekt (englisch sus, von Among Us)
basieren / based       = based: Wahrheit-Aussagend, kontrapunkt zu mainstream
cringe                 = peinlich (englisch entlehnt)
verkackt               = misslungen
Stress haben            = beschäftigt, gestresst sein
flexen                 = angeben, prahlen
```

#### Phrasen

```
"Voll krass!"           = sehr beeindruckend
"Das ist eine Pille."   = das ist easy / leicht
"Auf jeden!"           = auf jeden Fall
"Kein Plan."           = keine Ahnung
"Ehrenfrau!"           = Respekt!
"Cringe AF."           = peinlich (AF = "as fuck"; sehr informell)
```

### 7.2 Kiezdeutsch (multiethnischer urbaner Soziolekt)

Kiezdeutsch — Sprache zwischen Migranten + Deutschen in urbanen Vierteln (Berlin Kreuzberg, Hamburg-Altona, etc.).

```
- Vereinfachte Grammatik: keine Artikel-Präzision.
  "Ich gehe Bahnhof" (statt "zum Bahnhof") — typisch Kiezdeutsch.
- Türkische / arabische Lehnwörter: lan, walla, yalla.
- Code-Switching mit Türkisch / Arabisch / Russisch.
- Verstärker durch Wiederholung: "krass krass" (besonders krass).

Beispiel:
"Wallah, der ist krass, lan."  
  (Eindeutige Aussage [wallah, "bei Allah" als Verstärker]; krass; lan = "Mann")
```

(Hinweis: Kiezdeutsch ist nicht "schlechtes Deutsch" — es ist eigene linguistische Variante mit eigener Logik. Cf. Wiese 2012.)

### 7.3 Beamtendeutsch / Bürokratendeutsch

```
- Hochformelle Sprache der Verwaltung.
- Hyper-nominaler Stil.
- FVG-saturiert.
- Verben am Satzende fast immer.

Beispiel:
"Die Bearbeitung Ihres Antrages auf Auszahlung der Sozialleistungen 
hat zur Folge, dass die Auszahlung erst nach Abschluss der Prüfung 
erfolgen wird."

Standard-DE: "Wir bearbeiten Ihren Antrag und zahlen erst nach 
Abschluss der Prüfung."
```

(Cf. ANHANG G — FVG für Bürokratendeutsch-Wortschatz.)

## 8. Praxis — wie damit umgehen?

### 8.1 Was Lerner tun sollte

```
1. Standard-DE als aktive Norm lernen (Hochsprache, Bundesdeutsch).
2. Passives Verständnis der wichtigsten Dialekte aufbauen 
   (Berlinerisch + Bayrisch + Schwyzerdütsch + Wienerisch + Plattdt.).
3. Soziolekte erkennen — nicht produzieren als Lerner. Jugendsprache 
   wechselt schnell; was 2024 cool war, ist 2026 cringe.
4. Bei Reisen: explizit nach langsamerem Sprechen fragen, nicht 
   schämen sich. Native respektieren das.
```

### 8.2 Was Lerner NICHT tun sollte

```
1. Dialekt aktiv produzieren — wirkt comical/aufgesetzt.
2. Soziolekt-Wörter in formellem Kontext mischen.
3. Bei einem Native nachahmen versuchen — meistens unbeholfen.
4. Sich entmutigen, wenn man Dialekt nicht versteht — auch Native 
   verstehen sich oft nicht über Regionen hinweg.
```

### 8.3 Diagnostik-Pipeline beim Hören

```
1. Hört man /ick/ oder /ich/? → Berlin oder Standard?
2. Hört man /servus/, /grüß Gott/, /pfiat di/? → bayrisch / österreichisch?
3. Hört man /grüezi/, /merci/, /salü/? → Schweiz?
4. Hört man /moin/, /büschen/, /Schnack/? → norddeutsch?
5. Hört man /lan/, /wallah/, /yalla/? → Kiezdeutsch?
6. Hört man /krass/, /chillen/, /nice/? → Jugendsprache.
```
