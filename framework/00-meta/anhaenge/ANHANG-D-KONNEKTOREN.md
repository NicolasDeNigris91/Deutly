# ANHANG D — Konnektoren (Konjunktoren, Subjunktoren, Konjunktionaladverbien)

> Referência consolidada para [02-01 Subordination](../../02-struktur/02-01-subordination.md) §2 + transversal Stages 2-5 (Aufsatz-Bau).
>
> DE distingue **3 klassen sintáticamente** de Konnektoren — distinção essencial para PT-falantes (PT colapsa as 3 em "conjunção"). Cada klasse afeta diferentemente a posição do verbo finito.
>
> **Convenções:** `V2` = Hauptsatzstellung (V em segunda posição); `VL` = Verbletztstellung (V no fim, característica de Nebensatz); `[Vorf.] [V] [...]` = topologia.

---

## 1. As 3 klassen sintáticamente distintas

### Klasse I — Konjunktoren (koordinieren; sintaticamente neutros — V2 antes e depois)

```
und, oder, aber, sondern, denn, doch
```

Não ocupam posição na topologia (estão no `Konjunktional-Vorfeld` antes do Vorfeld principal). Verbo do segundo Hauptsatz fica em V2 normal.

```
[Konjunktional] [Vorfeld] [V2] [Mittelfeld] [RK]
   und            er         kommt   morgen      __
```

### Klasse II — Subjunktoren (subordinieren; forçam Verbletztstellung — VL)

```
weil, dass, ob, wenn, falls, als, sobald, sodass, sofern, obwohl, 
während, indem, nachdem, bevor, ehe, seitdem, solange, sooft, 
damit, soweit, sosehr, wohingegen, ...
```

Subjunktor ocupa o início do Nebensatz e força VL. Esta é **a klasse mais densa do alemão** — exigem inversão sintática completa em relação à intuição PT (português usa SVO em ambos os lados).

```
[Hauptsatz: V2]                    [, Subjunktor + Nebensatz: VL]
Ich gehe nach Hause                , weil ich müde bin.

ou:

[Subjunktor + Nebensatz: VL]       [, V2-Hauptsatz mit V im Vorfeld]
Weil ich müde bin                  , gehe ich nach Hause.
                                     ^^^ Hauptsatz V2; Nebensatz im Vorfeld
```

### Klasse III — Konjunktionaladverbien (semanticamente conetam; sintaticamente são ADVÉRBIOS — V2 atrás)

```
deshalb, deswegen, daher, darum, folglich, dennoch, trotzdem, 
allerdings, jedoch, hingegen, demzufolge, mithin, somit, ferner, 
außerdem, zudem, darüber hinaus, weiterhin, gleichwohl, indessen, ...
```

Ocupam **Vorfeld** ou **Mittelfeld** (não pré-Vorfeld). Frase é Hauptsatz V2 normal.

```
[Vorfeld: Adv.] [V2] [Mittelfeld] [RK]
   Deshalb        gehe   ich         nach Hause.

ou no Mittelfeld:

[Vorfeld: Subj.] [V2] [Mittelfeld: Adv.] [RK]
   Ich              gehe  deshalb              nach Hause.
```

### Diferença sintática crítica — par mínimo

```
Klasse II: Weil ich müde bin, gehe ich nach Hause.   (Nebensatz, VL: bin no fim)
Klasse III: Ich bin müde. Deshalb gehe ich nach Hause.   (Hauptsatz, V2: bin/gehe em 2ª)
```

PT-falantes confundem: produzem `*Weil ich bin müde, gehe ich nach Hause` (V2 no Nebensatz — erro pivotal Stage 2) ou `*Deshalb ich gehe nach Hause` (Vorfeld duplo — erro pivotal Stage 2).

## 2. Klasse I — Konjunktoren (klasse fechada de 6)

| Konj. | Bedeutung | Beleg |
|---|---|---|
| **und** | e (aditivo neutro) | *Er kam, und sie ging.* |
| **oder** | ou (alternativo) | *Heute oder morgen?* |
| **aber** | mas (adversativo neutro) | *Er ist müde, aber er arbeitet.* |
| **sondern** | mas sim (adversativo após Negation) | *Nicht heute, sondern morgen.* |
| **denn** | pois (causal-explicativo, V2 não-VL) | *Er bleibt zu Hause, denn er ist krank.* (≠ *weil* que força VL) |
| **doch** | mas / porém (adversativo enfatisch) | *Er versprach es, doch er kam nicht.* |

### Pares Konj. (correlativos)

```
sowohl ... als auch       =  tanto ... quanto
weder ... noch            =  nem ... nem
nicht nur ... sondern auch =  não só ... mas também
entweder ... oder         =  ou ... ou
zwar ... aber             =  embora ... mas
einerseits ... andererseits = por um lado ... por outro
mal ... mal               =  às vezes ... às vezes
je ... desto/umso         =  quanto ... tanto (mais)
```

Beispiel mit `je ... desto` (forma estruturalmente complexa):
```
Je länger ich warte, desto ungeduldiger werde ich.
   ^Nebensatz: VL              ^Hauptsatz: V2 com Adv.-Vorfeld
```

## 3. Klasse II — Subjunktoren (klasse aberta — funcional)

### A) Causais

| Subj. | Bedeutung | Beleg |
|---|---|---|
| **weil** | porque | *Ich bin müde, weil ich gearbeitet habe.* |
| **da** | já que (gehoben/causal estabelecido) | *Da es regnet, bleiben wir zu Hause.* |
| **zumal** | sobretudo porque | *Es lohnt sich, zumal wir Zeit haben.* |

### B) Konzessive (concessivas)

| Subj. | Bedeutung | Beleg |
|---|---|---|
| **obwohl** | embora | *Obwohl es regnet, gehen wir spazieren.* |
| **obgleich*** | embora (gehoben) | *Obgleich er reich ist, lebt er bescheiden.* |
| **obschon*** | embora (gehoben) | *Obschon er es wusste, sagte er nichts.* |
| **wenngleich** | embora (gehoben) | *Wenngleich es spät war, gingen wir noch aus.* |
| **auch wenn** | mesmo que / mesmo se | *Auch wenn es regnet, gehe ich.* |

### C) Konditionale

| Subj. | Bedeutung | Beleg |
|---|---|---|
| **wenn** | se (real ou hipotético) | *Wenn er kommt, gehe ich.* |
| **falls** | caso, se acaso | *Falls es regnet, bleiben wir zu Hause.* |
| **sofern** | desde que (restritivo) | *Sofern niemand widerspricht, beschließen wir.* |
| **soweit** | na medida em que | *Soweit ich weiß, ist er angekommen.* |

### D) Konsekutive (consequência)

| Subj. | Bedeutung | Beleg |
|---|---|---|
| **sodass / so dass** | de modo que (resultado) | *Es regnete stark, sodass die Straße überflutet wurde.* |
| **dass** (após `so` no Hauptsatz) | que (correlativo) | *Es war so kalt, dass das Wasser gefror.* |

### E) Finale (finalidade)

| Subj. | Bedeutung | Beleg |
|---|---|---|
| **damit** | para que (sujeitos diferentes) | *Ich erkläre es noch einmal, damit alle es verstehen.* |
| **um ... zu** + Inf. (na verdade nicht-Subjunktor mas Infinitivkonstruktion) | para (sujeitos iguais) | *Ich lerne, um die Prüfung zu bestehen.* |

### F) Temporais

| Subj. | Bedeutung | Beleg |
|---|---|---|
| **als** | quando (passado pontual / único evento) | *Als ich Kind war, lebten wir in Berlin.* |
| **wenn** | quando (presente, futuro, ou passado iterativ) | *Wenn ich nach Hause komme, esse ich.* |
| **während** | enquanto (simultâneo) | *Während er kochte, las sie ein Buch.* |
| **bevor** | antes que | *Bevor du gehst, ruf mich an.* |
| **ehe** | antes que (gehoben/literário) | *Ehe wir uns versahen, war es vorbei.* |
| **nachdem** | depois que | *Nachdem er gegessen hatte, ging er.* |
| **sobald** | assim que | *Sobald ich fertig bin, komme ich.* |
| **seitdem** | desde que | *Seitdem ich hier wohne, bin ich glücklich.* |
| **bis** | até que | *Wir warten, bis er kommt.* |
| **solange** | enquanto, durante | *Solange du hier bist, sind wir sicher.* |
| **sooft** | sempre que (iterativ) | *Sooft er anruft, lege ich auf.* |
| **kaum dass** | mal | *Kaum dass er kam, ging er wieder.* |

### G) Adversative (contraste, Nebensatz)

| Subj. | Bedeutung | Beleg |
|---|---|---|
| **wohingegen** | enquanto (contraste) | *Er ist fleißig, wohingegen sein Bruder faul ist.* |
| **während** | enquanto (contraste; ≠ uso temporal) | *Sie liest gern, während er Sport mag.* |

### H) Modale

| Subj. | Bedeutung | Beleg |
|---|---|---|
| **indem** | ao [+ Inf.] (modo) | *Indem er hart arbeitete, erreichte er sein Ziel.* |
| **dadurch dass** | pelo fato de (modo, causal) | *Dadurch dass er das tat, half er uns.* |
| **ohne dass** + Konj.II opcional | sem que | *Er ging weg, ohne dass jemand ihn sah.* |
| **anstatt dass** + Konj.II | em vez de | *Anstatt dass er arbeitete, schlief er.* |

### I) Komplementsätze (introduzem Nebensatz como argumento)

| Subj. | Bedeutung | Beleg |
|---|---|---|
| **dass** | que | *Ich weiß, dass er kommt.* |
| **ob** | se (interrogativa indireta) | *Ich frage, ob er kommt.* |
| **wer / was / wo / wie / wann / warum** etc. (W-Wörter) | (interrogativa indireta) | *Ich weiß nicht, wer das gemacht hat.* |

## 4. Klasse III — Konjunktionaladverbien

### A) Causais / consequência (denotam *deshalb*-Familie)

| Adv. | Bedeutung | Registro |
|---|---|---|
| **deshalb** | por isso | neutro (frequenten) |
| **deswegen** | por isso | neutro (similar a *deshalb*) |
| **daher** | daí, por isso | neutro/gehoben |
| **darum** | por isso | neutro/idiomático |
| **folglich** | conseqüentemente | gehoben/wissenschaftlich |
| **demzufolge** | conseqüentemente | gehoben/wissenschaftlich |
| **demnach** | de acordo com isso | gehoben |
| **mithin** | portanto, conseqüentemente | gehoben/literário |
| **somit** | assim, portanto | neutro/gehoben |
| **infolgedessen** | em consequência | gehoben/juridisch |
| **also** | então (consecutivo, neutro) | neutro |

### B) Adversative

| Adv. | Bedeutung | Registro |
|---|---|---|
| **dennoch** | mesmo assim | neutro/gehoben |
| **trotzdem** | apesar disso | neutro |
| **allerdings** | porém, contudo | neutro/gehoben |
| **jedoch** | porém | gehoben |
| **hingegen** | em contraste | neutro/gehoben |
| **dagegen** | em contraste | neutro |
| **demgegenüber** | em contrapartida | gehoben/wissenschaftlich |
| **gleichwohl** | mesmo assim (gehoben) | gehoben |
| **indessen** | enquanto isso / contudo (literário) | gehoben/literário |
| **dennoch** | mesmo assim | neutro/gehoben |

### C) Aditivo / contínuo

| Adv. | Bedeutung | Registro |
|---|---|---|
| **außerdem** | além disso | neutro |
| **zudem** | além disso | gehoben |
| **ferner** | além disso (acadêmico/listing) | gehoben/wissenschaftlich |
| **darüber hinaus** | mais ainda | gehoben |
| **weiterhin** | adiante / além disso | neutro/gehoben |
| **überdies** | mais ainda (gehoben) | gehoben/literário |
| **obendrein** | por cima (informal) | umgangssprachlich |
| **schließlich** | finalmente / por fim | neutro |
| **letztlich** | em última instância | gehoben |
| **dazu** | a isso, mais | neutro |

### D) Temporais

| Adv. | Bedeutung |
|---|---|
| **danach** | depois disso |
| **anschließend** | a seguir |
| **inzwischen** | enquanto isso |
| **währenddessen** | enquanto isso |
| **mittlerweile** | enquanto isso (mais coloquial) |
| **dann** | então (sequência) |
| **schließlich** | finalmente |
| **zuletzt** | por último |
| **zugleich** | ao mesmo tempo |
| **gleichzeitig** | simultaneamente |
| **vorher** | antes |
| **zuvor** | antes (gehoben) |
| **nachher** | depois |

### E) Distributivo / restritivo

| Adv. | Bedeutung |
|---|---|
| **insofern** | nesse sentido |
| **insoweit** | nessa medida |
| **inwiefern** (geralmente como W-Wort) | em que medida |

### F) Konzessive

| Adv. | Bedeutung |
|---|---|
| **immerhin** | pelo menos / contudo |
| **schließlich** | afinal de contas |
| **zugegeben** | reconhece-se |

## 5. Konnektoren acadêmicos — Kombinationen para Aufsatz / Vortrag

### Listing argumentativo

```
Erstens, ...    Zweitens, ...   Drittens, ...
Zunächst, ...   Sodann, ...     Schließlich, ...
Zum einen, ...  Zum anderen, ...
Auf der einen Seite, ... Auf der anderen Seite, ...
```

### Kausal-konsekutive (acadêmico)

```
demzufolge, mithin, folglich, infolgedessen, demnach, somit
```

### Konzessivo-adversative (acadêmico)

```
allerdings, indessen, gleichwohl, demgegenüber, hingegen, jedoch
```

### Aditivo (acadêmico)

```
ferner, darüber hinaus, zudem, überdies, ebenso, gleichermaßen
```

### Exemplificação

```
beispielsweise, etwa, exemplarisch, zur Illustration, 
zum Beispiel (z.B.), insbesondere, namentlich (gehoben)
```

### Concessão argumentativa

```
zwar ... aber/jedoch/doch
gewiss ... aber
freilich ... doch
sicherlich ... allerdings
```

### Schluss / Synthese

```
abschließend, zusammenfassend, schließlich, letztlich, 
im Endeffekt (oral), letzten Endes, alles in allem,
zum Schluss, in Summe (gehoben), zusammengenommen
```

## 6. Falsos cognatos / armadilhas PT-DE

| Konnektor PT | Tradução intuitiva DE | Realidade |
|---|---|---|
| "porque" | *weil* / *denn* | Diferentes sintaticamente: *weil* = Subjunktor (VL); *denn* = Konjunktor (V2). Ambos causais; *weil* mais frequenten escrito; *denn* literário. |
| "embora" | *obwohl* | Correto, mas Klasse II (VL exigida). PT-falante esquece e mantém SVO. |
| "se" | *wenn* / *falls* / *ob* | 3 Subjunktoren para 1 PT: *wenn* condicional/temporal; *falls* condicional restritivo; *ob* indireta interrogativa. |
| "quando" | *wenn* / *als* | *wenn* = presente/futuro/iterativ passado; *als* = passado pontual único. PT colapsa. |
| "mas" | *aber* / *sondern* | *aber* = neutro; *sondern* = adversativo após Negation (*nicht X, sondern Y*). |
| "portanto" | *deshalb* / *folglich* / *also* | Klasse III (V2 normal). PT-falantes errantemente mantém Vorfeld duplo: `*Portanto, eu vou` → `*Deshalb ich gehe` (errado). |
| "enquanto" | *während* / *solange* | *während* = simultâneo + adversativo; *solange* = simultâneo durativo. |
