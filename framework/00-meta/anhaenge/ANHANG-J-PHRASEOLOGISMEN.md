# ANHANG J — Phraseologismen kanonisch

> Referência consolidada para [03-03 Idiomatik und Phraseologie](../../03-stil/03-03-idiomatik.md) + transversal para Stages 2-5.
>
> **~450 Phraseologismen** organizados em 6 grupos: Redewendungen, Idiomatik gehoben, Sprichwörter, Geflügelte Worte, Routineformeln, Kollokationen lexikalisch fixiert. Cada Phraseologismus: Bedeutung + Stilstufe + Beispielsatz quando relevante. **Não inclui FVG** (cf. [ANHANG G — FVG Canônica](ANHANG-G-FVG-CANONICA.md)).

---

## Convenções

- **Stilstufe-Markierung:** `N` = neutro alltäglich; `U` = umgangssprachlich; `G` = gehoben/literarisch; `B` = Bürokratie/Recht; `H` = historisch/archaisch; `J` = jugendsprachlich.
- **Komponente flexível:** `jdn.` = jemanden (Akk.), `jdm.` = jemandem (Dat.), `etw.` = etwas.

## 4. Geflügelte Worte aus klassischer DE-Literatur (~60)

### Aus Goethe

```

"Grau, teurer Freund, ist alle Theorie."           (Faust I)
"Was du ererbt von deinen Vätern hast, 
   erwirb es, um es zu besitzen."                  (Faust I)
"Mehr Licht!"                                      (letzte Worte)
"Edel sei der Mensch, hilfreich und gut!"          (Das Göttliche)
"Wer fertig ist, dem ist nichts recht zu machen."  (Faust I)
"Ich bin kein gemachter Mann."                     (Faust I)
"Glücklich allein ist die Seele, die liebt."       (Egmont)
"Nur dem ist sie gewogen, 
   der die Schande nicht zu fliehen wusste."        (Egmont)
```

### Aus Schiller

```
"Die Welt ist vollkommen überall, 
   wo der Mensch nicht hinkommt mit seiner Qual."  (Wilhelm Tell)
"Frühe übt sich, was ein Meister werden will."     (Wilhelm Tell)
"Das ist der Fluch der bösen Tat."                  (Wallenstein)
"Spät kommt Ihr — doch Ihr kommt!"                  (Wallenstein)
"Der Mensch ist frei geboren, 
   und überall liegt er in Ketten."                 (Übers. Rousseau, oft zitiert)
"Es kann der Frömmste nicht in Frieden leben, 
   wenn es dem bösen Nachbarn nicht gefällt."       (Wilhelm Tell)
"Die Axt im Haus erspart den Zimmermann."           (Wilhelm Tell)
"Ehrlich währt am längsten."                        (Wilhelm Tell)
```

### Aus Heine

```
"Das ist die Krankheit unserer Zeit, 
   die Krankheit unserer Welt."                     (allg.)
"Wenn ich an Deutschland denke in der Nacht, 
   dann bin ich um den Schlaf gebracht."            (Nachtgedanken)

```

### Aus Kant

```
"Habe Mut, dich deines eigenen Verstandes zu bedienen!"   (Aufklärung)
```

### Aus Hegel

```
"Alles, was wirklich ist, ist vernünftig; 
   und alles, was vernünftig ist, ist wirklich."          (Rechtsphilosophie)
"Die Eule der Minerva fliegt erst in der einbrechenden Dämmerung." (Rechtsph. Vorrede)

```

### Aus Nietzsche

```
"Was mich nicht umbringt, macht mich stärker."             (Götzendämmerung)

"Es gibt keine Tatsachen, nur Interpretationen."          (Nachlass)

```

## 5. Routineformeln pragmatisch (~40)

### Begrüßung / Verabschiedung

```
Guten Tag / Guten Morgen / Guten Abend / Gute Nacht       (neutro/höflich)
Hallo / Hi / Servus / Moin                                 (informal regional)
Mahlzeit                                                    (informal Mittag)
Auf Wiedersehen / Tschüs / Tschüss / Mach's gut / Bis bald (neutro/inf.)
Auf Wiederschauen (südd.); Pfüat di / Pfiat Gott (bayr./österr.)
```

### Höflichkeitsformeln

```
Bitte / Danke / Gerne / Bitte sehr / Vielen Dank
Entschuldigung / Tut mir leid / Verzeihen Sie
Wenn ich bitten darf / Mit Ihrer Erlaubnis
Mit Verlaub gesagt / Wenn ich anmerken darf
Ich wäre Ihnen verbunden, wenn... (gehoben)
```

### Briefe / Email

```
Sehr geehrte Damen und Herren,                              (offiziell, unbekannt)
Sehr geehrter Herr Dr. ...                                  (offiziell, bekannt)
Liebe / Lieber ...                                          (informal)
Mit freundlichen Grüßen / Mit besten Grüßen                 (Schluss offiziell)
Hochachtungsvoll                                            (Schluss sehr formell, gehoben)
Mit freundlichen kollegialen Grüßen                         (akademisch)
Herzliche Grüße / Liebe Grüße                               (informal)
```

### Frage / Erwiderung

```
Wie geht es Ihnen? — Danke, gut. Und Ihnen?                 (Standard)
Wie war's? — Es ging.                                       (umg.)
Was darf es sein? — (Restaurant / Ladenfrage)
Was meinen Sie damit?
Verstehe ich Sie richtig, dass...? 
Ich bin damit nicht einverstanden / einverstanden.
```

### Pragmatische Markierungen

```
Auf jeden Fall / Auf keinen Fall                            (zustimmend / ablehnend)
Selbstverständlich                                          (höflich)
Mit Sicherheit                                              (Bestätigung)
Vermutlich / Vielleicht / Möglicherweise                    (Hedge)
Tatsächlich / In der Tat                                    (Bestätigung)
Das stimmt / Das stimmt nicht                               (neutro)
Das ist genau richtig / Das ist falsch                      (neutro)
```

### Wissenschaftliche Übergangs-Formeln

```
"Lassen Sie mich kurz erläutern..."                         (Vortrag)
"Im Folgenden werde ich zeigen, dass..."                    (Aufsatz/Vortrag)
"Es soll im weiteren untersucht werden, ob..."              (Aufsatz)

"Zusammenfassend lässt sich sagen, dass..."                 (Schluss)
"Abschließend soll noch hingewiesen werden auf..."          (Schluss)
```

## 7. Strategie für Aquisição

### Stage 1-2 (~50 Phraseologismen aktiv)

```
Foco: Routineformeln pragmáticas + Sprichwörter mais frequenten.
  + ~15 alltagssprachliche Redewendungen.
  Anki-cards: frasal mit Beispielsatz authentisch.
```

### Stage 3 (~150-200 cumulativo)

```
Foco: Idiomatik literarisch + classical Phrasen.
  + Geflügelte Worte aus Goethe / Schiller / Kant.
  Aufsatz: 1-2 Phraseologismen integrierte (não saturierte).
```

### Stage 4-5 (~300-400 cumulativo)

```
Foco: Saturação para reading sustentado em Adorno / Bernhard / Mann.
  + Geflügelte Worte aus Hegel / Nietzsche / Marx / Adorno.
  Aufsatz / Vortrag: integriert ohne Stilbruch.
```

### Anti-Pattern

```
Phraseologismus saturierte in Aufsatz academisch — wirkt parodisch.
  Gut kalibriert: 1-2 Phraseologismen gehoben pro 1000 W.
```
