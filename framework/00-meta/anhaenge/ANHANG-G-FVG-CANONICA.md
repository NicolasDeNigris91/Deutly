## 1. Was ist ein FVG?

Funktionsverbgefüge = `Funktionsverb (FV) + nominales Element (Subst. mit/ohne Präp.)`.

```
zur Sprache bringen     = Sprache + bringen → "thematisieren"
in Erwägung ziehen      = Erwägung + ziehen → "erwägen"  
zur Verfügung stehen    = Verfügung + stehen → "verfügbar sein"
```

**Eigenschaft:** o Funktionsverb está **lexicalisch entleert**; sentido nuclear vem do Substantiv. FVG é estrutura típica do **nominalen Stil** (cf. 03-01) e domina registros burocrático/jurídico/wissenschaftlich/politisch.

**Por que existem:**

1. **Distância nominal-objektiv** em registro acadêmico/jurídico (vs. verbal direto).
2. **Modifizierbarkeit** do Substantiv com Adjektive: *eine schnelle Entscheidung treffen* (≠ *schnell entscheiden*).
3. **Aspekt-Markierung** sutil: *zu Ende kommen* (perfectivo) vs. *enden* (neutro).
4. **Kollokationale Dichte** preferida no Wissenschaftsdeutsch hoch.

## 4. FVG-Tabelle als Lernscaffold

Sugestão de aquisição cumulativa por Stage:

```
Stage 1 (operacional básico):    ~10 FVG (alltäglich):
                                  Spaß machen, Sorgen machen, Sport treiben,
                                  Platz nehmen, Zeit haben, Auskunft geben,
                                  Bescheid geben, Notiz machen, Pause machen.

Stage 2 (introdução acadêmica):  ~30 FVG (W + N + B):
                                  zur Sprache bringen, in Erwägung ziehen,
                                  Stellung nehmen, in Anspruch nehmen,
                                  Anwendung finden, zur Verfügung stehen,
                                  in Frage stellen, einen Vorschlag machen,
                                  einen Beschluss fassen / treffen, ...

Stage 3 (registro hoch):         ~50 FVG cumulativa:
                                  + komplexere W + Po + J:
                                  zum Tragen kommen, zur Geltung kommen,
                                  in Wechselwirkung stehen, im Einklang stehen,
                                  Wert legen auf, einen Beitrag leisten, ...

Stage 4 (sistema completo):      ~100+ FVG cumulativa:
                                  + komplexere J + Po:
                                  Klage erheben, in Mitleidenschaft ziehen,
                                  zur Rechenschaft ziehen, einen Eid leisten, ...

Stage 5 (output):                referência consultável; aluno usa
                                  conscientemente em Vortrag/Aufsatz.
```
