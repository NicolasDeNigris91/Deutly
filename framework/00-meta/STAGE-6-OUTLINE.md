# STAGE 6 — Spezialisierungs-Tracks (Blueprint)

> Outline für Stage 6 — **opcional**, post-CAPSTONE-5. Spezialisierung in 4 Tracks für Lernende, die nach Erreichen von C2+ World Class einen genaueren akademischen / professionellen Fokus suchen.
>
> **Status:** Blueprint (v1.4, 2026-05-09) — vollständige Module-Implementation in v2.0 geplant. Hier Strukturskizze + Track-Beschreibungen + erste Modul-Drafts.
>
> **Voraussetzung:** CAPSTONE-5 abgeschlossen (Veröffentlichung in DE/AT/CH-Zeitschrift).
>
> **Resolve SN-016 partial.**

---

## 1. Was ist Stage 6?

Stage 6 ist **post-Meisterschaft**. Wer CAPSTONE-5 abgeschlossen hat, ist in C2+ World Class und hat das Hauptziel des FATHOM-Deutsch erreicht. Stage 6 bietet **vier alternative Spezialisierungs-Tracks** für unterschiedliche Berufsperspektiven oder akademische Vertiefungen:

```
Track A — Übersetzungswissenschaft + Praxis (PT↔DE)
Track B — Germanistische Forschung (Promotion-Vorbereitung)
Track C — Fachsprache spezialisiert (Recht / Medizin / Technik)
Track D — Mentoring + DaF-Lehre
```

Jeder Track besteht aus **5-7 Modulen + 1 Capstone-6**, der spezifisch für den Track ist.

## 2. Track A — Übersetzungswissenschaft + Praxis (PT↔DE)

### Vorhandene Anker-Module (Stage 5)

- [05-03 Übersetzungstheorie und -praxis](../05-meisterschaft/05-03-uebersetzungstheorie.md).
- Trilha D in [LEARNING-PATHWAYS.md](LEARNING-PATHWAYS.md).

### Stage 6 Track A — neue Module (geplant)

#### 06-A-1: Übersetzungstheorie vertieft

- Schleiermacher / Benjamin / Berman / Steiner / Venuti gelesen + analysiert.
- Eigene translatologische Position formulieren.
- Texto-âncora: Berman *L'épreuve de l'étranger* (1984).

#### 06-A-2: Literarische Übersetzung PT↔DE

- Mann nach PT-BR übersetzt; Machado de Assis nach DE übersetzt.
- Vergleich existierender Übersetzungen.
- Texto-âncora: Mann *Der Tod in Venedig* (1912) + bestehende PT-Übersetzungen.

#### 06-A-3: Philosophische Übersetzung

- Heidegger nach PT übersetzt; problematische Begriffe (Dasein, Eigentlichkeit).
- Texto-âncora: Heidegger *Sein und Zeit* §1-7 + bestehende PT-Übersetzungen.

#### 06-A-4: Juristische Übersetzung

- BGB-Auszüge; Verfassungstexte vergleichend (Grundgesetz vs. Constituição).
- Texto-âncora: Grundgesetz Art. 1-19 + Constituição Brasileira Art. 1-17.

#### 06-A-5: Kulturwissenschaftliche Übersetzung

- Adorno / Bourdieu / Habermas-Auszüge.
- Diskurs-spezifische Terminologie (z.B. *Bildungsbürger*) zwischen Sprachen.

#### 06-A-6: Lektorat + Redaktion

- Eigene Übersetzungen mit Lektor revidieren.
- Praxis professioneller Übersetzungsarbeit.

#### CAPSTONE-6-A: Publizierte Buchübersetzung

- Eine literarische / philosophische / Sachbuch-Übersetzung publiziert (Buchform oder Sammelband).
- Volumen: ~150-300 Seiten.
- Mit Vorwort + Übersetzer-Kommentar.

### Berufliche Anschlussmöglichkeiten

- Freier Literaturübersetzer.
- Verlagslektor PT-DE.
- Akademischer Übersetzer (Wissenschaftsverlag).
- Konferenzdolmetscher (mit zusätzlicher Ausbildung).

- Habilitations-Schrift planen.

## 7. Wer wählt welchen Track?

### Track A (Übersetzung)

```
Wenn:
  - PT↔DE-Mediation als Hauptberuf interessiert.
  - Literarische / philosophische Texte sind Liebe.
  - Geduld für lange Übersetzungs-Projekte (Buch ~6-18 Monate).
  - Editor/Verlag-Kontakte vorhanden oder aufzubauen.
```

### Track B (Forschung)

```
Wenn:
  - Akademische Karriere intendiert.
  - Forschungsfrage über Jahre stabil verfolgbar.
  - Promotions-Stipendium in DE/AT/CH realistisch erreichbar.
  - Ehrgeizig + zähig genug für Habilitation langfristig.
```

### Track C (Fachsprache)

```
Wenn:
  - Berufsausübung in DE/AT/CH intendiert (Anwalt, Arzt, Ingenieur).
  - Approbation / Anerkennung des fachlichen Diploms möglich.
  - Spezifischer Fachstuß bereits vorhanden.
```

### Track D (Mentoring)

```
Wenn:
  - Lehrerische Berufung verspürt.
  - Geduld + Empathie für Lernende.
  - Goethe-Institut / Sprachschul-Position erreichbar.
  - Bereitschaft zur DaF-Methodik-Vertiefung.
```

### Mehrere Tracks?

Möglich, aber nicht parallel: Stage 6 ist anstrengend. Empfehlung: einen Track abschließen, dann ggf. zweiten beginnen.

## 10. Hinweis zur Nutzung dieses Outlines

### Bis zur Implementation v2.0+

Lerner, der bereits CAPSTONE-5 abgeschlossen hat und auf v2.0 wartet, kann:

1. **Track wählen** basierend auf dem hier gegebenen Outline.
2. **Eigene Lernkurriculum** strukturieren mit der hier vorgeschlagenen Modul-Struktur.
3. **Eigene Capstone-6** definieren basierend auf dem Outline.
4. **Mit Mentor** den eigenen Track durcharbeiten.

Wenn Track-Spezifika ergänzt werden sollen (Quellen-Listen, Modul-Strukturen) — durch Issues / PRs in das FATHOM-Deutsch-Repo einbringen.
