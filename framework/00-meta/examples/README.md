# Examples — Capstones exemplares (worked examples)

> Catálogo dos Capstones exemplares publicados como modelo. **Worked examples** que demonstram a **forma** que o aluno deve produzir em cada CAPSTONE — não para copiar conteúdo, mas para calibrar expectativas estruturais.

---

## Princípio

Aluno em Stage 1 frequentemente **não sabe** o que CAPSTONE-1 produz concretamente — descrição abstrata em CAPSTONE-fundamente.md é necessária mas insuficiente. Worked example fecha o gap entre descrição e execução.

**Cuidado pedagógico crítico:** worked examples podem **substituir** o trabalho do aluno em vez de orientá-lo. Risco de fossilização por imitação. Cada exemplar inclui **avisos explícitos** + **estrutura clara distinguindo "o que aprender" vs. "o que NÃO copiar"**.

## Como usar um exemplar

### Was zu tun

1. **Lesen** após estudar Sektion 2 do respectivo Capstone-Modul (CAPSTONE-fundamente.md / CAPSTONE-struktur.md / etc.).
2. **Forma identifizieren** — 9-Felder-Schema (CAPSTONE-1), 6-Sektionen-Struktur (CAPSTONE-2), etc.
3. **Cross-references nachvollziehen** — wie entries / Sektionen sich vernetzen.
4. **Korrektur-Camadas verstehen** — wie Loop de Refinamento operiert.
5. **Eigene Strukturplanung** machen, basierend auf gelernter Form.

### Was NICHT zu tun

1. **Conteúdo kopieren** — Begriff-Wahl + Beleg-Wahl + Kollokationen müssen aus eigener Lektüre kommen.
2. **Ordem das entries** kopieren — eigene Progression reflectir.
3. **Stilexpektativas** überschreiten — exemplar zeigt Niveau erwartet, nicht Niveau-Decke.

---

## Princípios da curadoria de exemplares

1. **Begriffes-Auswahl** für exemplares: prefere os que têm **maior tradição filológica** para que múltiplos alunos possam usar como base sem que o exemplar feche todas as direções de leitura.
2. **Niveau-Kalibrierung:** exemplar deve estar **um pouco acima** do Niveau-Pass (~90% RUBRIC); fica claro que é exemplar não-trivial mas alcançável.
3. **Korrektur-Iteration sichtbar:** exemplar mostra v2 ou v3 — não v1; iteração é parte da forma.
4. **Quellen primärias citadas:** todos Belege são autênticos (Kant, Hegel, Adorno, Habermas, Foucault em CAPSTONE-1-Aufklärung).
5. **Warnungen explícitas:** cada exemplar diz claramente o que kopieren = Verstoß gegen den Erkenntnisprojekt-Geist.

---

## Como contribuir com novo exemplar

1. **Issue** com proposta: qual Capstone, qual Begriff, justificativa.
2. **Discussão** se Begriff é canônico ou exotic-justificado.
3. **PR** com exemplar completo seguindo padrões deste diretório.
4. **Review** mantenedor: corretude pedagógica + linguística + warnings explícitas.
5. **Merge** após v3-Niveau atingido.
