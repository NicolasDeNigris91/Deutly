## Modul 04-01 — Historische Linguistik

### Übung 04-01-A ★

**Frage:** Ordnen Sie die folgenden Sprachperioden chronologisch + nennen Sie für jede ein typisches Merkmal:

a) Mhd.
b) Frnhd.
c) Ahd.
d) Nhd.

**Erwartete Lösung:**

| Reihenfolge | Periode | Datierung | Merkmal |
|---|---|---|---|
| 1. | **Ahd.** | ~750–1050 | 2. Lautverschiebung (germ. *t* → *ts/s*; *p* → *pf/f*) |
| 2. | **Mhd.** | ~1050–1350 | Vollvokale unbetont (taga, Pl.); Höfische Dichtung (Walther, Wolfram) |
| 3. | **Frnhd.** | ~1350–1650 | Lutherbibel (1522/34); Standardisierungs-Beginn |
| 4. | **Nhd.** | ~1650–heute | Standardhochdeutsch; Rechtschreibreform 1996/2006 |

**Begründung:** Sprachperiodisierung hat keine harten Grenzen, sondern allmähliche Übergänge. Die zweite Lautverschiebung (~500–800 n.Chr.) markiert den Übergang germ. → ahd. (= Hochdeutsch); die Lutherbibel + Buchdruck (~1500) markieren den Beginn der Standardisierungsphase. (Cf. 04-01 §2.)

**Verweis:** [04-01 §2 Sprachperioden](../04-system/04-01-historische-linguistik.md).

### Übung 04-01-B ★★

**Frage:** Erklären Sie die zweite (Hochdeutsche) Lautverschiebung mit 3 Beispielen aus dem Vergleich Hochdeutsch vs. Niederdeutsch/Englisch:

**Erwartete Lösung:**

```
Konsonant germ. → hd. + Beleg DE vs. Niederdt./Engl.

1. germ. *t* → hd. *ts* / *s*
   - germ./engl. water — hd. Wasser (zwischen Vokalen *t* → *ss*)
   - germ./engl. two   — hd. zwei  (Wortanfang *t* → *ts* → *z*)

2. germ. *p* → hd. *pf* / *f*
   - germ./engl. pepper — hd. Pfeffer (Wortanfang *p* → *pf*)
   - germ./engl. up     — hd. auf    (zwischen Vokalen *p* → *f*)

3. germ. *k* → hd. *kx* (selten) / *ch*
   - germ./engl. make   — hd. machen (zwischen Vokalen *k* → *ch*)
   - germ./engl. ich/I  — hd. ich    (Auslaut *k* → *ch*)
```

Die Benrather Linie (Düsseldorf-Region) trennt Niederdeutsch (mit alten *t/p/k*) von Hochdeutsch (mit verschobenen *ts/pf/ch*).

**Begründung:** Die 2. LV ist das definitorische Merkmal des Hochdeutschen (= Sprachregion südlich Benrather Linie). Niederdeutsch (Plattdt.) hat sie nicht durchgeführt → behält *make, water, up*. (Cf. 04-01 §3 + Benrather Linie.)

**Verweis:** [04-01 §3 Lautverschiebungen](../04-system/04-01-historische-linguistik.md).

### Übung 04-01-C ★★★

**Frage:** Übersetzen Sie folgenden Mhd.-Text (Walther von der Vogelweide, ca. 1200) ins Nhd. + identifizieren Sie 3 Mhd.-Spezifika:

> *"under der linden / an der heide / dâ unser zweier bette was, / dâ muget ir vinden / schône beide / gebrochen bluomen unde gras."*

**Erwartete Lösung:**

```
NHD-Übersetzung:
"Unter der Linde / auf der Heide, / wo unser beider Bett war, / 
da könnt ihr finden / schön beide / gebrochene Blumen und Gras."

Mhd.-Spezifika:
1. *dâ* mit Zirkumflex = mhd. langes â (Lachmann-Edition); im Nhd. *da* (Kurzvokal).
2. *muget* = 2.Pl. Konj. *mögen* (mhd.) → nhd. *möget* (selten heute) / *könnt* (häufig).
3. *bluomen* = mhd. langes uo-Diphtong → nhd. ū / u (Blume).
4. *zweier* = mhd. Genitiv-Form (zweier Pers.) → nhd. *unserer beiden*.
5. Vollvokale unbetont (*linden, heide* mit -e Endung) → nhd. mit -e ebenfalls erhalten, 
   aber mhd. weniger reduziert.
```

**Begründung:** Mhd. ist klassische DE-Periode mit relativer Stabilität. Editorial-Konvention (Lachmann 1820–1850) verwendet Zirkumflex für Vokallänge. Diphthonge (*ei, ie, uo*) zeigen sich noch klar. Übersetzung erfordert Glossar + grammatisches Wissen über Konj.-Formen + Genitiv. (Cf. 04-01 §4 Mhd.-Lektüre.)

**Verweis:** [04-01 §4 Mhd. lesen](../04-system/04-01-historische-linguistik.md).

### Übung 04-02-B ★★

**Frage:** Beschreiben Sie den semantischen Wandel der folgenden Lemmata:

a) *Bildung* (mhd. → nhd.)
b) *artig* (mhd. → nhd.)
c) *geil* (ahd. → nhd. inkl. Jugendsprache)

**Erwartete Lösung:**

a) **Bildung**: 
   - mhd. *bildunge* = "Erschaffung, Form, Gestalt" (konkret: das Bilden eines Bildes/Gestalts).
   - 18. Jh. (Humboldt-Tradition): semantische Erweiterung zu "Selbstkonstitution des Menschen via Auseinandersetzung mit Welt" (abstrakt-pädagogisch).
   - Heute: ambig zwischen "schulische Ausbildung" (instrumentell) + "humboldtsche Bildung" (substantiell). Adorno warnt vor Halbbildung.

b) **artig**:
   - mhd. *artec* = "von guter Art, angeboren-edel".
   - frnhd. = "höflich, manierlich".
   - nhd. = "wohlerzogen, brav" (vor allem für Kinder); semantische Verengung + leichte Pejorisierung.

c) **geil**:
   - ahd. *geil* = "fröhlich, lustig, übermütig".
   - mhd. = "üppig, kraftvoll" (von Pflanzen + Personen).
   - frnhd. + nhd. (~1700) = sexuell konnotiert ("geile Person/Tier").
   - 1990er Jugendsprache: Neubedeutung "toll, super, geil" — paradoxe Wiederbelebung der ahd.-mhd. positiven Wertung.

**Begründung:** Semantischer Wandel hat 4 Hauptwege: Bedeutungserweiterung (Bildung), Bedeutungsverengung (artig), Pejorisierung (Weib, geil 17.-19. Jh.), Amelioration (geil 1990er). Wandel ist nicht linear. (Cf. 04-02 §3 + Pfeifer-DWDS.)

**Verweis:** [04-02 §3 Wortgeschichte](../04-system/04-02-etymologie.md), [BEGRIFFS-GLOSSAR § Bildung](BEGRIFFS-GLOSSAR.md).

### Übung 04-02-C ★★★

**Frage:** Rekonstruieren Sie die etymologische Geschichte des Lemmas *Aufklärung* (Konzept, nicht nur Wort) — von ahd. Form bis zur philosophischen Bedeutung im 18. Jh.:

**Erwartete Lösung:**

```
1. AHD. Schicht (~750–1050):
   *klāra* "klar, hell, glänzend" (verwandt mit lat. *clarus*).
   Verb *klāren* "klar machen".

2. MHD. Schicht (~1050–1350):
   *klœren / klāren* "erleuchten, klären" (lautlich + semantisch).
   Substantiv *klærunge* "das Klären" (selten).

3. FRNHD. Schicht (~1350–1650):
   Komposition mit *auf-* (intensifizierendes Verbalpräfix): *aufklären* 
   "ans Licht bringen, erläutern".
   
4. 18. JH. (semantischer Sprung):
   Lehnübersetzung von franz. *éclaircissement* / *Lumières* + engl. *Enlightenment*.
   Substantivierung *Aufklärung* erhält philosophisch-programmatische Bedeutung.
   Kant 1784: "Aufklärung ist der Ausgang des Menschen aus seiner 
   selbstverschuldeten Unmündigkeit."
   
5. 19.–21. JH.:
   Sub-Traditionen + Gegen-Traditionen entwickeln sich:
   - Romantische Kritik (Schlegel: Aufklärung verfehlt das Lebendige).
   - Hegel-rekonstruktiv: Aufklärung als historischer Schritt zur Selbstbewusstheit.
   - Adorno/Horkheimer 1944: Dialektik der Aufklärung — Selbstzerstörung der Vernunft.
   - Habermas 1981: Aufklärung als rekonstruierbares emanzipatorisches Projekt.
   - Foucault 1984: Aufklärung als ethos der ständigen Selbst-Befragung.
```

**Begründung:** Etymologie eines philosophischen Begriffs verbindet Wort-Geschichte (ahd. → nhd.) mit Begriffs-Geschichte (Koselleck-Methode). Aufklärung ist Paradigma-Beispiel: lautlich kontinuierlich, semantisch sprunghaft im 18. Jh., danach umkämpft in Sub-Traditionen. (Cf. 04-02 §4 + 03-09 Lexik III + BEGRIFFS-GLOSSAR.)

**Verweis:** [04-02 §4 Begriffs-Etymologie](../04-system/04-02-etymologie.md), [03-09 §3 Sub-Traditionen](../03-stil/03-09-lexik-3.md), [BEGRIFFS-GLOSSAR § Aufklärung](BEGRIFFS-GLOSSAR.md).

### Übung 04-03-B ★★

**Frage:** Identifizieren Sie für die folgende Aussage Region + 3 Marker:

> *"Servus, magst noch a Maß Bier?"*

**Erwartete Lösung:**

**Region:** Bayrisch-österreichisch (Süddeutsch).

### Übung 04-03-C ★★★

**Frage:** Analysieren Sie die folgende Kiezdeutsch-Aussage linguistisch (Soziolekt-Marker):

> *"Lan, ich gehe Bahnhof, du komm mit, walla!"*

**Erwartete Lösung:**

**Soziolekt:** Kiezdeutsch (Berlin-Kreuzberg, Hamburg-Altona; multiethnisch, ca. 1990er ff.).

**4 Marker:**
1. **Lan** = türkisches Adressat-Marker (nicht-direkte Übersetzung; ~"Mann, Junge, Bro"). Code-Switching DE-TR.
2. **ich gehe Bahnhof** = innovative Adverbial-Konstruktion ohne Präposition + Artikel. Standardhochdt.: *ich gehe zum Bahnhof*. Reduktion typisch Kiezdeutsch.

4. **walla** = arabisches Beschwörungs-/Bekräftigungs-Marker (lit. "bei Gott"); Diskursmarker in Kiezdeutsch.

**Hintergrund:** Kiezdeutsch ist KEIN gebrochenes Deutsch, sondern eigenständiger Soziolekt mit Regelhaftigkeit. Forschungswerk: Heike Wiese, *Kiezdeutsch — Ein neuer Dialekt entsteht* (2012, Beck). Marker:
- Vereinfachte Genus-Markierung.
- Innovative Lokativ-Konstruktionen.
- Lehnwörter aus Türkisch (lan, ay) + Arabisch (walla, yalla, halal).
- Code-Switching DE-TR-AR.

(Cf. 04-03 §4 + Wiese 2012.)

## Modul 04-04 — Generative Syntax

### Übung 04-04-A ★

**Frage:** Identifizieren Sie für jeden Satz die Schlüssel-Struktur (V2 / VL):

a) *Heute habe ich Hunger.*
b) *Ich glaube, dass er kommt.*
c) *Wenn es regnet, bleibe ich.*
d) *Was hast du gesagt?*

**Erwartete Lösung:**

a) **V2** (Hauptsatz; *habe* in C; *Heute* in CP-Spec).
b) Hauptsatz V2 (*glaube*); Nebensatz VL (*kommt* am Ende, *dass* in C).
c) Nebensatz VL (*regnet* am Ende, *Wenn* in C); Hauptsatz V2 mit Nebensatz im Vorfeld (*bleibe*).
d) **V2 mit Wh-Bewegung** (*Was* in CP-Spec; *hast* in C).

**Begründung:** Generative Syntax erklärt diese Asymmetrie via V→C-Bewegung im Hauptsatz; im Nebensatz wird C von Subjunktor/Wh-Wort besetzt → Verb bleibt in V → Verbletzt. (Cf. 04-04 §2.)

**Verweis:** [04-04 §2 V→C-Bewegung](../04-system/04-04-generative-syntax.md).

### Übung 04-04-B ★★

**Frage:** Konstruieren Sie einen X-bar-Baum für *"Der Mann liest das Buch"* (vereinfacht: NP, VP, IP):

**Erwartete Lösung:**

```
        IP
       /  \
      /    \
     NP    I'
     |     /\
   [Der  V    I
    Mann][liest][+fin]
                 |
                 VP
                / \
              [_v_] NP
                    |
                  [das Buch]
```

Detaillierter:
- **IP** (Inflectional Phrase): Subj. *Der Mann* in IP-Spec; I-Kopf trägt Tempus + Kongruenz.
- **VP** (Verbalphrase): V-Kopf *liest* (kann nach I bewegen); Akk-Komplement *das Buch*.
- Im Hauptsatz V2: *liest* bewegt sich von V → I → C; *Der Mann* bewegt sich von IP-Spec → CP-Spec (oder bleibt; je nach Topik).

**Begründung:** X-bar-Theorie postuliert universelle Phrasenstruktur [XP Spec [X' X Comp]]. DE-V2-Hauptsatz erfordert V→I→C-Bewegungs-Kette. (Cf. 04-04 §3.)

**Verweis:** [04-04 §3 X-bar-Theorie](../04-system/04-04-generative-syntax.md).

### Übung 04-04-C ★★★

**Frage:** Erklären Sie die Asymmetrie zwischen V2-Hauptsatz und VL-Nebensatz im Deutschen mit dem Generativen Modell (CP-IP-VP-Schichten + V→C-Bewegung):

**Erwartete Lösung:**

**Grundbeobachtung:** Im Hauptsatz steht das finite Verb in zweiter Position (V2): *Heute habe ich Hunger*. Im Nebensatz steht es am Ende (VL): *...weil ich Hunger habe*.

**Generative Erklärung:**

1. **Grundstellung der VP:** in der DE-VP ist das Verb final (Verb nach Komplement). Beleg: nicht-finite Form bleibt in VP-Endstellung im Hauptsatz: *Ich habe gestern den Brief **geschrieben*** (Part.II in V).

2. **C-Position als Schalter:**
   - Hauptsatz: C ist leer (kein Subjunktor). V→C-Bewegung obligatorisch (V2-Constraint). Resultat: finites Verb in C, andere Konstituente in CP-Spec → V2-Stellung.
   - Nebensatz: C ist von Subjunktor besetzt (*weil, dass, wenn*). V→C-Bewegung blockiert. Verb bleibt in V → Verbletzt-Stellung.

3. **Wh-Frage:** C-Position ist von [+wh] besetzt; Wh-Wort in CP-Spec; finites Verb in C → V2 mit Wh-Wort im Vorfeld.

4. **Konsequenz für PT-falante:** Diese Asymmetrie (V2/VL via C-Position) ist im PT abwesend (PT = SVO konsistent). PT-falante muss bewusst Subjunktor → VL koppeln; rein durch Übung internalisiert (typisch 6–12 Monate Praxis).

(Cf. 04-04 §4 + 04-09 Kontrastive PT-DE.)

**Verweis:** [04-04 §4 V2-Asymmetrie](../04-system/04-04-generative-syntax.md), [04-09 §3 VL-Lernschwierigkeit PT-falante](../04-system/04-09-kontrastive-linguistik.md).

## Modul 04-05 — Formale Semantik

### Übung 04-05-A ★

**Frage:** Übersetzen Sie in Quantorenlogik:

a) *Alle Menschen sind sterblich.*
b) *Es gibt einen Menschen, der unsterblich ist.*
c) *Kein Mensch ist allwissend.*
d) *Manche Studenten lernen.*

**Erwartete Lösung:**

a) ∀x (Mensch(x) → Sterblich(x))
b) ∃x (Mensch(x) ∧ ¬Sterblich(x))
c) ∀x (Mensch(x) → ¬Allwissend(x)) = ¬∃x (Mensch(x) ∧ Allwissend(x))
d) ∃x (Student(x) ∧ Lernen(x))

**Begründung:** Quantorenlogik ist Standard-Notation der formalen Semantik. Zwei Hauptquantoren: ∀ (Allquantor "für alle") + ∃ (Existenzquantor "es existiert"). Negation kann skopussensitiv sein: *Kein Mensch ist X* ≡ *Alle Menschen sind nicht X*. (Cf. 04-05 §2.)

**Verweis:** [04-05 §2 Quantorenlogik](../04-system/04-05-formale-semantik.md).

---

### Übung 04-05-B ★★

**Frage:** Identifizieren Sie die zwei möglichen Lesarten + Quantoren-Skopus von:

> *"Jeder Student liebt ein Buch."*

**Erwartete Lösung:**

**Lesart 1 (∀ > ∃, distributiv):**
∀x ∃y (Student(x) → (Buch(y) ∧ Liebt(x,y)))
"Für jeden Studenten gibt es (irgend)ein Buch, das er liebt."
= Buch kann für jeden Studenten anders sein.

**Lesart 2 (∃ > ∀, kollektiv):**
∃y ∀x (Buch(y) ∧ (Student(x) → Liebt(x,y)))
"Es gibt ein bestimmtes Buch, das jeder Student liebt."
= Ein einziges Buch, von allen geliebt.

**Skopus-Ambiguität** ist genau die Tatsache, dass *jeder* und *ein* unterschiedliche relative Reichweiten haben können. Disambiguierung im Deutschen via:
- Kontext.
- Akzent (kontrastiver Akzent auf *EIN* Buch markiert ∃ > ∀).
- Periphrastische Konstruktionen (*ein bestimmtes Buch* erzwingt ∃ > ∀; *je ein Buch* erzwingt ∀ > ∃).

**Begründung:** Skopus-Ambiguität ist Klassiker der formalen Semantik. PT verhält sich ähnlich. (Cf. 04-05 §3.)

**Verweis:** [04-05 §3 Skopus-Phänomene](../04-system/04-05-formale-semantik.md).

### Übung 04-05-C ★★★

**Frage:** Analysieren Sie folgenden Frege-Beleg semantisch:

> *"Der Morgenstern ist der Abendstern."*

Geben Sie an: was ist die *Bedeutung* (Referenz)? Was ist der *Sinn* der beiden Ausdrücke?

**Erwartete Lösung:**

**Frege-Klassiker** (*Über Sinn und Bedeutung*, 1892):

1. **Bedeutung (Referenz)** beider Ausdrücke ist identisch: der Planet **Venus**.

2. **Sinn** der beiden Ausdrücke ist verschieden:
   - *Morgenstern* = "der hellste Stern, der morgens am Himmel zu sehen ist".
   - *Abendstern* = "der hellste Stern, der abends am Himmel zu sehen ist".
   - Verschiedene "Arten des Gegebenseins" desselben Gegenstandes.

3. **Erkenntnistheoretische Konsequenz:** der Satz "Der Morgenstern ist der Abendstern" ist **informativ** (bringt neues Wissen), obwohl die Bedeutungen identisch sind. Wären die Sinne identisch, wäre der Satz tautologisch ("Venus ist Venus"). Frege löst das Problem durch die Sinn-Bedeutungs-Distinktion.

4. **Anwendung in Logik:** in extensionalen Kontexten sind co-referentielle Ausdrücke austauschbar (Substitutivität). In intensionalen Kontexten (z.B. *glauben*, *wissen*) NICHT — der Sinn zählt:
   - "Hans glaubt, dass der Morgenstern hell ist" ⊭ "Hans glaubt, dass der Abendstern hell ist" 
   (Hans könnte das Morgenstern-Bild + Wissen haben, ohne den Abendstern als denselben zu identifizieren).

**Begründung:** Sinn-Bedeutungs-Distinktion ist Frege's epochaler Beitrag zur Sprachphilosophie. Programmatisch in *Über Sinn und Bedeutung* (1892, Zeitschrift für Philosophie und philosophische Kritik). Anwendung in Linguistik, Logik, Philosophie of Language. (Cf. 04-05 §4 + 03-09 Lexik III.)

**Verweis:** [04-05 §4 Frege-Sinn-Bedeutung](../04-system/04-05-formale-semantik.md), [BEGRIFFS-GLOSSAR § Sinn + Bedeutung](BEGRIFFS-GLOSSAR.md).

## Modul 04-06 — Diskursanalyse

### Übung 04-06-A ★

**Frage:** Definieren Sie kurz die folgenden Foucault-Begriffe:

a) Diskurs
b) Dispositiv
c) Genealogie
d) Macht-Wissen-Komplex

**Erwartete Lösung:**

a) **Diskurs** = geregelte Gesamtheit von Aussagen + Praktiken, die definiert, was als Wissen, Wahrheit + Realität in einer Epoche gilt. Nicht reine Sprache, sondern sprachlich-institutionelle Praxis. (*Archäologie des Wissens*, 1969.)

b) **Dispositiv** = heterogene Anordnung von Diskursen, Institutionen, Gesetzen, Architekturen, Wissenschaften, die als Strategie auf historische Probleme antwortet. (*Wille zum Wissen*, 1976.)

c) **Genealogie** = historische Untersuchung der Entstehungsbedingungen von Diskursen + Praktiken; anti-essentialistisch, anti-progressivistisch. (*Überwachen und Strafen*, 1975.)

d) **Macht-Wissen-Komplex** = These, dass Macht und Wissen nicht-trennbar sind: Macht produziert Wissen; Wissen ermöglicht + legitimiert Macht. (*Wille zum Wissen*, 1976.)

**Begründung:** Foucault-Begriffe sind essenziell für Stage-4-Diskursanalyse + Stage-5-Politische-Sprache. Quellen genau zitieren. (Cf. 04-06 §2.)

**Verweis:** [04-06 §2 Foucault-Begriffe](../04-system/04-06-diskursanalyse.md), [BEGRIFFS-GLOSSAR § Diskurs + Macht](BEGRIFFS-GLOSSAR.md).

### Übung 04-06-B ★★

**Frage:** Wenden Sie das KDA-Schema (Fairclough) auf einen kurzen Belegtext an:

> *"Wir müssen handeln. Die Wirtschaft braucht Investitionen. Die Bürger erwarten Lösungen, keine Ausreden."*

**Erwartete Lösung:**

**Ebene 1 — Text (sprachliche Analyse):**
- Kurze Sätze (Hauptsätze; rhetorische Wirkung der Direktheit).
- Modalverb *müssen* (deontisch + kollektiv-inklusives *Wir*).
- Passiv-Vermeidung: *Wir müssen, die Wirtschaft braucht, die Bürger erwarten* — alles aktive Subjekt-Prädikat-Strukturen.
- Anaphorische Trias (Wir / Wirtschaft / Bürger) als rhetorische Klimax.
- Antithese: *Lösungen, keine Ausreden*.

**Ebene 2 — Diskursive Praxis:**
- Genre: politische Rede (Kontext: Wahlkampf? Pressekonferenz? Bundestags-Debatte?).
- Produzent: Politiker (der seine Position als Akteur markiert via *wir*).
- Adressat: Wähler / breite Öffentlichkeit.

**Ebene 3 — Soziale Praxis:**
- Konstruktion einer Krisen-Situation, die handlungsdrängend ist.
- Inklusiver *wir* mobilisiert Solidarität + impliziert: nicht-Handeln = Verrat.
- Antithese *Lösungen vs. Ausreden* impliziert Gegenposition (Gegner produziert nur Ausreden).
- Diskurs-Effekt: legitimiert Macht-Anspruch des Sprechers via Krisen-Frame.

(Cf. 04-06 §3 + Fairclough-Schema.)

## Modul 04-07 — Textlinguistik

### Übung 04-07-A ★

**Frage:** Identifizieren Sie 3 Kohäsionsmittel im folgenden Beleg:

> *"Hans hat einen Hund. Er heißt Rex. Rex ist sehr verspielt. Deshalb braucht er viel Auslauf."*

**Erwartete Lösung:**

1. **Pronominalisierung**: *Er* (= Rex; Wiederaufnahme via Personalpronomen); *er* (= Rex zum zweiten Mal; weitere Wiederaufnahme).
2. **Lexikalische Wiederaufnahme**: *Rex* wird explizit zweimal wiederholt (statt nur Pron); *Hund* → *Rex* (spezifizierende Wiederaufnahme via Eigennamen).
3. **Konnektor**: *Deshalb* (kausal-konsekutiv) verknüpft Sätze 3-4.

Plus: **Definitheit-Marker**: *einen Hund* (indefinit, neu) → *der Hund* (definit) implizit über Pron *er*; Tempus-Konsistenz (Präsens durchgängig).

**Begründung:** Kohäsion ist sprachlich-formale Verknüpfung. Pronominalisierung ist häufigstes Mittel; Konnektoren machen logische Beziehungen explizit. (Cf. 04-07 §2.)

**Verweis:** [04-07 §2 Kohäsionsmittel](../04-system/04-07-textlinguistik.md).

### Übung 04-07-B ★★

**Frage:** Diagnostizieren Sie das Problem im folgenden Text + machen Sie einen Verbesserungsvorschlag:

> *"Die Universität hat einen Beschluss gefasst. Bildung ist wichtig. Wir brauchen mehr Forschung. Im Sommer fährt sie nach Italien."*

**Erwartete Lösung:**

**Problem:** Mangel an **Kohärenz** (semantischer Zusammenhang). Sätze sind isoliert, keine logische Progression. Kohäsion (Pronomen *sie* in S4) ist sogar unklar (Referent uneindeutig: Universität? Bildung? Forschung?).

**Spezifika:**
- Satz 1: konkret (Universität-Aktion).
- Satz 2: abstrakte Behauptung ohne Verbindung zu S1.
- Satz 3: Forderung ohne Kontext.
- Satz 4: völlig disparat (jemand fährt nach Italien; *sie* unklar).

**Verbesserungsvorschlag:** Welcher Satz fehlt, der die Konstellation kohärent macht? Beispielsweise:

> *"Die Universität hat einen Beschluss gefasst, der Bildung als zentrales Gut ihrer Mission bekräftigt. **Da Bildung Forschung erfordert**, will die Universität ihre Forschungsmittel um 15% erhöhen. Im Sommer fährt **die Rektorin** nach Italien, um mit Universitäten dort über Kooperationen zu sprechen."*

Verbesserungen:
1. **Kohäsion durch Konnektor**: *Da Bildung Forschung erfordert* macht logische Beziehung explizit.
2. **Klärung Referent**: *die Rektorin* statt *sie* (eindeutiger Referent).
3. **Kohärenz durch thematische Progression**: alle Sätze gehören zum Frame "Universitäts-Strategie".

**Begründung:** Kohärenz erfordert thematische Progression + logische Verkettung. Kohäsion allein (Pronomen) reicht nicht aus; Sätze müssen semantisch zusammengehören. (Cf. 04-07 §3.)

**Verweis:** [04-07 §3 Kohärenz-Diagnose](../04-system/04-07-textlinguistik.md).

## Modul 04-09 — Kontrastive Linguistik PT–DE

### Übung 04-09-A ★

**Frage:** Identifizieren Sie für jeden Bereich den Hauptkontrast PT vs. DE:

a) Wortstellung
b) Kasus-System
c) Verbalstruktur (Klammer)
d) Komposition

**Erwartete Lösung:**

a) **Wortstellung**: PT = SVO konsistent. DE = V2 im Hauptsatz (jedes Konstituent kann ins Vorfeld), VL im Nebensatz.

b) **Kasus-System**: PT = keine morphologische Kasus-Markierung; verwendet Präpositionen + Wortstellung. DE = 4 Kasus (Nom, Akk, Dat, Gen) morphologisch markiert auf NPs.

c) **Verbalstruktur (Klammer)**: PT = keine Verbalklammer; finite Verbteile bleiben zusammen. DE = Verbalklammer (LK + RK) durch trennbare Verben, Hilfsverb+Part.II, Modal+Inf.

d) **Komposition**: PT = analytisch (mit *de*: companhia de navegação a vapor). DE = produktive Synthese (Donaudampfschifffahrtsgesellschaft als 1 Wort).

**Begründung:** Diese 4 Kontraste sind die Hauptursachen für PT-falante-Schwierigkeiten in DE-Erwerb. Bewusstmachung der Kontraste = erster Schritt zur Internalisierung. (Cf. 04-09 §2 + ANHANG F.)

**Verweis:** [04-09 §2 Strukturkontraste](../04-system/04-09-kontrastive-linguistik.md), [ANHANG-F-PT-DE-KONTRASTIVE](anhaenge/ANHANG-F-PT-DE-KONTRASTIVE.md).

### Übung 04-09-B ★★

**Frage:** Übersetzen Sie folgende DE-Sätze ins PT + identifizieren Sie 2 Probleme der Übersetzung:

a) *Ich helfe dir.*
b) *Sie sagte, sie sei krank.*
c) *Wir hätten kommen sollen.*

**Erwartete Lösung:**

a) **DE → PT:** "Eu te ajudo." 
   **Problem:** DE *helfen* + Dat. → PT *ajudar* + Akk. (mit Pronomen *te/o/a* statt *lhe*). PT-falante-Risiko: PT verwendet "ajudar a alguém" oder "ajudar alguém" — das Direktobjekt-PT entspricht dem DE-Dativ.

b) **DE → PT:** "Ela disse que estava doente." (Indikativ; PT hat keinen Konj. I.)
   **Problem:** DE Konj. I (*sei*) hat keine direkte PT-Entsprechung. PT kann via Lexik distanzieren: "Segundo ela, estaria doente." (Konditional als Distanzierungs-Marker), aber im Alltag nicht praktiziert. PT nutzt Indikativ + Verbum dicendi.

c) **DE → PT:** "Deveríamos ter vindo." (Konj. II Plusquamperfekt = Condicional Composto + Inf. Pretérito).
   **Problem:** DE Modalverb-Konstruktion (*hätten ... sollen*) ist Doppelinfinitiv mit komplexer Verbalklammer; PT verwendet einfacheres Konditional-Tempus. Ohne Bewusstmachung der DE-Struktur produziert PT-falante häufig fehlerhafte Übersetzungen wie *"hätten gekommen sollen"* mit Word-by-Word-Ansatz.

**Begründung:** Übersetzungs-Drills offenbaren Kontraste konkret. PT-falante muss explizit lernen: (i) DE-Verbregierung (Dativ vs. Akkusativ), (ii) Konj.-I/II-Periphrasen ohne PT-Entsprechung, (iii) Modal-Doppelinfinitiv. (Cf. 04-09 §3 + ANHANG F.)

**Verweis:** [04-09 §3 Übersetzungs-Probleme](../04-system/04-09-kontrastive-linguistik.md), [ANHANG-F](anhaenge/ANHANG-F-PT-DE-KONTRASTIVE.md).

### Übung 04-10-B ★★

**Frage:** Erklären Sie den hermeneutischen Zirkel mit einem konkreten Beispiel aus der Lektüre eines philosophischen Textes:

**Erwartete Lösung:**

**Hermeneutischer Zirkel:** Verstehen geschieht zirkulär — Teil verweist auf Ganzes, Ganzes nur durch Teile verständlich. Vorverständnis modifiziert sich durch Detail-Lektüre.

**Konkretes Beispiel: Lektüre von Kants *Kritik der reinen Vernunft* (1781/87):**

1. **Vorverständnis**: Lerner beginnt mit allgemeinem Bild "Kant kritisiert traditionelle Metaphysik; transzendentale Frage: was kann ich wissen?"

2. **Erster Lektüre-Durchgang**: Vorrede + Einleitung gelesen → Detail-Begriffe begegnen (Anschauung, Begriff, Verstand, Vernunft) — Vorverständnis wird modifiziert: "Kant trennt Anschauung und Denken; sucht Bedingungen synthetischer Urteile a priori."

3. **Detail-Lektüre der "Transzendentalen Ästhetik"**: Begriffe Raum + Zeit als reine Anschauungsformen → erneute Modifikation: "Raum/Zeit sind nicht Eigenschaften der Welt, sondern Bedingungen unserer Wahrnehmung."

4. **Rückkehr zum Ganzen**: jetzt versteht Lerner Vorrede + Einleitung in neuem Licht (transzendentaler Idealismus als systematisches Programm).

5. **Iteration**: Detail-Lektüre der "Transzendentalen Analytik" + "Dialektik" modifizieren weiter; Verständnis des Ganzen wächst.

6. **Heideggers Pointe**: Zirkel ist nicht zu vermeiden, sondern korrekt zu betreten ("In ihn nicht hineinkommen, sondern in der rechten Weise hineinkommen.") — bewusste Vorverständnis-Reflexion + Bereitschaft zur Modifikation.

**Begründung:** Hermeneutischer Zirkel ist nicht logischer Fehler (zirkuläre Begründung), sondern erkenntnistheoretische Bedingung des Verstehens. Schleiermacher-divinatorisch + Heidegger-ontologisch differenzieren ihn. Anwendung auf Kant-Lektüre = paradigmatisch. (Cf. 04-10 §3 hermeneutischer Zirkel.)

**Verweis:** [04-10 §3 Hermeneutischer Zirkel](../04-system/04-10-hermeneutik.md).

### Übung 04-10-C ★★★

**Frage:** Wenden Sie Gadamers Begriff *Horizontverschmelzung* + *Wirkungsgeschichte* auf die Lektüre von Hegels *Phänomenologie des Geistes* (1807) heute an:

**Erwartete Lösung:**

**Wirkungsgeschichte der *Phänomenologie des Geistes*:**

1. **Direkte Nachfolge**: Junghegelianer (Marx, Bauer, Stirner) lesen Hegel materialistisch; Adorno-Kritik (1944) liest Hegel als kritische Tradition.

2. **Marxistische Tradition**: Lukács (*Geschichte und Klassenbewusstsein*, 1923) reaktualisiert Hegel via Klassenkampf-Dialektik.

3. **Französisch-Hegelianische Welle**: Kojève (1933–39 Lectures) inszeniert Hegel als Anthropologie der Anerkennung; beeinflusst Sartre, Lacan, Foucault.

4. **Analytisch-pragmatische Wiederlesen**: Brandom (*Tales of the Mighty Dead*, 2002), Pinkard (*Hegel's Phenomenology*, 1994) — Hegel als Sozialtheorie + normative Pragmatik.

5. **Zeitgenössische Erinnerung**: Honneth (*Kampf um Anerkennung*, 1992) reaktualisiert Hegel via Frankfurter Schule.

**Konsequenz für die Lektüre HEUTE:**

- Lerner liest Hegel **nicht unmittelbar**, sondern durch die Schichten dieser Wirkungsgeschichte.
- Vorverständnis ist von Marx-Kojève-Brandom-Honneth geprägt, ob bewusst oder nicht.
- *Wirkungsgeschichtliches Bewusstsein* (Gadamer) = Anerkennung dieser Vor-Konditionierung.

**Horizontverschmelzung:**

- Hegels historischer Horizont (1807, Napoleonische Kriege, Idealismus-Debatte) trifft den gegenwärtigen Horizont (post-1989, Globalisierung, Identitätspolitik).
- Beispiel: das Herr-Knecht-Kapitel (PhdG §178–196) wird heute oft via Anerkennungs-Theorie gelesen (Honneth) — eine Lesart, die Hegel nicht intendierte, aber durch unsere zeitgenössischen Probleme produktiv wird.
- Die Verschmelzung ist NICHT Aufhebung der Differenz, sondern produktives Aufeinandertreffen.

**Praktische Konsequenz für CAPSTONE-3/-4 zu Hegel:**

1. Vorverständnis explizit machen: "Ich lese Hegel via Honneth-Anerkennungs-Theorie."
2. Wirkungsgeschichte rekonstruieren (Marx → Kojève → Brandom → Honneth) als Forschungsstand.
3. Direkte Hegel-Lektüre + Sekundärliteratur in Konstellation lesen.
4. Eigene Position im Anschluss an + in Differenz zu dieser Tradition formulieren.

(Cf. 04-10 §4 Gadamer; CAPSTONE-3-AUFKLAERUNG-EXEMPLAR analog für Aufklärung.)

**Verweis:** [04-10 §4 Gadamer-Begriffe](../04-system/04-10-hermeneutik.md), [CAPSTONE-3-AUFKLAERUNG-EXEMPLAR](examples/CAPSTONE-3-AUFKLAERUNG-EXEMPLAR.md), [BEGRIFFS-GLOSSAR § Geist + Anerkennung](BEGRIFFS-GLOSSAR.md).

## Cross-Module-Übungen Stage 4

### Übung X-01 ★★★

**Frage:** Verbinden Sie Generative Syntax (04-04) + Kontrastive Linguistik (04-09) + Hermeneutik (04-10) in einer kurzen Analyse: Wie hängen die drei zusammen?

**Erwartete Lösung:**

**Verbindung der drei Module:**

1. **Generative Syntax** liefert das **formale Werkzeug** zur strukturellen Analyse jedes Satzes (X-bar, V→C-Bewegung, Phrasenstruktur). Erlaubt präzise Beschreibung dessen, was im Deutschen syntaktisch geschieht.

2. **Kontrastive Linguistik** verwendet diese Werkzeuge, um **PT-DE-Asymmetrien** strukturell zu erklären (V2 vs. SVO, Verbalklammer als V→C-Bewegung, VL als Subjunktor-blockierte V-Bewegung). Macht das, was PT-falante "intuitiv schwierig" findet, präzise erklärbar.

3. **Hermeneutik** liefert die **interpretative Rahmung**, in der formale Analyse erst sinnvoll wird. Ein Hegel-Satz syntaktisch zu zerlegen, ohne den hermeneutischen Kontext (Wirkungsgeschichte, Begriffsgeschichte, Tradition) zu kennen, produziert leere formale Übung. Umgekehrt: Hegel-Lektüre ohne syntaktische Schärfe produziert impressionistische Lektüre.

**Konkrete Synthese (Beispiel):**
Beim Lesen des Hegel-Satzes "Das Wahre ist das Ganze" (PhdG §20) operiert der Lerner:
- **Generative Syntax**: identifiziert Subj. *Das Wahre* (NP) + Kopula *ist* + Prädikativ *das Ganze* (NP). V2-Struktur. Substantivierte Adjektive als NP-Köpfe.
- **Kontrastive Linguistik**: notiert dass PT-Übersetzung "O verdadeiro é o todo" die Substantivierung verliert (PT braucht *o* als Quasi-Artikel; aber der Adjektiv-Substantivierungs-Charakter wird abgeschwächt).
- **Hermeneutik**: identifiziert die Wirkungsgeschichte (Adornos berühmte Inversion "Das Ganze ist das Unwahre", *Minima Moralia* §29) und liest beide Sätze in Konstellation; erkennt die dialektische Methode bei Hegel + ihre kritische Wendung bei Adorno.

(Cf. 04-04 + 04-09 + 04-10; CAPSTONE-3-Vorbereitung.)

**Verweis:** Cross-references in DAG.md § Caminho A (Sintaxe → Generative → Hermenêutica).

## Stage-4-Abschluss-Selbstdiagnose (Übung Stage-4-Final ★★★)

**Frage:** Verfassen Sie eine wissenschaftliche Skizze (~300W) für eine korpusbasierte Begriffsanalyse von *Bildung* mit folgenden Anforderungen:

1. Etymologische Notiz (3-4 Sätze; ahd. → nhd. + Humboldt-Erweiterung).
2. Korpus-Anfrage-Plan (DWDS + COSMAS II).
3. Mindestens 3 Sub-Traditionen identifiziert + Quellen.
4. Hermeneutische Vorverständnis-Reflexion.
5. Wissenschaftsdeutsch hoch (Konnektoren akademisch, Konj. II, FVG, Passiv).

**Erwartete Lösung (eine mögliche Realisation):**
```
Eine korpusbasierte Untersuchung des Begriffs *Bildung* hätte zunächst die 
etymologische Schichtung zu rekonstruieren. Mhd. *bildunge* — abgeleitet von 
ahd. *bilidōn* (ein Bild machen) — bezeichnet ursprünglich konkret-handwerkliche 
Erschaffung. Erst im 18. Jahrhundert vollzieht der Begriff in der Humboldtschen 
Tradition seinen entscheidenden Bedeutungssprung zur abstrakt-pädagogischen 
"Selbstkonstitution des Menschen via Auseinandersetzung mit Welt". 

Methodisch wäre die Untersuchung durch eine kombinierte Korpusanalyse zu fundieren: 
DWDS-Frequenzverlauf (1700–2025) zur Erfassung der diachronen Häufigkeit, ergänzt 
durch Wortprofil-Analyse zur synchron-semantischen Verortung; flankierend 
COSMAS II-Stichproben in periodisch geschichteten Sub-Korpora.

Hinsichtlich der Sub-Traditionen ließen sich mindestens drei rivalisierende 
Auslegungen rekonstruieren: (1) Die humboldtsche Bildung als nicht-instrumentelle 
Selbstvervollkommnung (Humboldt 1809; Schleiermacher); (2) die kritische 
Tradition, die Bildung gegen ihre Verfälschung zur "Halbbildung" verteidigt 
(Adorno 1959, *Theorie der Halbbildung*); (3) die kompetenzorientierte Reduktion, 
die Bildung mit Ausbildung verschmilzt (PISA-Diskurs, ca. 2000 ff.).

Die hermeneutische Selbstreflexion müsste explizit machen, dass der zeitgenössische 
Lese-Horizont durch die Adorno-Kritik präfiguriert ist — was die Adorno-Linie 
womöglich zugunsten der humboldtschen Tradition gewichten würde. Diese 
Vorverständnis-Reflexion bliebe entscheidend für die methodische Sauberkeit der 
Synthese, die nicht zuletzt durch die Konstellation dreier Quellengattungen 
(Primärtexte, Korpusdaten, Sekundärliteratur) zu gewährleisten wäre.
```

**Marker-Bilanz:**
- ✓ Etymologie (mhd. *bildunge* → ahd. *bilidōn* → 18. Jh. Humboldt).
- ✓ Korpus-Plan (DWDS Frequenzverlauf + Wortprofil + COSMAS II-Stichproben).
- ✓ 3 Sub-Traditionen (Humboldt + Adorno + PISA-Diskurs).
- ✓ Hermeneutische Vorverständnis-Reflexion (Adorno-Vor-Konditionierung).
- ✓ Wissenschaftsdeutsch hoch (Konj. II durchgängig — *hätte zu rekonstruieren, ließen sich rekonstruieren, müsste explizit machen, wäre zu gewichten*; Konnektoren akademisch — *Methodisch, Hinsichtlich, Diese*; FVG — *zur Erfassung, Selbstkonstitution*; Passiv — *zu fundieren, gewichten würde*).

**Selbstdiagnose:** wenn diese Skizze gelingt + alle Marker erfüllt sind + stilistisch konsistent ist, ist Stage 4 reif für CAPSTONE-4 (korpusbasierte Begriffsanalyse, ~30 pp).
