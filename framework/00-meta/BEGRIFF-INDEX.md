# BEGRIFF-INDEX — Scaffold dos 7 Begriffe canônicos

> Documento operacional cross-Capstone. Para cada um dos 7 *Begriffe* sugeridos em CAPSTONE-EVOLUTION.md, apresenta scaffold inicial: tradição filológica, Primärquellen centrais, sub-tradições contemporâneas, veículos de publicação prováveis, dificuldades específicas para aluno PT-falante.

---

## 1. Como usar este documento

1. **Antes de escolher Begriff** (cf. CAPSTONE-1 §1): ler entradas para 2-3 Begriffe candidatos.
2. **Escolha**: identificar Begriff que melhor combina (a) interesse pessoal sustentado por anos, (b) tradição filológica densa, (c) Primärquellen acessíveis, (d) sub-tradição contemporânea ativa.
3. **Plano de Capstones**: usar scaffold como base inicial; expandir via pesquisa.

Este documento **não é definitivo** — cada Begriff tem mais tradição que cabe num scaffold. Ponto de partida para investigação própria.

## 2. Aufklärung (f.) — Iluminismo

### Tradição filológica

```
Origem etimológica:  ahd. *uf-kleron 'tornar claro' → frnhd. clarificação
                     metonimia 18. Jh. para movimento iluminista.
                     
Bedeutungsverschiebung dramática:
  séc. XVII: literal (esclarecimento individual).
  séc. XVIII: metonímico (movimento histórico de Aufklärungsbewegung).
  séc. XX: criticamente revisitado (Frankfurter Schule).
  séc. XXI: termo normativo + objeto de crítica feminista, pós-colonial, etc.
```

### Primärquellen centrais

```
1. Kant, Beantwortung der Frage: Was ist Aufklärung? (1784)
   — definição programática
   
2. Mendelssohn, Über die Frage: was heißt aufklären? (1784)
   — debate paralelo a Kant
   
3. Hegel, Phänomenologie des Geistes (1807), capítulo "Die Wahrheit der Aufklärung"
   — crítica dialética da Aufklärung como auto-superação
   
4. Horkheimer/Adorno, Dialektik der Aufklärung (1944/1947)
   — crítica radical: Aufklärung dialeticamente engendra sua própria barbárie

5. Habermas, Strukturwandel der Öffentlichkeit (1962)
   — Aufklärung como espaço público burguês
   
6. Foucault, Qu'est-ce que les Lumières? (1984; em DE *Was ist Aufklärung?*)
   — leitura genealógica de Kant 1784
```

### Sub-tradições contemporâneas

- **Habermasiana**: rekonstruktive Verteidigung da Aufklärung como projeto inacabado.
- **Adorniana**: Negative Dialektik da Aufklärung; suspeita.
- **Foucaultiana**: genealogische Kritik dos dispositivos iluministas.
- **Feminist (Lloyd, Friedmann)**: Aufklärung como projeto masculino-eurocentrico.
- **Pós-colonial**: Aufklärung como cumplicidade com colonização.

### Veículos de publicação prováveis (Capstone-5)

- *Deutsche Zeitschrift für Philosophie*.
- *Mittelweg 36* (kritische Theorie).
- *Merkur* (cultural).
- *Begriffsgeschichte / Conceptual History* (Brill).

### Dificuldade específica PT-falante

```
'Iluminismo' (PT) ≠ 'Aufklärung' (DE) — perde:
  - Begriffsgeschichte koselleckiana.
  - Conexão com 'Klärung' (esclarecer).
  - Ressonância normativa contemporânea (Aufklärung = ainda projeto vivo).

Estratégias tradução: preservar 'Aufklärung' entre aspas + glossa em rodapé;
ou traduzir 'Esclarecimento' (mais fiel) em vez de 'Iluminismo' (calque hispânico).
```

### Volume bibliográfico estimado

- Stage 1-3: 5-10 livros + 5-10 artigos.
- Stage 4: 10-15 livros + 15-25 artigos.
- Stage 5: 15-25 livros + 25-50 artigos para Capstone-5.

## 3. Bildung (f.) — Formação cultural-intelectual

### Tradição filológica

```
Etimologia: ahd. bilad-i 'imagem' → mhd. bilde 'forma' → frnhd. Bildung 'formação'.
Sentido humanista séc. XVIII-XIX: auto-formação espiritual-cultural.
Conceito intraduzível em PT (≠ educação, formação, cultura).
```

### Primärquellen centrais

```
1. Wilhelm von Humboldt, Theorie der Bildung des Menschen (1793)
   — definição clássica humboldtiana

2. Schiller, Über die ästhetische Erziehung des Menschen (1794)
   — Bildung como processo ético-estético

3. Goethe, Wilhelm Meisters Lehrjahre (1795-96)
   — Bildungsroman canônico

4. Schleiermacher, Über die Religion (1799)
   — Bildung em sentido religioso-cultural

5. Adorno, Theorie der Halbbildung (1959)
   — crítica: Bildung degrada-se em Halbbildung (pseudo-formação)

6. Jaeger, Paideia (1934, em DE)
   — Bildung como herança grega
```

### Sub-tradições contemporâneas

- **Humboldtiana clássica**: Bildung como auto-formação para si mesmo.
- **Adorniana**: Halbbildung-Kritik; cultura industrial mata Bildung autêntica.
- **Pedagogia kritisch (Klafki, Mollenhauer)**: Bildung como processo crítico-emancipatório.
- **Liberale Bildungstheorie (Nussbaum em DE)**: capabilities approach.

### Veículos de publicação prováveis

- *Zeitschrift für Pädagogik*.
- *Vierteljahrsschrift für wissenschaftliche Pädagogik*.
- *Mittelweg 36*.
- Revistas filosóficas: DZPhil, *Allgemeine Zeitschrift für Philosophie*.

### Dificuldade específica PT-falante

```
'Formação' (PT) é traduções vestigial; perde:
  - Tradição humboldtiana (auto-formação não dirigida).
  - Distinção Bildung vs. Erziehung (educação dirigida).
  - Halbbildung-Kritik adorniana.

Estratégia: 'Bildung' entre aspas + glossário expandido.
```

### Volume bibliográfico estimado

Similar a Aufklärung; tradição menos massiva mas mais focada na pedagogia.

## 4. Geist (m.) — Espírito

### Tradição filológica

```
Etimologia: idg. *ǵʰeysd- 'agitar, encantar' → germ. *gaistaz 'demônio, espírito' →
            ahd. geist 'espírito, alma' → mhd. geist → nhd. Geist.

Bedeutungsverschiebung dramática:
  Cristianização: Heiliger Geist (Espírito Santo).
  Idealismo alemão (Hegel séc. XIX): Geist como mente coletiva-histórica auto-consciente.
  Hoje: 'mente, espírito, ânimo' (com adj. geistig).
```

### Primärquellen centrais

```
1. Hegel, Phänomenologie des Geistes (1807)
   — Geist como auto-desenvolvimento dialético da autoconsciência histórica

2. Hegel, Vorlesungen über die Philosophie der Weltgeschichte (1822-31)
   — Weltgeist como sujeito da história

3. Dilthey, Aufbau der geschichtlichen Welt in den Geisteswissenschaften (1910)
   — Geist como objeto das Geisteswissenschaft

4. Cassirer, Philosophie der symbolischen Formen (1923-29)
   — Geist como faculdade simbólica humana

5. Heidegger, Sein und Zeit (1927) §72-77
   — crítica do Geist hegeliano via Sein-Frage

6. Klages, Der Geist als Widersacher der Seele (1929-32)
   — crítica anti-Geist (controversa, por Lebensphilosophie)
```

### Sub-tradições contemporâneas

- **Hegeliana clássica**: Geist como motor histórico-dialético.
- **Heideggeriana**: Geist como ofuscamento da Sein-Frage.
- **Geisteswissenschaft pós-Dilthey**: método hermenêutico em ciências humanas.
- **Cognitive science (Dennett, Searle em DE)**: Geist como mind.

### Veículos de publicação prováveis

- *Hegel-Studien*.
- *DZPhil*.
- Revistas de filosofia da mente.

### Dificuldade específica PT-falante

```
'Espírito' (PT) tem ressonância religiosa que apaga sentido hegeliano coletivo-histórico.
'Mente' (PT) é cognitivo restrito; perde dimensão histórica-dialética.

Estratégia: traduzir 'Geist' como 'Espírito' (Hegel) ou 'Mente' (cognitivo);
sempre com glossa explicativa; preservar DE em primeira ocorrência.
```

## 5. Wahrheit (f.) — Verdade

### Tradição filológica

```
Etimologia: idg. *weh₁- 'verdadeiro, fiel' → germ. *waraz → ahd. wâr → 
            mhd. wâr → nhd. wahr → Wahrheit (-heit).

Tradição metafísica clássica: Wahrheit = adaequatio rei et intellectus
                              (Aristoteles, Tomás).
Heidegger Re-etymologisierung: Wahrheit ↔ gr. ἀλήθεια (a-letheia, des-velar).
Kontroverse filológica: etymon DE wahr ≠ etymon GR ἀλήθεια.
```

### Primärquellen centrais

```
1. Aristóteles, Metafísica IV (em DE: Reclam)
   — Wahrheit como adaequatio

2. Tomás de Aquino, Summa Theologiae I, q. 16 (em DE)
   — Wahrheit como conformidade

3. Kant, Kritik der reinen Vernunft (1781/1787)
   — Wahrheit como acordo-com-objeto via categorias

4. Hegel, Wissenschaft der Logik (1812-16)
   — Wahrheit como auto-desenvolvimento dialético

5. Frege, Über Sinn und Bedeutung (1892)
   — Wahrheit como Bedeutung de proposição

6. Heidegger, Vom Wesen der Wahrheit (1943)
   — Wahrheit como Unverborgenheit (re-etymologisierung Aletheia)

7. Tarski, Der Wahrheitsbegriff in den formalisierten Sprachen (1935, em DE)
   — Wahrheit semântico-formal

8. Habermas, Theorie des kommunikativen Handelns (1981)
   — Wahrheit como Geltungsanspruch comunicativo

9. Tugendhat, Vorlesungen zur Einführung in die sprachanalytische Philosophie (1976)
   — Wahrheit em filosofia analítica DE
```

### Sub-tradições contemporâneas

- **Tarski-tradição**: Wahrheit semântica formalizada.
- **Heideggeriana**: Wahrheit como Unverborgenheit (controversial, fenomenológica).
- **Habermasiana**: Wahrheit como pretensão comunicativa intersubjetiva.
- **Adorniana**: Wahrheit como momento crítico-negativo (Konstellation).

### Veículos de publicação prováveis

- *DZPhil*, *Zeitschrift für philosophische Forschung*.
- *Hegel-Studien* se foco hegeliano.
- *Heidegger Studien* (peer-reviewed).
- *Erkenntnis* (filosofia analítica).

### Dificuldade específica PT-falante

```
'Verdade' (PT) é razoavelmente direto; mas:
  - Heidegger Aletheia/Unverborgenheit perde-se em PT 'verdade'.
  - Distinção Wahrheit/Wahrhaftigkeit (Habermas) sem paralelo direto em PT.

Estratégia: usar 'verdade' como tradução padrão; preservar DE específico
em discussões técnicas (Aletheia, Unverborgenheit, Wahrhaftigkeit).
```

## 6. Macht (f.) — Poder

### Tradição filológica

```
Etimologia: idg. *māgh- 'poder, ser capaz' → germ. *mahti- → 
            ahd. maht → mhd. maht → nhd. Macht.
```

### Primärquellen centrais

```
1. Nietzsche, Der Wille zur Macht (1888 - manuscrito; 1901 - publicação póstuma)
   — Macht como princípio ontológico

2. Weber, Wirtschaft und Gesellschaft (1922)
   — Macht como autoridade tipologizada (legal, traditional, charismatisch)

3. Schmitt, Politische Theologie (1922) e Begriff des Politischen (1932)
   — Macht como decisão soberana

4. Foucault, Überwachen und Strafen (1975/1977)
   — Macht como rede de práticas disciplinares e bio-políticas

5. Arendt, Macht und Gewalt (1970)
   — Macht como acordo coletivo (vs. Gewalt)

6. Habermas, Faktizität und Geltung (1992)
   — Macht legitimada por discurso comunicativo
```

### Sub-tradições contemporâneas

- **Weberiana**: Macht-Tipologie em ciências sociais.
- **Foucaultiana**: Macht-Wissen-Komplex; Genealogie.
- **Arendtiana**: Macht como ação coletiva; vs. Gewalt instrumental.
- **Habermasiana**: Macht legitimada por procedimento discursivo.
- **Schmittiana**: Macht como decisão soberana (controversa, herança nazi-jurídica).

### Veículos de publicação prováveis

- *Soziale Welt*.
- *Mittelweg 36*.
- *Politische Vierteljahresschrift*.
- *Berliner Journal für Soziologie*.

### Dificuldade específica PT-falante

```
'Poder' (PT) é direto, mas perde:
  - Distinção Macht/Gewalt (Arendt: poder coletivo vs. violência instrumental).
  - Macht-Wissen-Komplex foucaultiano (em PT é 'poder-saber' aceitável).
```

## 7. Sein (n.) — Ser

### Tradição filológica

```
Etimologia: 3-stem suppletiv (Idg. *h₁es- + *bʰuH- + *wes-) →
           ahd. wesan/sîn → mhd. wesen/sîn → nhd. sein.

Substantivierung filosófica do Inf.: das Sein.
```

### Primärquellen centrais

```
1. Parmênides, Sobre a natureza (em DE: Reclam)
   — Sein como princípio ontológico

2. Aristóteles, Metafísica (em DE: Reclam)
   — Sein como conceito ontológico-categorial

3. Kant, KrV (1781) — capítulo "Vom Sein"
   — Sein não é predicado real

4. Hegel, Wissenschaft der Logik (1812-16) — Sein-Logik
   — Sein como categoria inicial do sistema

5. Heidegger, Sein und Zeit (1927) — texto-fundador
   — Sein-Frage; Differenz Sein/Seiende

6. Heidegger, Vom Wesen des Grundes (1929), Beiträge zur Philosophie (1936-38, póstumo)
   — Sein-Geschichte
```

### Sub-tradições contemporâneas

- **Heideggeriana**: Sein-Frage como núcleo da filosofia.
- **Hegeliana**: Sein como categoria dialética inicial.
- **Tomista (em DE: Pieper, Lotz)**: Sein como ato divino criador.
- **Ontologia analítica (Quine em DE)**: Sein-Frage como problema lingüístico.

### Veículos de publicação prováveis

- *Heidegger-Jahrbuch*, *Heidegger Studies*.
- *DZPhil*, *Zeitschrift für philosophische Forschung*.
- *Hegel-Studien* (se Sein hegeliano).

### Dificuldade específica PT-falante

```
'Ser' (PT) é direto em uso geral, mas:
  - Heidegger Sein/Seiende não tem distinção morfológica clara em PT
    ('ser/ente' é tentativa de tradução, com perda).
  - Substantivierung do Inf. ('das Sein') é morfo-sintaticamente mais natural em DE.

Estratégia: preservar 'Sein/Seiende' alemão em discussões heideggerianas;
em outros contextos, 'ser/ente' aceita-se com perda.
```

### Recomendação

**Begriff difícil para iniciantes.** Apenas escolher Sein como Begriff de Capstone se aluno tem **base filosófica sólida** + **interesse heideggeriano genuíno**. Sem isso, Begriff frustra.

## 8. Sprache (f.) — Linguagem

### Tradição filológica

```
Etimologia: ahd. sprâhha → mhd. sprâche → nhd. Sprache.
Ressonância filosófica: Wittgenstein, Heidegger, Gadamer transformam Sprache em
                       Begriff filosófico central.
```

### Primärquellen centrais

```
1. Humboldt, Über die Verschiedenheit des menschlichen Sprachbaues (1836)
   — Sprache como Weltansicht; ergon e energeia

2. Wittgenstein, Tractatus logico-philosophicus (1921)
   — Sprache como imagem lógica do mundo

3. Wittgenstein, Philosophische Untersuchungen (1953)
   — Sprache como Sprachspiele em Lebensformen

4. Heidegger, Unterwegs zur Sprache (1959)
   — Sprache como casa-do-Sein; Sprechen vs. Sagen

5. Gadamer, Wahrheit und Methode (1960)
   — Sprache como medium da Verstehen

6. Habermas, Theorie des kommunikativen Handelns (1981)
   — Sprache como base universal-pragmática
```

### Sub-tradições contemporâneas

- **Wittgensteiniana**: Sprache como prática (Sprachspiel).
- **Heideggeriana**: Sprache como casa-do-Sein.
- **Gadameriana**: Sprache como medium hermenêutico.
- **Habermasiana**: Sprache como base universal-pragmática.
- **Linguística teórica (Chomsky em DE)**: Sprache como faculdade inata.

### Veículos de publicação prováveis

- *Zeitschrift für Sprachwissenschaft*.
- *Sprache und Literatur*.
- *Wittgenstein-Studien* (Wittgensteiniana).
- *Heidegger Studies*.
- *DZPhil*.

### Dificuldade específica PT-falante

```
'Linguagem' (PT) é direto em uso geral, mas:
  - Sprache filosófico (Heidegger, Gadamer, Wittgenstein) tem ressonâncias específicas.
  - Distinção Sprache/Rede/Sprechen (Heidegger) sem paralelo morfológico em PT.

Estratégia: preservar termos alemães específicos em análises filosóficas.
```

### Recomendação

**Begriff meta-reflexivo**: você usa linguagem para estudar linguagem. Excelente para quem ama meta-níveis filosóficos. Conexão direta com toda a metodologia FATHOM-Deutsch.

## 10. Critérios para escolha

```
Pergunta-Test:
1. Eu sustentaria interesse neste Begriff por 5+ anos?
2. Tenho acesso a Primärquellen (biblioteca, e-books)?
3. Sub-tradição contemporânea me motiva?
4. Posso ler texto-âncora (uma obra primária) em DE original?
5. Veículo de publicação Capstone-5 ressoa com meu objetivo?

Se 4-5/5: Begriff é candidato sólido.
Se 2-3/5: considerar outros Begriffe.
Se 0-1/5: re-avaliar interesse profundo em germanística filosófica.
```
