## Modul 04-01 — Historische Linguistik (~70 Karten)

### Sprachperioden

```
Q: 5 Sprachperioden des Deutschen?
A: Idg. (Indoeuropäisch, ~3500 v. Chr.) — 
   Ahd. (Althochdeutsch, ~750–1050) — 
   Mhd. (Mittelhochdeutsch, ~1050–1350) — 
   Frnhd. (Frühneuhochdeutsch, ~1350–1650) — 
   Nhd. (Neuhochdeutsch, ~1650–heute).
Tag: 04-01

Q: Welche Lautverschiebung trennt Hochdeutsch von Niederdeutsch?
A: Zweite (Hochdeutsche) Lautverschiebung (~500–800 n. Chr.).
   Beispiel: germ. *p* → hd. *pf/f* (Apfel/auf vs. niederdt. Appel/op).
Tag: 04-01

Q: Was ist das Benrather Linie?
A: Isoglosse, die Hoch- von Niederdeutsch trennt (verläuft etwa entlang Benrath bei Düsseldorf).
   Nördlich: maken (NL/Plattdt.); Südlich: machen.
Tag: 04-01

Q: Charakteristik des Mhd. lautlich?
A: Vollvokale in unbetonten Silben (gegen Nhd. Schwa-Reduktion); 
   Beispiel: mhd. *taga* (Pl.) → nhd. *Tage*.
   Editorial: Zirkumflex ô markiert Vokallänge in Lachmann-Edition.
Tag: 04-01

Q: Wann beginnt die Lutherbibel-Periode des Frnhd.?
A: 1522 (NT) bzw. 1534 (Vollbibel). Standard-bildender Effekt für ostmitteldeutsches DE 
   als Grundlage des modernen Standardhochdeutschen.
Tag: 04-01
```

### Lautverschiebungen

```
Q: Erste (Germanische) Lautverschiebung — Beispielregel?
A: idg. *p t k* → germ. *f þ h* (Grimms Gesetz).
   Beispiel: lat. *pater* → germ. *fader* → engl. *father* / dt. *Vater*.
Tag: 04-01

Q: Verners Gesetz — Worum geht's?
A: Modifikation von Grimms Gesetz: idg. stimmlose Plosive werden im Germ. zu stimmhaften 
   Frikativen, wenn der Akzent NICHT direkt davor liegt.
   Beispiel: griech. *patḗr* → germ. *fader* (mit Stimmhaftigkeit), 
   nicht **fáþer*.
Tag: 04-01

Q: Zweite (Hochdt.) Lautverschiebung — Beispiele?
A: germ. *t* → hd. *ts/s* (Wasser, zwei vs. niederdt. Water, twee).
   germ. *p* → hd. *pf/f* (Pfeffer, auf vs. NL pepper, op).
   germ. *k* → hd. *kx/ch* (machen, ich vs. NL maken, ik).
Tag: 04-01
```

### Mhd. Editorial-Konventionen

```
Q: Was bedeutet â / ê / î / ô / û in Mhd.-Editionen?
A: Lange Vokale (Lachmann-Notation 1820–1850).
   Beispiel: mhd. *liep* → mhd.-Edition *liep* mit kurzem i; 
   *lîp* (Leib) mit langem î.
Tag: 04-01

Q: Übersetzen Sie: "wîp ist sælig"
A: "Eine Frau (Weib) ist selig/glücklich". 
   *wîp* = Weib (mit langem î); *sælig* = selig.
Tag: 04-01

Q: Übersetzen Sie: "ich hân daz vernomen"
A: "Ich habe das vernommen / gehört". 
   *hân* = habe; *vernomen* = vernommen.
Tag: 04-01
```

## Modul 04-02 — Etymologie und Wortgeschichte (~60 Karten)

### Etymon-Identifikation

```
Q: Etymon von *Wahrheit*?
A: ahd. *wārheit* < *wār* "wahr" + Suffix *-heit*; 
   idg. *wēr-* "treu, vertrauenswürdig"; verwandt mit lat. *verus*, ir. *fīr*.
Tag: 04-02

Q: Etymon von *Bildung*?
A: ahd. *biladunga* < mhd. *bildunge* "Erschaffung, Form". Wurzel *bilden* 
   < ahd. *bilidōn* "ein Bild machen". Zur abstrakten "Selbstkonstitution" 
   im 18. Jh. semantisch erweitert (Humboldt).
Tag: 04-02

Q: Etymon von *Geist*?
A: ahd. *geist*; verwandt mit altsächsisch *gēst*, ae. *gāst* "Geist, Atem". 
   Idg. *gheis-* "wundern, schauern". Christlich-religiös als "spiritus" 
   (Heiliger Geist) lehnübersetzt.
Tag: 04-02

Q: Etymon von *Aufklärung*?
A: nhd. Bildung < *auf-* + *klären* < ahd. *klāra* "klar, hell". 
   Lehnübersetzung von französisch *éclaircissement* / *Lumières*; 
   semantisch "philosophisches Programm" seit Kant 1784.
Tag: 04-02

Q: Etymon von *Begriff*?
A: ahd. *bigrīfan* "umfassen, ergreifen"; im 17. Jh. nominalisiert zu *Begriff* 
   = das Erfasste, das Konzept; semantisch parallel zu lat. *conceptus* < *concipere*.
Tag: 04-02
```

### Wortgeschichte (Bedeutungswandel)

```
Q: Bedeutungswandel von *artig*?
A: Mhd. *artec* = "angeboren, von guter Art" → frnhd. = "höflich" → 
   nhd. = "wohlerzogen, freundlich, brav" (vor allem für Kinder).
Tag: 04-02

Q: Bedeutungswandel von *geil*?
A: ahd. *geil* = "fröhlich, lustig"; mhd. = "üppig, kraftvoll"; 
   frnhd. = sexuell konnotiert ("geil sein"); 
   nhd. (Jugendsprache 1990er ff.) = "toll, super, geil" (Bedeutungs-Aufwertung).
Tag: 04-02

Q: Pejorisierung — Beispiel?
A: *Weib*: ahd. *wīb* neutrale Bezeichnung für Frau → nhd. pejorativ-rauh 
   (vs. neutrales *Frau*). 
   Anderes Beispiel: *Dirne* (mhd. neutral "Mädchen") → nhd. pejorativ "Prostituierte".
Tag: 04-02
```

### Pfeifer / Kluge — Standardwerke

```
Q: Welches Werk ist Standard für deutsche Etymologie wissenschaftlich?
A: Wolfgang Pfeifer, *Etymologisches Wörterbuch des Deutschen* (DWDS).
   Online frei verfügbar via dwds.de. Standard für moderne Forschung.
Tag: 04-02

Q: Kluge vs. Pfeifer — Unterschied?
A: Kluge (*Etymologisches Wörterbuch der deutschen Sprache*, Berlin: De Gruyter, 
   25. Aufl. 2011) = klassisch, kompakt, bewährt.
   Pfeifer (DWDS-online) = moderner, ausführlicher, frei zugänglich.
   Beide gleichberechtigt zitierfähig.
Tag: 04-02

Q: Wann verwendet man Grimm-DWB?
A: Wenn historische Belege ab ca. 1500 mit Originalzitaten gewünscht sind.
   *Deutsches Wörterbuch* der Brüder Grimm (1854–1961). 
   Online via dwds.de oder woerterbuchnetz.de.
Tag: 04-02
```

## Modul 04-04 — Generative Syntax (~70 Karten)

### Grundbegriffe

```
Q: Was ist X-bar-Theorie?
A: Universelle Phrasenstruktur: jede Phrase X-Phrase (XP) hat Spezifizierer + 
   X-bar (X' = Kopf X + Komplement). Schema: [XP Spec [X' X Comp]].
   Anwendung: NP, VP, AP, PP, CP, IP — alle nach diesem Schema.
Tag: 04-04

Q: Was ist V→C-Bewegung im Deutschen?
A: Hauptsatz V2-Stellung: das finite Verb bewegt sich in den C-Kopf (Comp-Position).
   Im Nebensatz wird C von Subjunktor besetzt → V bleibt in V/I (= Verbletzt).
   Erklärt V2 vs. VL-Asymmetrie.
Tag: 04-04

Q: Was sagt das CP/IP/VP-Schichtenmodell?
A: Satz hat 3 funktionale Schichten:
   - VP (Verbalphrase): θ-Rollen-Vergabe
   - IP (Inflectional Phrase): Tempus, Kongruenz
   - CP (Complementizer Phrase): Komplementierer, Wh-Bewegung
   Bewegung läuft von unten (VP) nach oben (CP).
Tag: 04-04
```

### Theorien-Phasen

```
Q: 3 Phasen der Generativen Grammatik nach Chomsky?
A: 1. Standard Theory (1965) — Aspects of the Theory of Syntax.
   2. GB-Theorie (1981) — Lectures on Government and Binding (Module: θ-Theorie, 
      Bindungstheorie, Kasus-Theorie, Bewegungstheorie).
   3. Minimalismus (1995 ff.) — Reduktion auf Merge + Move + Agree.
Tag: 04-04

Q: Was ist θ-Theorie?
A: Theta-Rollen-Vergabe: jeder Argumentplatz eines Verbs hat eine semantische Rolle 
   (Agens, Patiens, Thema, Experiencer, Goal, Source).
   Theta-Kriterium: jedes Argument trägt genau eine θ-Rolle; jede θ-Rolle wird 
   genau einem Argument zugeordnet.
Tag: 04-04

Q: Was ist Bindungstheorie (Prinzipien A, B, C)?
A: Prinzip A: Reflexivpronomen muss in seiner Bindungs-Domäne gebunden sein 
   (sich, mich).
   Prinzip B: Pronomen muss in seiner Bindungs-Domäne frei sein (er, sie).
   Prinzip C: R-Ausdruck muss überall frei sein (Maria, der Mann).
Tag: 04-04
```

### Anwendung auf Deutsch

```
Q: Wie erklärt Generative Syntax dt. Verbalklammer?
A: V2-Hauptsatz: finites Verb in C; nicht-finite Verbteile (Part.II, Inf., 
   trennbares Präfix) bleiben in V → Klammer.
   VL-Nebensatz: C ist von Subjunktor besetzt; Verb bleibt in V → Verbletzt.
Tag: 04-04

Q: Wie erklärt sie die Wh-Bewegung?
A: Wh-Wort wird in CP-Spec bewegt; finites Verb bewegt sich nach C; übrige 
   Konstituenten bleiben unten. Resultat: V2 mit Wh-Wort im Vorfeld.
   Beispiel: "Was hast du gestern gemacht?" → [CP Was [C hast] [IP du gestern 
   gemacht]].
Tag: 04-04

Q: Wie erklärt Generative Syntax Topikalisierung im Vorfeld?
A: Topikalisierte Konstituente bewegt sich in CP-Spec (analog zu Wh-Bewegung). 
   Akzent + Pragmatik markieren, ob Topik oder Fokus.
Tag: 04-04
```

## Modul 04-05 — Formale Semantik (~60 Karten)

### Wahrheitsbedingungen

```
Q: Was sagt die Wahrheitskonditionale Semantik?
A: Die Bedeutung eines Satzes besteht in seinen Wahrheitsbedingungen — 
   den Bedingungen, unter denen er wahr ist.
   Programmatisch: Frege, Tarski, Davidson, Montague.
Tag: 04-05

Q: Was sagt das Frege-Prinzip (Kompositionalität)?
A: Die Bedeutung eines komplexen Ausdrucks ist eine Funktion der Bedeutungen 
   seiner Teile + der Art ihrer Kombination.
   Bei Frege: *Sinn* + *Bedeutung* (Referenz) systematisch unterschieden.
Tag: 04-05

Q: Was unterscheidet *Sinn* von *Bedeutung* (Frege)?
A: *Bedeutung* (Referenz) = der Gegenstand, auf den ein Ausdruck zeigt 
   ("Morgenstern" + "Abendstern" = Venus).
   *Sinn* = die Art und Weise des Gegebenseins ("Morgenstern" + "Abendstern" 
   haben unterschiedlichen Sinn, gleiche Bedeutung).
Tag: 04-05
```

### Quantorenlogik

```
Q: Wie übersetzt man "Alle Studenten lernen" in Quantorenlogik?
A: ∀x (Student(x) → Lernen(x))
   ("Für alle x: wenn x ein Student ist, dann lernt x.")
Tag: 04-05

Q: Wie übersetzt man "Manche Studenten lernen"?
A: ∃x (Student(x) ∧ Lernen(x))
   ("Es existiert (mindestens) ein x, sodass x ein Student ist und x lernt.")
Tag: 04-05

Q: Skopus-Ambiguität — Beispiel?
A: "Jeder Student liebt ein Buch."
   Lesart 1: ∀x ∃y (Student(x) → (Buch(y) ∧ Liebt(x,y))) — jeder hat irgendein Buch.
   Lesart 2: ∃y ∀x (Buch(y) ∧ (Student(x) → Liebt(x,y))) — es gibt ein bestimmtes 
   Buch, das jeder liebt.
Tag: 04-05
```

### Montague-Grammatik

```
Q: Was ist die Idee der Montague-Grammatik?
A: Natürliche Sprache wird mit denselben formalen Mitteln behandelt wie 
   formale Sprachen — jede syntaktische Operation entspricht einer semantischen 
   Operation (Komposition).
   Klassisch: Richard Montague, "The Proper Treatment of Quantification in 
   Ordinary English" (1973).
Tag: 04-05

Q: Was ist λ-Abstraktion in der Semantik?
A: Funktional-abstraktive Notation. *λx.P(x)* = "die Funktion, die jedem x 
   den Wahrheitswert von P(x) zuordnet".
   Beispiel: *λx.lernen(x)* = die Eigenschaft "lernen".
Tag: 04-05
```

### Anwendung im DE

```
Q: Wie analysieren Sie *Das Auto fährt schnell* semantisch?
A: Schnell(Fahren(Das_Auto)) — Adverb modifiziert Verb-Phrase.
   In Lambda-Notation: λx.Fahren(x) wird durch Adverb modifiziert zu 
   λx.(Schnell(Fahren(x))).
Tag: 04-05

Q: Wie unterscheiden sich *kein Mann* und *nicht ein Mann* semantisch?
A: "kein Mann" = ∀x ¬(Mann(x) ∧ ...) — universelle Negation der Existenz.
   "nicht ein Mann" (in negativer Lesart) = ¬∃x (Mann(x) ∧ ...) — 
   Negation der Existenz; im Skopus normalerweise gleich.
   Pragmatischer Unterschied: *kein* = standard, *nicht ein* = markiert/kontrastiv.
Tag: 04-05
```

## Modul 04-06 — Diskursanalyse (~50 Karten)

### Foucault-Begriffe

```
Q: Was ist *Diskurs* bei Foucault?
A: Geregelte Gesamtheit von Aussagen + Praktiken, die definiert, was als 
   Wissen, Wahrheit + Realität in einer Epoche gilt. Nicht reine Sprache, sondern 
   sprachlich-institutionelle Praxis.
   Quelle: Foucault, *Archäologie des Wissens* (1969).
Tag: 04-06

Q: Was ist *Dispositiv* bei Foucault?
A: Heterogene Anordnung von Diskursen, Institutionen, Gesetzen, Architekturen, 
   Wissenschaften, die als Strategie auf historische Probleme antwortet.
   Klassisches Beispiel: Sexualitäts-Dispositiv (Foucault, *Wille zum Wissen*, 1976).
Tag: 04-06

Q: Was ist *Genealogie* bei Foucault (Methode)?
A: Historische Untersuchung der Entstehungsbedingungen von Diskursen + 
   Praktiken — anti-essentialistisch, anti-progressivistisch.
   Versucht zu zeigen: was als "natürlich" gilt, hat eine kontingente Geschichte.
   Klassisch: *Überwachen und Strafen* (1975).
Tag: 04-06

Q: Was unterscheidet Archäologie von Genealogie bei Foucault?
A: Archäologie (1969) = synchron-strukturalistisch; analysiert Aussagen-Regularitäten.
   Genealogie (1971 ff.) = diachron-historisch; verfolgt Entstehung + Wandel von 
   Diskursen + Macht-Wissen-Komplexen.
Tag: 04-06
```

### Kritische Diskursanalyse (KDA)

```
Q: Was ist Kritische Diskursanalyse?
A: Empirische Methode zur linguistischen Analyse politisch-gesellschaftlicher 
   Diskurse mit kritischer Absicht (Macht, Ideologie, Hegemonie aufdecken).
   Hauptvertreter: Norman Fairclough, Ruth Wodak, Siegfried Jäger.
Tag: 04-06

Q: 3 Analyse-Ebenen der KDA nach Fairclough?
A: 1. **Text** — sprachliche Analyse (Lexik, Syntax, Kohäsion).
   2. **Diskursive Praxis** — Produktion, Distribution, Rezeption.
   3. **Soziale Praxis** — gesellschaftlicher Kontext + Macht-Verhältnisse.
Tag: 04-06

Q: Wer ist Siegfried Jäger?
A: Diskursanalytiker (Duisburger Schule). Hauptwerk: *Kritische Diskursanalyse — 
   Eine Einführung* (1993). Methode: Diskursstränge, Diskurspositionen, 
   Diskursebenen.
Tag: 04-06
```

### Anwendung

```
Q: Wie analysieren Sie ein Bundestagsdebatten-Plenarprotokoll diskursanalytisch?
A: 1. Diskursstränge identifizieren (Themen-Cluster).
   2. Akteure-Positionen verorten (Partei, Regierung, Opposition).
   3. Hegemoniale vs. marginalisierte Stimmen markieren.
   4. Lexikalische + rhetorische Strategien analysieren (Framing, Topoi).
   5. Diskurs-Effekte rekonstruieren (welche Realität wird konstituiert?).
Tag: 04-06
```

## Modul 04-07 — Textlinguistik (~50 Karten)

### Kohäsion vs. Kohärenz

```
Q: Unterschied Kohäsion vs. Kohärenz?
A: **Kohäsion** = sprachlich-formale Verknüpfung von Text-Elementen 
   (Pronomen, Konnektoren, Wiederaufnahme).
   **Kohärenz** = inhaltlich-logischer Zusammenhang (Thematische Progression, 
   semantische Relationen).
   Text kann kohäsiv ohne kohärent sein (Wortsalat mit Pronomen) und umgekehrt.
Tag: 04-07

Q: 5 Kohäsionsmittel?
A: 1. Pronominalisierung (Personal-, Demonstrativ-Pron als Wiederaufnahme).
   2. Konnektoren (und, aber, weil, deshalb).
   3. Lexikalische Wiederaufnahme (Synonyme, Hyperonyme, Wiederholung).
   4. Tempus-Konsistenz (Präteritum-Ketten in Erzählung).
   5. Definitheits-Markierung (der/ein als bekannt/neu-Marker).
Tag: 04-07
```

### Textsorten

```
Q: Klassifikation Textsorten nach Brinker?
A: Brinker (*Linguistische Textanalyse*, 1985) gruppiert nach 
   Texttyp + Textfunktion:
   - Informativ (Nachricht, Bericht)
   - Appellativ (Kommentar, Rede)
   - Obligativ (Vertrag, Antrag)
   - Kontaktiv (Brief, Gruß)
   - Deklarativ (Urkunde, Testament)
Tag: 04-07

Q: Was sind Textsortenmerkmale?
A: Konstellation von:
   1. Funktion (informativ/appellativ/...)
   2. Situation (Kontext, Audience)
   3. Sprache (Register, Stil)
   4. Struktur (Aufbau, Argumentation)
Tag: 04-07
```

### Thematische Progression

## Modul 04-08 — Korpuslinguistik (~50 Karten)

### Korpora-Inventar

```
Q: Was ist DWDS?
A: Digitales Wörterbuch der deutschen Sprache. Online-Portal (dwds.de) mit:
   - Wörterbuch (Pfeifer, DWB, anderen)
   - Korpus-Belegen (Kernkorpus 20./21. Jh., Zeitungs-Korpus)
   - Frequenzanalyse (Wortverlauf-Diagramme)
   - Kollokationsprofile (Wortprofil)
   Frei zugänglich. Standard für Begriffsanalyse.
Tag: 04-08

Q: Was ist COSMAS II?
A: Korpus-Suchsystem des IDS Mannheim (Institut für Deutsche Sprache).
   Zugang: cosmas2.ids-mannheim.de (Registrierung erforderlich).
   Korpora: DEReKO (Deutsches Referenzkorpus, ~50 Mrd. Tokens).
   Eingebaute Suchsprache mit Operatoren (NEAR, AND, NOT, etc.).
Tag: 04-08

Q: Wann verwendet man DWDS vs. COSMAS II?
A: DWDS = schneller, weniger flexibel; gut für Frequenzverlauf + Kollokationsprofil.
   COSMAS II = mächtiger, komplexere Anfragen; Standard in akademischer Forschung.
   Empfehlung: DWDS für Erkundung; COSMAS II für systematische Studie.
Tag: 04-08
```

### Methode

```
Q: Was ist Kollokation linguistisch?
A: Häufiges Auftreten zweier Wörter im Text in räumlicher Nähe (typischerweise 
   ±5 Wörter). Misst die statistische Bindung.
   Beispiel: *Aufklärung* kollidiert oft mit *Vernunft, Mündigkeit, Kritik, Kant*.
Tag: 04-08

Q: Was ist Log-Dice (Kollokations-Maß)?
A: Statistisches Maß zur Stärke der Kollokation, normalisiert zwischen 0 und 14.
   Höhere Werte = stärkere Bindung. Standard im Sketch Engine.
   Alternative Maße: T-Score, MI (Mutual Information), Log-Likelihood.
Tag: 04-08

Q: Was ist Frequenzverlauf-Analyse?
A: Diachrone Verfolgung der Häufigkeit eines Lemmas über Zeit (gewöhnlich pro Jahr 
   oder pro Dekade). Visualisiert in Liniendiagramm.
   Anwendung: zeigt Aufstieg + Abstieg eines Begriffs (z.B. Aufklärung-Peak im 
   späten 18. Jh.).
Tag: 04-08
```

## Modul 04-09 — Kontrastive Linguistik PT–DE (~70 Karten)

### Strukturkontraste systematisch

```
Q: Hauptunterschied Wortstellung PT vs. DE?
A: PT = SVO (Subjekt-Verb-Objekt) konsistent. 
   DE = V2 im Hauptsatz (jedes Konstituent kann im Vorfeld), 
   VL im Nebensatz (Verbalklammer + Verbletzt).
   Daraus folgen die meisten PT-falante-Schwierigkeiten.
Tag: 04-09

Q: Wie löst PT-falante das DE-VL-Problem?
A: Häufiger Fehler: PT-falante setzt Verb in Mitte des Nebensatzes (analog zu PT).
   ("*weil ich gehe nach Hause" statt "weil ich nach Hause gehe").
   Lösung: bewusste Konstruktion VL-Drill bis Internalisierung 
   (typisch 6–12 Monate aktive Praxis).
Tag: 04-09

Q: 4-Kasus-System DE vs. fehlendes Kasus-System PT?
A: DE markiert 4 Kasus (Nom, Akk, Dat, Gen) auf NPs morphologisch (Artikel + Adj).
   PT verwendet Präpositionen + Wortstellung; keine Kasus-Markierung der NP.
   Konsequenz: PT-falante muss DE-Kasus-Wahl explizit lernen + drill 
   (Verbregierung, Präp-Rektion, NP-Funktion).
Tag: 04-09
```

### Konj. I/II — keine direkte Entsprechung

```
Q: Wie übersetzt man Konj. I in indirekter Rede ins PT?
A: PT hat keinen direkten Konj.-I-Modus. Lösung:
   - Modus indicativo + Verb des Sagens: "Ele disse que ela é doente."
   - Modus subjuntivo (eingeschränkt): "Ele alegou que ela fosse doente." (formell)
   - Markierung Distanzierung via Lexik: "Segundo ele, ela seria doente."
Tag: 04-09

Q: Wie übersetzt man Konj. II Irrealis Vergangenheit ins PT?
A: "Wenn ich es gewusst hätte, wäre ich nicht gekommen" → 
   "Se eu soubesse / Se eu tivesse sabido, não teria vindo."
   PT verwendet Subjuntivo Imperfeito + Condicional Composto.
Tag: 04-09
```

### Modalverben — epistemisch/deontisch

```
Q: Wie übersetzt man "Er muss krank sein" (epistemisch) ins PT?
A: "Deve estar doente." (deve + Inf. epistemisch).
   Distinkt von deontischer Lesart: "Ele tem que/deve estar lá às 9h" (Pflicht).
Tag: 04-09

Q: Wie übersetzt man "Er muss arbeiten" (deontisch)?
A: "Ele tem que trabalhar" oder "Ele deve trabalhar" 
   (deve mit deontischer Lesart, schwächer als ter que).
   Risiko PT-falante: *deve* falsch generalisieren als nur deontisch.
Tag: 04-09
```

### Wortbildung — Komposition

```
Q: Hauptunterschied DE Komposition vs. PT?
A: DE = produktive Komposition (1 Wort: Donaudampfschifffahrtsgesellschaft).
   PT = analytisch (2-3 Wörter mit *de*: companhia de navegação a vapor do Danúbio).
   PT-falante muss DE-Komposition als produktive Operation aktiv lernen.
Tag: 04-09

Q: Genus arbiträr im DE — wie kompensiert PT-falante?
A: PT hat 2 Genus (m/f) mit etwas natürlicher Korrelation (-o m, -a f).
   DE hat 3 Genus (m/f/n) ohne sichere phonologische Marker.
   Kompensation: jedes Lemma mit Artikel lernen (das Mädchen, die Sonne, der Mond).
   Genus-Suffix-Regel internalisieren (-ung f, -chen n, -er m, -keit f).
Tag: 04-09
```

## Modul 04-10 — Hermeneutik klassischer Texte (~80 Karten)

### Hermeneutik-Geschichte

```
Q: 4 Hauptphasen der hermeneutischen Tradition?
A: 1. Klassische Hermeneutik (Schleiermacher, ca. 1800) — Verstehen als 
      grammatisch + psychologisch.
   2. Geisteswissenschaftliche H. (Dilthey, ca. 1900) — Erleben als Quelle des Verstehens.
   3. Existential-ontologische H. (Heidegger 1927; Gadamer 1960) — Verstehen als 
      Seinsweise des Daseins.
   4. Diskurs-/Kritische H. (Habermas, Ricœur, ca. 1970 ff.) — Verstehen als 
      kommunikatives Handeln.
Tag: 04-10

Q: Schleiermacher — was sind die zwei Verstehens-Aspekte?
A: 1. **Grammatisches Verstehen** = sprachlich-semantisch (Wort + Syntax + 
      sprachliche Konvention).
   2. **Psychologisches Verstehen** = Eindringen in das Bewusstsein des Autors 
      (göttliches Errichten dessen, was er meinte).
   Beide müssen iterieren — divinatorisch + komparativ.
Tag: 04-10
```

### Hermeneutischer Zirkel

```
Q: Was ist der hermeneutische Zirkel?
A: Verstehen geschieht zirkulär: Teil verweist auf Ganzes, Ganzes nur durch Teile 
   verständlich. Vorverständnis modifiziert sich durch Detail-Lektüre.
   Bei Heidegger ontologisiert: Zirkel ist nicht zu vermeiden, sondern korrekt zu 
   betreten ("In ihn nicht hineinkommen, sondern in der rechten Weise hineinkommen.")
Tag: 04-10

Q: Heideggers "Vorhabe / Vorsicht / Vorgriff"?
A: Strukturmomente des Verstehens (*Sein und Zeit* §32):
   - **Vorhabe** = das gesamte Worüber des Verstehens.
   - **Vorsicht** = die Sicht auf das, woraufhin verstanden wird.
   - **Vorgriff** = die begriffliche Vorausnahme der Auslegung.
   Sie konstituieren den hermeneutischen Zirkel ontologisch.
Tag: 04-10
```

### Gadamer-Begriffe

```
Q: Was ist *Horizontverschmelzung* (Gadamer)?
A: Verstehen geschieht als Verschmelzung des historischen Horizonts des Textes 
   mit dem gegenwärtigen Horizont des Lesers. Nicht-Aufhebung der Differenz, 
   sondern produktives Aufeinanderstoßen.
   Quelle: *Wahrheit und Methode* (1960), Teil 2.
Tag: 04-10

Q: Was ist *Wirkungsgeschichte* (Gadamer)?
A: Geschichte der Wirkungen + Auslegungen, die einem Text vorgeschaltet sind. 
   Der Leser steht nie unmittelbar vor dem Text, sondern in einer 
   Auslegungs-Tradition, die seinen Verstehens-Horizont prägt.
Tag: 04-10

Q: Wirkungsgeschichtliches Bewusstsein — was?
A: Bewusstsein dafür, dass das eigene Verstehen historisch-traditionell konditioniert 
   ist. Erkenntnis-theoretisch: Anerkennung der Vorurteile als unaufhebbare Bedingung 
   des Verstehens.
Tag: 04-10
```

### Anwendung — Kant lesen

```
Q: Welche hermeneutische Schwierigkeit hat Kant *Kritik der reinen Vernunft* (1781/87)?
A: 1. Lange Sätze (Vorklassischer-Stil mit Hyper-Subordination + Verbalklammer).
   2. Begriffe in Pre-Stabilisations-Phase (Anschauung, Begriff, Verstand, Vernunft 
      mit kantischen Spezial-Bedeutungen).
   3. 1781 vs. 1787 zwei Auflagen mit großen Änderungen (B-Auflage hat zusätzliche 
      Vorrede + revidierte Deduktion).
   4. Akademie-Ausgabe: AA III + IV (1787 + 1781) Standard-Zitierform.
Tag: 04-10

Q: Welche Akademie-Ausgabe-Sigle für Kant?
A: AA = Akademie-Ausgabe (Kant's gesammelte Schriften, hg. Königlich Preußische 
   Akademie der Wissenschaften, Berlin 1900 ff.).
   Standard-Zitierform: AA Bd.:Seite. Beispiel: AA IV:421 (= Bd. 4, S. 421 — 
   *Grundlegung zur Metaphysik der Sitten*).
Tag: 04-10

Q: Wie liest man Hegel *Phänomenologie des Geistes* (1807) hermeneutisch?
A: 1. Begriffsumkehr beachten (Hegels Methode: Begriffe entfalten sich dialektisch).
   2. Bewusstseins-Stufen-Reihenfolge folgen (sinnliche Gewissheit → Wahrnehmung → 
      Verstand → Selbstbewusstsein → Vernunft → Geist).
   3. Lesehilfen verwenden (z.B. Hegel-Kommentar von Hyppolite, Fink, Pinkard).
   4. Suhrkamp-Werkausgabe Bd. 3 als Standard.
Tag: 04-10

Q: Heideggers *Sein und Zeit* (1927) — Lese-Strategie?
A: 1. Glossar-Aufbau: Heideggers Spezial-Begriffe (Dasein, In-der-Welt-sein, Sorge, 
      Geworfenheit, Eigentlichkeit/Uneigentlichkeit, Vorhandenheit/Zuhandenheit) 
      systematisch sammeln.
   2. Re-Etymologisierungen erkennen (Sein → seinhaft; Wahrheit → Un-verborgenheit; 
      Existenz → Ek-sistenz).
   3. §1–7 (Einleitung) + §31–34 (Verstehen + Auslegung + Sprache) als zentrale Stellen.
   4. Niemeyer-Ausgabe als Standard; GA = Gesamtausgabe Bd. 2.
Tag: 04-10
```
