# 03-10, Hörverstehen colloquial — Filme, Serien, authentische Konversation

> 📚 **Dialekte + Soziolekte erkennbar** in [ANHANG L — Dialekte](../00-meta/anhaenge/ANHANG-L-DIALEKTE.md). **Audio/Video-Quellen** kanonisch in [AUDIO-VIDEO-CANON.md](../00-meta/AUDIO-VIDEO-CANON.md).

---

## 1. Sprachliches Problem

Stage 1-3 hat den Lerner zu erudite-Hörverstehen geführt: Tagesschau, Deutschlandfunk, Adorno-Vorträge, Habermas-Reden. Was systematisch fehlt: **colloquiale Hörrealität**.

Tagesschau-Sprecher (cf. AUDIO-VIDEO-CANON.md) folgen Konventionen, die im Alltag **nicht** gelten:
- **Tempo**: 140-160 W/min (artifically slow); colloquial: 180-220 W/min.
- **Hochsprache** rein; colloquial: regionalfärbung dominant.
- **Keine Modalpartikeln** (außer "freilich" gehoben); colloquial: doch/ja/halt/mal/eben in 50%+ der Frasen.
- **Klar artikulierte Konsonanten**; colloquial: klitisiert (*ich hab*, *kannste*, *isses*).
- **Vorbereitete Skripte**; colloquial: Hesitation, Selbstkorrektur, *also-naja-tja*.

Aprendizes adultos travam in:
- **Tatort verstehen** ohne Untertitel: Tempo + Pragmatik + regionale Färbung overwhelming.
- **Familienkonversation in München** verstehen: Bayrisch + Modalpartikel-Saturation.
- **YouTube-Vlogger** verstehen: Jugendsprache + Code-Switching + Anglizismen.
- **Politische Talkshows**: simultanes Sprechen mehrerer Diskutanten.

Sem este módulo:
- Aprendiz liest Adorno wunderbar, aber Tatort ohne Untertitel ist nicht-zugänglich.
- Capstone-2 schriftlich exzellent; Reise nach Berlin frustrierend (Familien-Konversation overwhelming).
- Phonetische Theorie (01-08) bleibt theoretisch ohne realistic Hörmaterial-Konfrontation.

Este módulo schließt **die Lücke zwischen artificial Tagesschau-Hören und realistic colloquialem Hören** systematisch ein.

## 2. Harte Theorie

### 2.1 Hörverstehen-Pyramide (DaF-Standard)

```
Stufe 1 (A1):       Einzelne Wörter, Zahlen, Daten.
Stufe 2 (A2):       Kurze Skripte (Wegbeschreibung, Zeitansage); 
                    Standard-Tempo, klar artikuliert.
Stufe 3 (B1):       Tagesschau-langsamer / Tagesschau-Standard. 
                    Akademische Vorträge mit erudite-Tempo.
Stufe 4 (B2):       Spielfilme bei Standardtempo. Dichte Vorträge. 
                    Erste regionale Färbung erkennbar.
Stufe 5 (C1+):      Alle Genre + Tempi + Dialekte + Slang + 
                    Code-Switching + Hesitation + Selbstkorrektur.
Stufe 6 (C2):       Native-Niveau Hörverstehen.
```

**Stage 3 zielt auf Stufe 4 — Spielfilm-Hörverstehen** mit gelegentlichen Modalpartikel-Verwirrungen.

### 2.2 Was unterscheidet colloquiales Hörverstehen?

#### A) Tempo

```
Native colloquial:        180-220 W/min  (alltäglich)
Native akademisch:        120-140 W/min  (Vortrag)
Tagesschau-Sprecher:      140-160 W/min  (Mittelweg)
Spielfilm-Dialog:         160-200 W/min  (variabel)
Reality-TV / Vlog:        200-260 W/min  (sehr schnell)

Stage-3-Lerner-Verstehen: ~120-150 W/min komfortabel
                          ~160-180 W/min mit Anstrengung
                          >180 W/min schwierig ohne Wiederholung
```

#### B) Klitisierung

DE-colloquial verkürzt + verschmilzt häufig:

```
"Ich habe"        →  "ich hab'"        ([ɪç hap])
"Du hast"         →  "du hast"         (Standard) oder "haste"
"Kannst du..."    →  "kannste..."      ([kanstə])
"Wir sind"        →  "mir sind"        (Bayrisch)
"Es ist"          →  "isses" / "is's"  ([ɪsəs])
"Wie geht's"      →  "wie geht's"      (Standard) oder "wie's geht?"
"Was ist los?"    →  "was'n los?"      (Berlinerisch) / "wos'n los?" (bayrisch)
```

PT-falante muss **passiv erkennen** — produzieren als Lerner unangebracht (wirkt aufgesetzt).

#### C) Modalpartikel-Saturation

```
Tagesschau:        ~0-1 Modalpartikel pro Minute.
Akademischer V:    ~1-2 Modalpartikel pro Minute (gehoben: freilich, indessen).
Filmedialog:        ~5-10 Modalpartikel pro Minute (doch / ja / mal / halt).
Familien-Konv.:    ~10-15 Modalpartikel pro Minute (Modalpartikel-Sättigung).
```

Wer Modalpartikel nicht aktiv erkennt + interpretiert, **versteht** den Dialog nicht — Modalpartikel sind nicht semantisch leer, sie tragen pragmatischen Akzent.

#### D) Hesitation + Diskursmarker

```
"Also, weißt du, das ist halt so..."     (3 Diskursmarker in 1 Satz)
"Naja, tja, ich denke..."                (2 Hesitationsmarker)
"Ach so! Verstehe."                       (Ach-so + Verstehe)
```

Filme + Talkshows + Tandem-Konversation enthalten Hesitation in 50%+ der Frasen. Lerner muss erkennen + filtern.

### 2.3 Methodische Strategien

#### A) Untertitelte Phase (Stage 3 Anfang)

```
1. Spielfilm mit DE-Untertiteln schauen.
2. Pause bei jeder Szene; Untertitel lesen + Audio-Frase wiederholen.
3. ~30-60 min pro Sitzung.
4. 1-2 Sitzungen pro Woche.
```

#### B) Halbblind Phase (Stage 3 Mitte)

```
1. Spielfilm zuerst ohne Untertitel ansehen (10-min Ausschnitt).
2. Dann mit Untertiteln nochmals.
3. Vergleich: was wurde nicht verstanden? warum?
4. Notizen + Anki-Cards für unbekannte Lexik / Modalpartikeln / Klitisierungen.
```

#### C) Blind Phase (Stage 3 Ende — B2 erreicht)

```
1. Spielfilm einmal ohne Untertitel ansehen.
2. Verständnis-Quote selbst einschätzen (% verstanden).
3. Schwierige Szenen markieren + zurückblicken.
4. Bei Verständnis < 70%: zurück zu untertitelter Phase.
```

#### D) Shadowing als Brücke

Shadowing (cf. 01-08 §AUDIO-VIDEO-CANON.md):

```
1. Spielfilm-Ausschnitt 5-10 Sätze.
2. Audio abspielen + 1-2 Sek. später laut nachsprechen.
3. 5-10× wiederholen; Tempo + Akzent + Modalpartikeln intern reproduzieren.
4. ~10-15 min pro Tag.
```

Shadowing aktiviert **simultan** Hörverstehen + Aussprache + Phrase-Memorierung. Für Stage-3-Lerner non-substituierbar.

### 2.4 Filme + Serien — kanonische Auswahl

#### A) Tatort (ARD, seit 1970)

**Beschreibung:** Krimi-Reihe, sonntäglich auf ARD. ~30 regionale Tatort-Teams (Berlin, München, Hamburg, Münster, Köln, Wien, Zürich, etc.) — jede Region mit eigener Sprachfärbung.

**Niveau:** B2 vorne; B2-C1 mit Variation.

**Empfohlene Tatort-Folgen für Lerner:**
- *Tatort: Münster* (Boerne+Thiel; humorvoller Standard, langsam).
- *Tatort: Wien* (mit Wienerisch — Stufe 5).
- *Tatort: München* (mit bayrischer Färbung — Stufe 5).
- *Tatort: Köln* (Standard + Kölnisch).

**Quellen:** ARD-Mediathek (https://www.ardmediathek.de/tatort) für ~30 Tage nach Ausstrahlung kostenlos.

#### B) Babylon Berlin (Sky / ARD, 2017-)

**Beschreibung:** Krimi-Drama im Berlin der späten 1920er-Jahre. Historisches Berlinerisch + Hochdeutsch + Jugendsprache der Weimarer Republik.

**Niveau:** B2-C1 (historisches DE + dichter Plot).

**Schwierigkeit:** Tempo + Slang der 1920er + Code-Switching mit Jiddisch + Russisch.

**Wert:** zeigt regionale + historische Variation gleichzeitig.

#### C) Dark (Netflix, 2017-2020)

**Beschreibung:** Netflix-Sci-Fi-Drama in fiktivem deutschem Kleinstadt. Standard-Hochdeutsch sehr klar, langsam, mit philosophischem Sub-Text.

**Niveau:** B2 ideal — perfekte Brücke zwischen Tagesschau-Standard und Spielfilm-Realität.

**Vorteil:** Untertitel + Transkripte international verfügbar; Tempo komfortabel; Plot dicht aber nicht überfordernd.

#### D) Goodbye, Lenin! (Wolfgang Becker, 2003)

**Beschreibung:** Komödie-Drama um die Wende 1989–90. Standard-DE + DDR-Lexik (Trabbi, Jugend-Pioniere, etc.).

**Niveau:** B2 zentral.

**Wert:** kulturhistorische Tiefe — DDR-Wortschatz wird nicht in Tagesschau heute gehört.

#### E) Lola rennt (Tom Tykwer, 1998)

**Beschreibung:** Schneller Berliner Kult-Film; 80 min Tempo durchgehend.

**Niveau:** B2-C1 (Tempo + Berlinerisch).

**Wert:** Berliner Schnauze + Tempo-Training.

#### F) Andere Empfehlungen

- *Das Leben der Anderen* (2006) — DDR + langsamer Plot, B1-B2 zentral.
- *Lola Montès* (klassisch) + *Wir können auch anders* (1993) — Komödie.
- *Bad Banks* (Serie 2018-) — Bankenwelt + Frankfurter Akzent.
- *How To Sell Drugs Online (Fast)* (Netflix 2019-) — Jugendsprache zentral.
- *Fack ju Göhte* (2013, 2015, 2017) — Lehrer-Komödie + sehr aktuelle Jugendsprache.
- *Die Welle* (2008) — Schule + Pädagogik-Drama.
- *Sonnenallee* (1999) — DDR + Jugend in Ost-Berlin.

#### G) Was zu vermeiden Stage 3

```
- Hollywood-Synchronisationen: artificial Tempo + Lippensynchronisation 
  produzieren Sprache ungewöhnlich.
- Reality-TV (Bauer sucht Frau, etc.): zu chaotisch, schnell, schlecht 
  artikuliert.
- Anime-Synchros: spezifische Untergrundlexik.
- Privat-TV-Talkshows (Markus Lanz, Anne Will können OK sein, aber sehr 
  variabel).
```

## 4. Sprachliche Aufgabe — Tatort-Analyse

### Aufgabe

Wählen Sie **eine** Tatort-Folge (~90 min) auf der ARD-Mediathek. Empfohlen: *Tatort: Münster* (Boerne+Thiel) oder *Tatort: Berlin*.

#### Phase 1 — untertitelt (Sitzung 1, ~120 min)

```
1. Folge mit DE-Untertiteln ansehen.
2. Bei jeder unbekannten Vokabel pausieren + Wort + Bedeutung notieren.
3. 5-10 Modalpartikeln markieren (welche? Wie übersetzen?).
4. 3-5 Klitisierungen markieren (Klitisierungsformen + Standard-Form).
5. Notizen: ~30-50 unbekannte Wörter / Phrasen / Modalpartikeln.
```

#### Phase 2 — halbblind (Sitzung 2, ~120 min)

```
1. Folge ohne Untertiteln ansehen.
2. Verständnis-Quote schätzen (~%).
3. 5 schwierige Szenen markieren.
4. Bei Wiederholung mit Untertiteln: was war das Hindernis? 
   (Tempo? Akzent? Lexik? Modalpartikel?)
5. 5 Anki-Cards für die schwierigsten Phrasen erstellen.
```

#### Phase 3 — Shadowing (Sitzung 3, ~60 min)

```
1. Eine 5-min-Szene auswählen (gerne intensives Dialog).
2. 10× shadowen (mit ~1-2 Sek. Verzögerung).
3. Eigene Aussprache mit Original vergleichen — Aufnahme machen.
4. 5 phonetische Eigenheiten notieren (Auslautverhärtung, /r/, Modalpartikel).
```

### Output

Schriftliche Reflexion (~600 W) in DE oder PT-BR:

1. Tatort-Folge identifizieren (Folgennummer + Titel + Datum + Region).
2. Verständnis-Quote vor + nach Untertitelt-Phase.
3. 5-10 Modalpartikel-Beispiele aus der Folge + ihre Funktion.
4. 3-5 Klitisierungen aus der Folge + Standard-Pendant.
5. Phonetische Beobachtungen (Auslautverhärtung, /r/, Akzent, regionale Färbung).
6. Reflexion: was wurde im Vergleich zu Tagesschau-Hören anders gefordert?

Após terminar, peça o **Praktisches Tor**.

## 5. Erweiterungen und Verbindungen
