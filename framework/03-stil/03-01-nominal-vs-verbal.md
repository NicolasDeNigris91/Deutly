# 03-01, Nominaler vs. verbaler Stil

## 1. Sprachliches Problem

A escolha entre nominaler e verbaler Stil é o **eixo estilístico mais consequente** do alemão escrito. Cada registro favorece um polo; cada gênero textual exige calibração específica. Aprendizes adultos travam em:

- **Default verbal calcado de PT/EN**: produzem Aufsatz acadêmico em registro narrativo, soando como blog em vez de Wissenschaftsdeutsch.
- **Nominalitis (excesso nominal)**: imitando Bürokratendeutsch sem domínio, produzem prosa ofuscada onde nada é argumentável.
- **Não diagnosticar Stilbruch**: misturar registros num mesmo Aufsatz.
- **Não dominar transformações nominal↔verbal**: dada uma frase nominal, falham em produzir equivalente verbal e vice-versa.

Sem este módulo:
- Você lê Adorno e perde a função estilística da nominalização.
- Você produz Aufsatz acadêmico que soa coloquial ou que soa burocrático demais — sem ponto de equilíbrio.
- Você falha em escolher entre `Anwendung finden` (FVG nominal) e `angewendet werden` (Passiv verbal) conforme contexto.

## 2. Harte Theorie

### 2.1 Definição operacional

**Nominaler Stil**: prosa caracterizada por:
- Alta densidade de Substantivierungen (verbais e adjetivais).
- FVG saturadas.
- Genitivketten longas.
- Cópula + NP-Prädikativ (`X ist die Y`).
- Passiv impessoal frequente.
- Agente apagado / em PP-anafórica.
- Frases longas com encadeamentos atributivos.

**Verbaler Stil**: prosa caracterizada por:
- Verbos plenos como predicado central.
- Aktiv com Subjekt-agente explícito.
- Tempos finitos diversificados.
- Frases mais curtas, dinâmicas.
- Substantivierungen reduzidas; sufixo -ung apenas onde necessário.
- Modalverben em uso deontisch ou epistemisch direto.

### 2.2 Diagnóstico — sinais de cada Stil

| Sinal | Nominaler Stil | Verbaler Stil |
|---|---|---|
| Densidade Substantivos abstratos | alta (`Durchführung, Berücksichtigung, Anwendung, Erkenntnis`) | baixa |
| FVG | frequente (`zur Sprache bringen, in Frage stellen, Anwendung finden`) | rara |
| Verbos plenos transitivos | poucos | maioria |
| Aktiv vs. Passiv | Passiv impessoal frequente | Aktiv com agente |
| Estrutura frasal | hipotática longa | parataxis curta |
| Subjekt no Vorfeld | menos frequente (Topikalisierung de outros constituintes) | default |
| Tempora dominantes | Präs. + Perf. (atemporais) | Prät. + Perf. (narrativos) |
| Modalverben | epistemisch + Konj. II (hedge) | deontisch direto |
| Vocabulário | abstrato, operacional | concreto, eventivo |

### 2.3 Pares paralelos — transformações nominal↔verbal

#### Substantivierung de Verb-Inf.

```
Verbal:    Wir untersuchen die Frage.
Nominal:   Die Untersuchung der Frage erfolgt durch uns.
           (mais nominal ainda: Eine Untersuchung der Frage liegt vor.)
```

#### FVG vs. verbo simples (cf. 02-06)

```
Verbal:    Die Regel wird angewendet.
Nominal:   Die Regel findet Anwendung. / Die Regel kommt zur Anwendung.
```

#### Passiv impessoal vs. Aktiv com man

```
Aktiv-man:    Man muss die Faktoren berücksichtigen.
Passiv:       Die Faktoren müssen berücksichtigt werden.
Nominal-FVG:  Die Berücksichtigung der Faktoren ist erforderlich.
              (mais nominal: Eine Berücksichtigung der Faktoren ist erforderlich, 
              um zu Erkenntnissen zu gelangen.)
```

#### Genitivkette para encadear conceitos

```
Verbal:    Wir haben verstanden, was Adorno gemeint hat, als er die 
           Identität als falsch bezeichnete.
Nominal:   Adornos Bezeichnung der Identität als falsch erschließt sich 
           aus der Lektüre seiner Schrift.
```

### 2.4 Distribuição por registro / gênero

| Registro / Gênero | Stil dominante |
|---|---|
| **Wissenschaftsdeutsch hoch** (Habermas, Luhmann, Adorno) | Nominaler |
| **Bürokratendeutsch / Recht** (BGB, VwVfG) | Nominaler hipertrofiado |
| **Aufsatz acadêmico** | Nominaler com calibração |
| **Feuilleton FAZ/NZZ** | Híbrido — Stilfiguren + nominal acadêmico + verbal narrativo |
| **Leitartikel / Kommentar** | Híbrido com tendência verbal argumentativa |
| **Reportagem** | Verbaler com inserções nominais para dados |
| **Glosse satírica** | Verbaler com Stilfiguren irônicas |
| **Roman / Erzählung** | Verbaler dominante; nominais filosóficos opcionais |
| **Bildzeitung-Stil** | Verbaler agressivo, frases curtas |
| **Tagesschau / Nachricht** | Misto, com Sachlichkeit |
| **Coloquial / Fala** | Verbaler |

### 2.5 Adorno — caso paradigmático de nominaler Stil hoch

Adorno é **virtuose extremo** do nominaler Stil em filosofia. Estratégia distinctiva:

#### Nominalisation dos Subjekte abstratos + verbalização do predicado

```
Die Wirklichkeit hat sich verfinstert.
↑ Subjekt = Substantivierung (Wirklichkeit ← wirklich + -keit)
                             ↑ Predikativ = Verb pleno (sich verfinstern)
```

#### Genitivketten saturadas

```
Der Begriff der Identität des bürgerlichen Subjekts in der spätkapitalistischen Phase.
   |       |          |              |                    |
   N       Gen-attr   Gen-attr      attributive PP        attributive PP
```

#### Topikalisierung do Prädikativs (cf. 02-08)

```
Falsch ist der Begriff der Identität.
Verfehlt ist die Hoffnung auf das gerechte Leben.
Aufgehoben ist die Wahrheit, die einmal Wahrheit hieß.
```

#### Frase aforística + Atemporalität

Adorno tende a Präsens / Perfekt atemporal (não Prät. narrativo) — codifica que as proposições valem **sempre**, não em uma narrativa específica.

### 2.6 Calibração — quando usar nominaler Stil em Aufsatz

#### Apropriado para nominal

- Definitionen e Begriffsklärung.
- Sintese de teorias / posições alheias.
- Hedge acadêmico ("Eine Erwägung der Frage legt nahe, dass...").
- Distância autoral em apresentação de teses controversas.

#### Apropriado para verbal

- Argumentação própria ativa ("Ich argumentiere, dass... / Wir zeigen, dass...").
- Ilustração via exemplos.
- Crítica direta (Aktiv direto: "Adorno irrt, wenn er behauptet...").
- Conclusão / Schluss com tese assertiva.

#### Híbrido recomendado em Aufsatz

```
Begriffsklärung:           nominal saturado
Forschungsstand:           nominal + híbrido (cita autores em Konj. I + Aktiv)
Hauptteil:                 híbrido com argumentação verbal ativa
Diskussion:                verbal mais ativo
Schluss:                   verbal assertivo
Literaturverzeichnis:      nominal padronizado
```

### 2.7 Diagnóstico — Stilbruch

Stilbruch nominal/verbal ocorre quando registros incompatíveis aparecem na mesma frase ou parágrafo:

```
Stilbruch (nominal+verbal sem coerência):
"Die Anwendung der Regel erfolgt automatisch und das ist halt einfach so."

Coerente nominal:
"Die Anwendung der Regel erfolgt automatisch."

Coerente verbal:
"Die Regel wird automatisch angewendet, das ist halt einfach so."
```

`das ist halt einfach so` é fala coloquial Modalpartikel-saturada (`halt, einfach`), incompatível com nominal acadêmico.

### 2.8 Pipeline diagnóstico

Quando lendo:
1. Inventário de Substantivierungen + FVG no parágrafo.
2. Densidade de Genitivketten.
3. Distribuição Aktiv vs. Passiv.
4. Estrutura frasal: hipotática longa ou parataxis curta?
5. Diagnóstico de registro.

Quando escrevendo:
1. Determinar registro e gênero.
2. Escolher stil dominante (nominal / verbal / híbrido).
3. Identificar momentos de transição (Begriffsklärung → Argumentation → Diskussion).
4. Ajustar densidade nominal por seção.
5. Auditar Stilbruch.

## 4. Sprachliche Aufgabe

### Texto-âncora

**Theodor W. Adorno — *Negative Dialektik*** (1966), Einleitung. Texto fundador da kritischen Theorie em sua forma sintaticamente mais densa.

> "Die philosophische Reflexion versichert sich des Nichtbegrifflichen im Begriff. Sonst wäre, nach Kants Verdikt, dieser leer, am Ende kein Begriff von etwas und damit nichtig. Die Erkenntnis indessen, die etwas erkennen will, muss Mehr als das Begriffliche denken können. Nur durch solch ein Mehr wird sie ihrem Begriff gleich. Die Unterscheidung von 'pour soi' und 'an sich' ist von der Sache her, was darüber gedacht wird. Adorno's Vorgehen besteht darin, die Identität des Begriffs mit dem Bezeichneten in Frage zu stellen, ohne den Begriff aufzugeben."

(Composto a partir de fragmentos canônicos do estilo Adorno. Para passagens integrais, consultar Suhrkamp, *Negative Dialektik*, GS Bd. 6.)

### Tarefa

Análise escrita, **800-1100 palavras** em PT-BR.

1. **Inventário Substantivierungen**: identificar **toda Substantivierung** no trecho (Verb-Inf., Adj.-Subst., Subst.-Subst.). Mínimo 12. Para cada: forma + Genus + Genitiv-Sg.
2. **FVG identificadas**: localizar e classificar (cf. 02-06).
3. **Genitivketten**: traçar cada cadeia Gen. encontrada. Quantos níveis? Qual o referente final?
4. **Transformação verbal**: pegar 3 frases nominais densas e reescrever em registro verbal coloquial. Comparar perda + ganho.
5. **Análise da estratégia adorniana**: como Adorno **personifica abstrações** (Reflexion, Erkenntnis, Begriff, Unterscheidung)? Como o Subjekt-NP funciona como agente ativo?
6. **Topikalização**: identificar Vorfeld-Choices não-default (cf. 02-08).
7. **Stilkritik**: Adorno é frequentemente acusado de prosa inacessível. Defenda ou critique a opção pelo nominaler Stil hoch — qual a relação entre densidade sintática e conteúdo crítico?

Após terminar, peça o **Praktisches Tor**.
