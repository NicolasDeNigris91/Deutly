# 02-04 — Passivkonstruktionen (Deutsche Fassung)

> Parallel-Adaptation. v3.0.

## 1. Sprachliches Problem

DE hat **3 distinkte Passive** + Ersatzformen. Wissenschaftsdeutsch + Verwaltungsdeutsch operieren passiv-saturiert.

## 2. Harte Theorie

### 2.1 werden-Passiv (Vorgangspassiv) — 3 Tempora

**Präsens**: *Die Aufsätze werden korrigiert.*  
**Perfekt**: *Die Aufsätze sind korrigiert worden.* (sein + Part.II + worden; *worden* ohne ge-)  
**Futur I**: *Die Aufsätze werden korrigiert werden.*

Funktion: Vorgang in Verwirklichung (Prozess).

### 2.2 sein-Passiv (Zustandspassiv)

**Standard**: *Die Tür ist geschlossen.* (Zustand-Resultat)

Distinktion zu werden-Passiv:
- *Die Tür wird geschlossen.* = Vorgang (jemand schließt sie jetzt).
- *Die Tür ist geschlossen.* = Zustand (sie ist bereits geschlossen).

### 2.3 bekommen-Passiv (Adressatenpassiv)

**Standard**: *Ich bekomme ein Buch geschenkt.* (= Indir.-Obj. wird Subj.)

Nur bei Verben mit Dat.-Empfänger (geben, schenken, empfehlen, anbieten, zusenden, ...).

Synonyme: kriegen-Passiv (umgangssprachlich); erhalten-Passiv (gehoben).

### 2.4 Agens-Markierung

- **von + Dat.**: Person/Institution-Akteur.
> *Der Brief wurde **vom Sekretär** unterschrieben.*

- **durch + Akk.**: Mittel/Ursache.
> *Das Haus wurde **durch ein Erdbeben** zerstört.*

### 2.5 Modal + Passiv

**Konstruktion**: Modal + Part.II + werden.

> *Der Brief muss geschrieben werden.* (Standard)

**Modal + Konj.II + Plusquamperfekt + Passiv** (komplex):
> *Der Brief hätte geschrieben werden müssen.* (Doppelinfinitiv: Part.II *geschrieben* + Hilfsverb-Inf. *werden* + Modal-Inf. *müssen*)

### 2.6 Passiv-Ersatzformen

**(a) sein + zu + Inf.**: Modal-äquivalent (= muss/kann ... werden).
> *Der Brief ist zu schreiben.* (= muss geschrieben werden)

**(b) sich lassen + Inf.**: Möglichkeits-Passiv.
> *Der Text lässt sich übersetzen.* (= kann übersetzt werden)

**(c) Reflexiv mit Subj.-Affinität**: 
> *Das Buch verkauft sich gut.* (= wird gut verkauft)

### 2.7 Unpersönliches Passiv

Bei intransitiven Aktivitätsverben:
> *Es wird getanzt.* / *Hier wird gearbeitet.*

## 3. Texto-âncora

Eisenberg Bd. 2 *Der Satz*, Passiv-Kapitel.

## 4. Sprachliche Aufgabe

(a) Aktiv → werden-Passiv-Transformation für 25 Sätze (alle Tempora).
(b) sein- vs. werden-Passiv-Differenzierung für 15 Belege.
(c) Modal+Passiv-Drill: 10 Sätze in Konj.-II-Plusquamperfekt-Passiv konstruieren.
