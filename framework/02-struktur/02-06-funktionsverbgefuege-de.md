# 02-06 — Funktionsverbgefüge (Deutsche Fassung)

> Parallel-Adaptation. v3.0.

## 1. Sprachliches Problem

FVG = phraseologische Verbindung von Funktionsverb (lexikalisch entleert) + Substantiv (Bedeutungsträger). Pivotal in Wissenschafts-, Verwaltungs-, Juristen- + Politiksprache.

PT hat keine direkte Entsprechung — PT-falante muss FVG aktiv lernen + integrieren.

## 2. Harte Theorie

### 2.1 FVG-Definition

**3 Kriterien**:
1. Funktionsverb hat lexikalisch entleerte Bedeutung.
2. Substantiv trägt die Bedeutung.
3. Verbindung phraseologisch fixiert (kein freier Austausch).

**Beispiel**: *zur Anwendung kommen* = **angewendet werden** (Passiv-Äquivalent).
> NICHT freie Verbindung wie *in den Garten ziehen*.

### 2.2 Häufige Funktionsverben

bringen, kommen, finden, stehen, nehmen, machen, geben, ziehen, führen, halten, treffen, üben, erheben, leisten, gewinnen, treten, setzen, legen.

cf. ANHANG G FVG-CANONICA: >250 FVG nach 18 Funktionsverben + Domänen-Markierung.

### 2.3 Beispiel-Inventar (mit Vollverb-Äquivalent)

| FVG | Vollverb | Domäne |
|---|---|---|
| eine Entscheidung treffen | entscheiden | neutral / Politik |
| zur Anwendung kommen | angewendet werden | Wissenschaft / Recht |
| Bezug nehmen auf | sich beziehen auf | Wissenschaft / Bürokratie |
| in Frage stellen | bezweifeln / problematisieren | Wissenschaft |
| Stellung beziehen | sich positionieren | Politik / Journalistik |
| eine These vertreten | argumentieren | Wissenschaft |
| Kritik üben an | kritisieren | Wissenschaft / Politik |
| Widerstand leisten | sich widersetzen | Politik |
| Rechnung tragen | berücksichtigen | Wissenschaft / Recht |
| in Anspruch nehmen | nutzen | Bürokratie / Recht |

### 2.4 Stiltransformation

**Verbalstil → Nominalstil via FVG**:

> Verbal: *Wir entscheiden.*  
> Nominal mit FVG: *Wir treffen eine Entscheidung.*

Funktion: erhöht Distanzierung + Distanzierung; macht Aussage formaler.

**Wann FVG-saturiert**: Wissenschafts-, Verwaltungs-, Juristen- + Politik-Texten. Cf. 06-C1 Recht; 06-C3 Technik.

**Wann FVG vermeiden**: Belletristik + Konversation + Feuilleton (außer pointiert).

### 2.5 FVG mit Passivierung

FVG erlauben Passivierung:
> *Wir treffen eine Entscheidung.* → *Eine Entscheidung wird (von uns) getroffen.*

Substantiv wird Subj. des Passivs.

## 3. Texto-âncora

ANHANG G FVG-CANONICA. + Helbig/Buscha *Deutsche Grammatik*, FVG-Kapitel.

## 4. Sprachliche Aufgabe

(a) Vollverb → FVG-Transformation für 25 Verben.
(b) FVG-Domänen-Identifikation für 20 FVG aus Anhang G.
(c) Aufsatz-Stiltransformation: 100W Verbalstil → Nominalstil mit ≥5 FVG.
