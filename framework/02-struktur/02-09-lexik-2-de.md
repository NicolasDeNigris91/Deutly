# 02-09 — Lexik II (Deutsche Fassung)

> Parallel-Adaptation. v3.0.

## 1. Sprachliches Problem

Stage-2-Lexik = ~5000 Lemmata operationale, kollokationsorientiert. Übergang von Grundwortschatz (Stage 1: ~2000) zu argumentativ-akademischem Wortschatz.

Domänen-Schwerpunkte: Politik, Wirtschaft, Wissenschaft, Argumentation.

## 2. Harte Theorie

### 2.1 Akademische Konnektoren

5-Cluster:

**Kausal-konsekutiv**: folglich, mithin, demnach, somit, infolgedessen.
**Konzessiv**: gleichwohl, dennoch, indessen, nichtsdestoweniger.
**Adversativ**: jedoch, hingegen, indessen, freilich.
**Additiv**: überdies, ferner, des Weiteren, darüber hinaus.
**Referentiell**: hinsichtlich, bezüglich, in Bezug auf, mit Blick auf.

### 2.2 Argumentations-Verben gradiert

5-Stufen Sicherheit:

```
konstatieren (neutral, deskriptiv)
> postulieren (axiomatisch-systematisch)
> argumentieren (mit Begründung)
> vermuten (schwach; Hypothese)
> unterstellen (Sprecherkritik; oft pejorativ)
```

Plus Spezifika:
- darlegen, erläutern, explizieren, ausführen (Erklärung).
- nachweisen, belegen, demonstrieren, aufzeigen (Beweis).
- hinterfragen, problematisieren (Kritik).

### 2.3 Begriffs-Synonymie

| Alltagssprache | Akademisch |
|---|---|
| Idee | Konzeption / These / Annahme |
| Argument | Begründung / Beleg |
| Problem | Frage / Aporie / Schwierigkeit |
| wichtig | wesentlich / zentral / fundamental |
| wahrscheinlich | vermutlich / höchstwahrscheinlich |

### 2.4 Adverbien graduierend

5-Stufen-Skala "wichtig":
> peripher / nebensächlich / wesentlich / zentral / fundamental / unverzichtbar.

5-Stufen-Skala "wahrscheinlich":
> möglich / vermutlich / wahrscheinlich / höchstwahrscheinlich / gewiss / zweifellos.

### 2.5 Kollokationen wissenschaftlich

**These + Verb**: aufstellen / vertreten / verteidigen / verwerfen / revidieren / stützen.
**Frage + Verb**: aufwerfen / erörtern / behandeln / beantworten / offenlassen.
**Begriff + Verb**: einführen / definieren / verwenden / präzisieren / problematisieren.

### 2.6 Phraseologisch fixierte Junkturen

- *im Übrigen*, *gleichwohl*, *insofern*, *insoweit*.
- *hinsichtlich*, *bezüglich*, *im Hinblick auf*.
- *vor dem Hintergrund*, *im Lichte*, *in Anbetracht*.

### 2.7 Wortschatz-Aufbau-Strategie

(cf. STUDY-PROTOCOL §2 + ANKI-FRAMEWORK)

- Anki-Karten frasal (mit Beleg-Kontext + Kollokations-Marker).
- Aus authentischen Wissenschaftstexten (Habermas, Adorno) extrahieren.
- Domänen-cluster aufbauen (Politik / Wirtschaft / Wissenschaft).

## 3. Texto-âncora

Mittelpunkt B2 (Klett); Aspekte B2 (Klett); Erkundungen B2 (Schubert) — Wortschatz-Sektionen. + Tschirner *Häufigkeitswörterbuch* B2-Niveau.

## 4. Sprachliche Aufgabe

(a) Konnektoren-Synonymie-Drill: 25 alltagssprachliche Konnektoren → 5 akademische pro Originale.
(b) Argumentations-Verb-Drill: 15 Sätze mit graduierter Sicherheit.
(c) Wortschatz-Anki-Aufbau: 200 neue Lemmata in 4 Wochen.
