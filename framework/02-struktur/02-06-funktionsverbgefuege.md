# 02-06, Funktionsverbgefüge — nominaler Stil

## 1. Sprachliches Problem

Funktionsverbgefüge (FVG) são uma classe **idiosincrática** de construções alemãs onde **um verbo semanticamente leve combina com um nomalisador-Substantiv** para formar uma unidade semântica fixa. *zur Sprache bringen, Anwendung finden, in Frage kommen, Bezug nehmen auf, in Anspruch nehmen* — não são "frases verbais" comuns mas **idiomatic-semilexicalisierten Konstruktionen** com Verbalvalenz fixa.

FVG são o **idioma do Bürokratendeutsch, Recht, Wissenschaftsdeutsch**: leitura de BGB, Verwaltungsrecht, Habermas, Luhmann depende de reconhecimento de FVG. Substituí-las por verbo simples destrói o registro.

Aprendizes adultos travam em:

- **Não reconhecer FVG**: ler 'Anwendung finden' palavra-por-palavra como 'achar aplicação', perdendo o sentido idiomático 'ser aplicado'.
- **Errar a combinação fixa**: produzir `*einen Beschluss machen` em vez de `einen Beschluss fassen`.
- **Confundir registros**: usar FVG em fala coloquial (soa parodicamente burocrático) ou evitá-las em Aufsatz acadêmico (perde-se densidade).
- **Perder Passiv codificado**: 'zur Anzeige kommen' = `angezeigt werden` — ignorar a equivalência produz prosa redundante.

Sem este módulo:
- Você lê BGB, Verwaltungsverfahrensgesetz, contratos, sentenças judiciais como tradução literal e perde o sentido.
- Você produz Aufsatz acadêmico denso sem FVG, soando como blog em vez de Wissenschaft.
- Você ignora a estratégia central do Bürokratendeutsch: distanciar agente via nomalização.

## 2. Harte Theorie

### 2.1 Definição operacional

**Funktionsverbgefüge (FVG)** = **Funktionsverb (semanticamente leve) + Nominalkomplement (PP ou Akk-NP)** formando unidade semântica idiomatizada.

Estrutura:

```
[Subjekt] + Funktionsverb + (Komplement) + Nominalkomplement
```

Exemplos canônicos:

```
Er bringt das Problem zur Sprache.
   ↑ Funktionsverb (bringen)         ↑ Nominalkomplement (PP[zu+Dat])
   = Er spricht das Problem an.

Die Regel findet Anwendung.
   ↑ Funktionsverb               ↑ Nominalkomplement (Akk-NP)
   = Die Regel wird angewendet.

Das kommt nicht in Frage.
       ↑ Funktionsverb     ↑ Nominalkomplement (PP[in+Akk])
       = Das ist nicht möglich / akzeptabel.
```

### 2.2 Klasse de Funktionsverben

**Klasse fechada (~10-15 Funktionsverben canônicos)**:

```
bringen      kommen        finden       stehen      stellen
geben        nehmen        gelangen     gehen       treffen
führen       fassen        ziehen       fallen      sich befinden
```

Cada Funktionsverb combina com **um conjunto restrito** de Nominalkomplement-tipos:

| Funktionsverb | Padrão típico de Komplement |
|---|---|
| **bringen** | + PP[zu+Dat]: zur Sprache, zur Aufführung, zur Vollendung; + Akk: ein Opfer bringen |
| **kommen** | + PP[zu+Dat / in+Akk]: zur Sprache, zur Anzeige, in Frage, in Schwierigkeiten, zum Stillstand |
| **finden** | + Akk: Anwendung, Berücksichtigung, Eingang, Verwendung, Anklang |
| **stehen** | + PP[zu+Dat / in+Dat]: zur Verfügung, zur Debatte, in Verbindung, im Mittelpunkt |
| **stellen** | + PP[zu+Dat] / Akk: zur Verfügung, in Frage, einen Antrag stellen, eine Frage stellen |
| **geben** | + Akk: Auskunft, Bescheid, Anlass, eine Antwort, einen Hinweis |
| **nehmen** | + PP[in+Akk] / Akk: in Anspruch, in Empfang, in Kauf, Bezug auf, Stellung |
| **fassen** | + Akk: einen Beschluss, eine Entscheidung, Vertrauen, Mut, Hass |
| **ziehen** | + PP[in+Akk]: in Erwägung, in Betracht, in Zweifel, zur Verantwortung |
| **treffen** | + Akk: eine Entscheidung, Vorbereitungen, Maßnahmen, Vorkehrungen |
| **führen** | + Akk: ein Gespräch, einen Krieg, Verhandlungen, einen Beweis |

### 2.3 Tipos semânticos de FVG

#### Tipo 1: FVG-Aktiv (durativo / processual)

Codifica processo / atividade:

```
ein Gespräch führen           = sprechen, miteinander reden
Verhandlungen führen          = verhandeln
einen Krieg führen            = Krieg machen / kriegerisch agieren
Aufmerksamkeit schenken       = aufmerksam sein
```

#### Tipo 2: FVG-Passiv (resultativo / passive Bedeutung)

Codifica que algo é/torna-se feito, sem agente explícito:

```
Anwendung finden              = angewendet werden
Berücksichtigung finden       = berücksichtigt werden
zur Sprache kommen            = angesprochen werden
zur Aufführung kommen         = aufgeführt werden
zur Anzeige gebracht werden   = angezeigt werden
zur Anzeige kommen            = idem (mais leve)
```

Vantagem estilística: forma sintática Aktiv, semântica Passiv → evita von-Phrase, distancia agente.

#### Tipo 3: FVG-Modal (deontisch / epistemisch)

Codifica obrigação, possibilidade, vontade:

```
in Frage kommen               = möglich/akzeptabel sein
in Betracht kommen            = möglich sein als Option
zur Verfügung stehen          = verfügbar sein
Pflicht ankommen lassen       = (gehoben) verpflichtet sein lassen
```

#### Tipo 4: FVG-Inkohativ (início) / Resultativ (fim)

```
zum Stillstand kommen         = aufhören zu funktionieren
in Bewegung geraten           = sich zu bewegen anfangen
zur Vollendung bringen        = vollenden / fertigmachen
in Gang setzen                = anfangen lassen
```

### 2.4 Bürokratendeutsch — habitat natural das FVG

#### Características do registro

- **Impessoalidade**: agente omitido / institucionalizado.
- **Nominalizações**: substituição de verbos por substantivos.
- **FVG saturadas**: **2-5 FVG por sentença** em texto jurídico denso.
- **Genitivketten**: cf. 02-04 + Wissenschaftsdeutsch.

#### Exemplo (BGB §§ esquema)

> "Der Antrag findet keine Anwendung, soweit dem Antragsgegner ein berechtigtes Interesse zur Seite steht und dadurch ein Anspruch auf Berücksichtigung seiner Position zur Geltung gebracht werden kann."

Nesta única sentença: 4 FVG (`Anwendung finden, zur Seite stehen, Anspruch auf Berücksichtigung, zur Geltung gebracht werden`) + 1 Modal Passiv. Reescrita em estilo verbal:

> "Der Antrag wird nicht angewendet, soweit der Antragsgegner ein berechtigtes Interesse hat und dadurch seine Position berücksichtigt werden kann."

A versão "verbal" perde:
- Densidade lexical (4 FVG → 0 FVG).
- Marcação institucional (Bürokratisches Idioma).
- Equivalência semântica fina (`zur Seite stehen` ≠ `haben` — implica posição advogatória, não posse).

### 2.6 Distinção: FVG vs. fester Verbalkomplex vs. idiomatik geral

#### FVG (semilexicalizado, produtivo)

```
in Anspruch nehmen     (= beanspruchen)
zur Sprache bringen    (= ansprechen)
```

Características: o nominale Teil tem **valência sintática** (admite Genitivattribute, Adjektive, etc.):

```
seine berechtigten Ansprüche in Anspruch nehmen
das brennende Problem zur Sprache bringen
```

#### Fester Verbalkomplex (lexicalisierte Phraseologismen)

```
ins Gras beißen     (= sterben — coloquial)
den Löffel abgeben  (= sterben — coloquial)
über die Stränge schlagen  (= übertreiben)
```

Características: nominale Teil **não admite** modificação (é frase fixa, não-decomponível):

```
*ins grüne Gras beißen
*einen Löffel abgeben
```

#### Idiomatik geral

Construções idiomáticas em todos os registros, sem o caráter "Funktionsverb leve" das FVG.

### 2.7 Diagnóstico — pipeline para FVG

Quando lendo:
1. **Identificar verbo + substantivo abstrato em PP/Akk**: candidato a FVG.
2. **Procurar equivalente verbal simples** (anwenden, ansprechen, entscheiden, ...).
3. **Verificar fixidez**: a combinação é única? (não 'Anwendung machen', apenas 'Anwendung finden').
4. **Ler como unidade semântica**, não palavra-por-palavra.

Quando escrevendo:
1. **Registro determinado**: Wissenschaft / Recht / Bürokratendeutsch → FVG.
2. **Escolher o Funktionsverb correto** para o Nominalkomplement (Anki + leitura).
3. **Não inventar combinações**: se duvidar, consultar DWDS-Wortprofil ou Helbig/Buscha.

## 4. Sprachliche Aufgabe

### Texto-âncora

**Bürgerliches Gesetzbuch (BGB) §§ 1-10** — texto jurídico fundacional alemão. FVG densas + Bürokratendeutsch canônico.

> "§1 Beginn der Rechtsfähigkeit. Die Rechtsfähigkeit des Menschen beginnt mit der Vollendung der Geburt.
>
> §2 Eintritt der Volljährigkeit. Die Volljährigkeit tritt mit der Vollendung des 18. Lebensjahres ein.
>
> §13 Verbraucher. Verbraucher ist jede natürliche Person, die ein Rechtsgeschäft zu Zwecken abschließt, die überwiegend weder ihrer gewerblichen noch ihrer selbständigen beruflichen Tätigkeit zugerechnet werden können."

(Texto integral em https://www.gesetze-im-internet.de/bgb/.)

Suplementar: **§ 242 BGB** (Treu und Glauben) — princípio jurídico geral, FVG-saturado:

> "Der Schuldner ist verpflichtet, die Leistung so zu bewirken, wie Treu und Glauben mit Rücksicht auf die Verkehrssitte es erfordern."

### Tarefa

Análise escrita, **600–900 palavras** em PT-BR.

1. **Inventário FVG nos §§ 1, 2, 13, 242**: identificar **toda FVG** ou estrutura próxima a FVG. Para cada: Funktionsverb, Nominalkomplement, equivalente verbal simples.
2. **Tipos semânticos**: classificar FVG identificadas (Aktiv/Passiv/Modal/Inkohativ-Resultativ).
3. **Substantivierung adicional**: o trecho tem várias Substantivierungen não-FVG (`Volljährigkeit, Rechtsfähigkeit, Verbraucher, Schuldner, Verkehrssitte`). Como elas interagem com FVG na construção do registro?
4. **Reescrita verbal**: pegue § 13 e reescreva em **prosa verbal coloquial**. Identifique a perda específica de cada elemento substituído.
5. **Análise § 242**: discuta a expressão `Treu und Glauben` (princípio jurídico clássico). É FVG, Phraseologismus, ou outra classe? Como funciona sintaticamente?
6. **Estilo BGB no panorama**: compare BGB-Stil com Heidegger (filosofia, FVG?), Adorno (Kritische Theorie, FVG?), e jornalismo Tagesschau. Onde FVG aparecem? Onde estão ausentes?
7. **Stilbruch hipotético**: pegue uma FVG canônica (`zur Anwendung kommen`) e use-a em fala coloquial. Que efeito (paródia? formalidade exagerada? Stilbruch?) produz?

## 5. Erweiterungen und Verbindungen

- **02-04 Passivkonstruktionen** (prereq): FVG-Passiv ('Anwendung finden') é alternativa nominal a werden-Passiv direto.
- **01-04 Nominalflexion**: o Nominalkomplement em FVG é NP plena, com Genus, Kasus, Plural — flexão segue Stage 1.
- **01-06 Wortbildung**: Substantivierungen que servem de Nominalkomplement ('Anwendung, Berücksichtigung') frequentemente são sufixadas com -ung.
- **02-01 Subordination**: FVG simples como 'in Erwägung ziehen' frequentemente combinam com Inf-Sätze: 'in Erwägung ziehen, X zu tun'.
- **03-01 Nominaler vs. verbaler Stil**: FVG é o coração do nominaler Stil em registro burocrático/jurídico/wissenschaftlich.
- **03-07 Wissenschaftliches Schreiben**: aufsatzes acadêmicos usam FVG seletivamente para densidade.
- **04-08 Korpuslinguistik**: análise empírica de FVG via DWDS-Wortprofil — o profile mostra Funktionsverb-Nominalkomplement Co-Vorkommen.
- **PT comparativo**: PT tem FVG vestigiais (`tomar conhecimento`, `dar atenção`, `fazer uso`), mas em escala muito menor; DE expande sistematicamente em registro institucional.
