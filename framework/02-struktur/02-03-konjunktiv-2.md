# 02-03, Konjunktiv II (Irrealis und Höflichkeit)

## 1. Sprachliches Problem

Konjunktiv II é o **modo do contrafactual e da polidez**. Sem ele:
- Não há Konditionalsätze irrealis ("se eu tivesse, faria").
- Não há Höflichkeitsfloskeln ("eu gostaria, poderia, teria a gentileza").
- Não há comparações `als ob`.
- Não há substituição de Konj. I quando este coincide com Indikativ (cf. 02-02 §2.3).

Aprendizes adultos travam em:

- **Confundir Konj. II morfológico com Konj. I**.
- **Não dominar a `würde`-Umschreibung**: produzir Konj. II direto em verbos schwacher (= idêntico a Indikativ Prät.) gerando ambigüidade.
- **Confundir Tempos** do Konj. II: Präsens (`hätte`) vs. Plusquamperfekt (`hätte gehabt`).
- **Höflichkeit em fala**: usar Imperativ ou Indikativ em pedido (= não-cortês) onde norma exige Konj. II.

Sem este módulo:
- Pedidos coloquiais soam grosseiros (`Geben Sie mir Kaffee` em vez de `Ich hätte gern einen Kaffee`).
- Aufsätze com hipotético ficam em Indikativ + adverbial pesado em vez de Konj. II + estrutura limpa.
- Leitura literária (Schiller, Goethe, Mann) torna-se opaca em momentos de irrealis.

## 2. Harte Theorie

### 2.1 Bildung — Konjunktiv II Präsens

Padrão geral por klasse de verbo:

#### Starke Verben — Stamm-Prät. + Umlaut + Konj.-Endungen

```
gehen   → ging   → ginge      (sem Umlaut: i fica i)
sehen   → sah    → sähe        (a → ä)
nehmen  → nahm   → nähme       (a → ä)
finden  → fand   → fände        (a → ä)
fahren  → fuhr   → führe        (u → ü)
schreiben → schrieb → schriebe (sem Umlaut: ie fica ie)
liegen  → lag    → läge         (a → ä)
sitzen  → saß    → säße         (a → ä)
fliegen → flog   → flöge        (o → ö)
stehen  → stand  → stünde / stände (variante: stünde gehoben)
```

#### Schwache Verben — idêntico ao Prät. Indikativ → würde-Umschreibung

```
sagen   → sagte  → sagte       (= Ind. Prät., ambíguo) → würde sagen
machen  → machte → machte      → würde machen
arbeiten → arbeitete → arbeitete → würde arbeiten
```

Por isso a `würde`-Umschreibung domina com schwachen Verben em escrita moderna.

#### Gemischte Verben — Stamm-Prät. + Umlaut + Endungen

```
denken  → dachte → dächte
bringen → brachte → brächte
wissen  → wusste → wüsste
können  → konnte → könnte
müssen  → musste → müsste
dürfen  → durfte → dürfte
wollen  → wollte → wollte         (sem Umlaut! coincide com Ind. Prät. — mas marcado pelo contexto)
sollen  → sollte → sollte         (sem Umlaut)
mögen   → mochte → möchte
```

`wollen` e `sollen` não recebem Umlaut → ambíguos com Indikativ Prät. Distinção apenas contextual.

#### Irreguläre — formas-chave

```
sein    → war    → wäre
haben   → hatte  → hätte
werden  → wurde  → würde         (Aux. da Umschreibung!)
tun     → tat    → täte
```

### 2.2 würde-Umschreibung

`würde` (Konj. II de werden) + Infinitiv = **periphrastische Umschreibung** do Konj. II.

```
ich würde sagen        =  ich sagte (irrealis)        — esta forma desambigua
er würde gehen         =  er ginge                    — coloquial substitui forma starke
wir würden kommen      =  wir kämen
```

Distribuição:

| Klasse | Konj. II direto | würde-Umschreibung |
|---|---|---|
| Schwache Verben | (sagte, kaufte — ambíguo com Ind. Prät.) | **norma** |
| Starke Verben com Umlaut distinguível (käme, nähme, ginge, fände, wäre, hätte) | **norma escrita gehoben** | coloquial difundida |
| Modalverben (könnte, müsste, dürfte, möchte) | **norma sempre** | raro/desnecessário |
| sein, haben, werden | **norma sempre** (wäre, hätte) | desnecessário (würde sein, würde haben — pleonástico em norma) |
| Verbos starke sem distinção | (schriebe, liefe — em recuo) | norma |

Regra prática: **quando Konj. II direto é distinguível de Indikativ**, usar direto em escrita formal; **quando coincide com Ind. Prät.**, usar `würde + Inf.`.

### 2.3 Tempos do Konjunktiv II

Konj. II tem **2 tempos**:

| Tempus | Bildung | Função | Exemplo |
|---|---|---|---|
| **Präsens** | Stamm-Prät. + Umlaut + Konj.-Endung; ou würde + Inf. | irrealis presente/futuro; Höflichkeit | wenn ich Zeit hätte; ich würde kommen |
| **Plusquamperfekt** | Konj. II de haben/sein + Part. II | irrealis passado (contrafactual passado) | wenn ich Zeit gehabt hätte; ich wäre gekommen |

Aplicação em Konditionalsätze:

```
Realis Präsens:           Wenn ich Zeit habe, komme ich.            (Indikativ; vai acontecer ou não)
Irrealis Präsens:         Wenn ich Zeit hätte, käme ich.            (Konj. II; não tenho tempo)
Irrealis Plusquamperfekt: Wenn ich Zeit gehabt hätte, wäre ich gekommen.   (Konj. II Plusqp.; não tive)
```

### 2.4 Konditionalsätze (irrealis)

#### Estrutura básica

```
Wenn-Satz (protasis: condição) + Hauptsatz (apodosis: conseqüência)
```

#### Konditional Präsens (Gegenwart-/Zukunftsirrealis)

```
Wenn ich Zeit hätte, würde ich kommen.
Wenn ich reicher wäre, kaufte ich ein Haus.
Wenn er morgen käme, wäre ich froh.
```

#### Konditional Plusquamperfekt (Vergangenheitsirrealis)

```
Wenn ich Zeit gehabt hätte, wäre ich gekommen.
Wenn er das gesagt hätte, hätten wir reagiert.
```

#### Omissão de `wenn` — V1-Konstruktion (gehoben/literário)

Em registro elevado, o `wenn` pode ser omitido, com **V1** na protasis:

```
Hätte ich Zeit, käme ich.                    (= Wenn ich Zeit hätte, käme ich)
Hätte er das gewusst, wäre er nicht gekommen. (= Wenn er das gewusst hätte, ...)
Wäre ich reicher, kaufte ich ein Haus.
```

A apodosis frequentemente recebe `so` ou `dann` (opcional) em V1-Protasis:

```
Hätte ich Zeit, so käme ich.
```

### 2.5 Höflichkeit (atenuação cortês)

Konj. II atenua pedidos, desejos, sugestões, hipóteses. Atinge o tom polite ausente do Imperativ ou Indikativ direto.

#### Pedidos / wishes

```
Imperativ direto:        Geben Sie mir den Schlüssel.       (assertivo)
Konj. II Höflichkeit:    Könnten Sie mir den Schlüssel geben?
                         Würden Sie mir den Schlüssel geben?
                         Ich hätte gern den Schlüssel.
                         Ich möchte den Schlüssel.
```

#### Sugestões

```
Indikativ:               Du sollst es machen.               (assertivo / autoritário)
Konj. II:                Du solltest es machen.             (= "deveria")
                         Du könntest es machen.             (= "poderia")
                         An deiner Stelle würde ich...      (= "no seu lugar eu...")
```

#### Diplomatic distance / Hedging em escrita acadêmica

```
Es ließe sich vermuten, dass...                  (= "poderia-se supor que...")
Man könnte argumentieren, dass...                (= "poderia argumentar que...")
Es wäre denkbar, dass...                          (= "seria concebível que...")
Es dürfte sich lohnen, X zu untersuchen.         (= "valeria a pena investigar X")
```

Wissenschaftsdeutsch usa Konj. II profusamente para **hedge**: distancia o autor da assertividade total, marcando proposições como tentativas / hipóteses / propostas.

### 2.6 Vergleichssätze irrealis (`als ob, als wenn`)

Comparação contrafactual exige Konj. II:

```
Sie tut, als ob sie krank wäre.            (= "como se estivesse doente" — não está)
Es schien, als ob er zugehört hätte.       (= "como se tivesse escutado" — não escutou)
Er sieht aus, als wäre er müde.            (V1 omissão de 'ob': Konj. II direto)
```

Sem `als ob`, com V1 direto na comparação: gehoben.

### 2.7 Wunschsatz irrealis

```
Wenn ich doch Zeit hätte!                  (desejo presente irrealis)
Wenn er doch früher gekommen wäre!         (desejo passado irrealis)
Wäre ich doch reicher!                     (V1 + doch + Konj. II: padrão Wunschsatz)
Hätte er doch das nicht gesagt!            (idem passado)
```

`doch` é Modalpartikel (cf. 01-07) que reforça o caráter de desejo/lamento.

### 2.8 Diagnóstico — pipeline de uso de Konj. II

1. **Estou em Konditional irrealis?** Sim → Konj. II em ambas orações.
2. **Estou em Höflichkeit?** Sim → Konj. II.
3. **Vergleich com `als ob`?** Sim → Konj. II.
4. **Wunschsatz?** Sim → Konj. II + `doch`.
5. **Substituindo Konj. I que coincide com Indikativ?** Sim → Konj. II.
6. **Verbo é schwach ou starke?** Schwach → würde-Umschreibung; starke distinguível → forma direta gehoben.
7. **Tempo do irrealis?** Presente/futuro → Konj. II Präsens; passado contrafactual → Konj. II Plusqp.

## 4. Sprachliche Aufgabe

### Texto-âncora

**Friedrich Schiller — *Der Verbrecher aus verlorener Ehre*** (1786, novela). Trecho em condicional/irrealis denso. Schiller é mestre do Konj. II em prosa narrativa clássica.

> "Wäre ich an seiner Stelle gewesen, ich hätte gewiss anders gehandelt; aber wer weiß, ob nicht auch ich, wenn das Schicksal mich auf gleiche Weise gequält hätte, in dieselbe Verzweiflung gefallen wäre? Hätte er nur einen Menschen gehabt, der ihm zur Seite gestanden hätte, der zu ihm gesagt hätte, dass nicht alles verloren sei — vieles wäre anders gekommen. Doch so wie es war, blieb ihm nur die finstere Bahn, und sein Schicksal nahm seinen Lauf, als hätte es nie eine andere Möglichkeit gegeben."

(Composto/adaptado para densidade pedagógica; consultar edição Reclam para texto integral.)

### Tarefa

Análise escrita, **800–1000 palavras** em PT-BR.

1. **Inventário Konj. II**: identificar **toda forma Konj. II** no trecho (mínimo 10). Para cada: forma (`hätte, wäre, ginge, ...`), Verbo (Inf.), Tempus (Präsens / Plusqp.), uso (Konditional irrealis / Höflichkeit / Vergleich / Wunschsatz / substituição Konj. I).
2. **Konditionalsätze**: identificar **todas** as estruturas. Para cada: tipo (Präsens irrealis / Plusqp. irrealis); presença/omissão de `wenn`; presença de `so` na apodosis.
3. **`als hätte` (V1 com Konj. II)**: o trecho tem `als hätte es nie eine andere Möglichkeit gegeben`. Identificar tipo de comparação (irrealis / V1 omissão de `ob`).
4. **würde-Umschreibung**: o trecho usa formas Konj. II diretas? Por que **Schiller prefere Konj. II direto** sobre würde-Umschreibung? (Resposta: registro gehoben + verbos starke + período histórico antes da generalização würde-).
5. **Tempos relativos**: o irrealis é presente, passado, ou ambos? Como Schiller estrutura a relação temporal entre o evento real e o contrafactual?
6. **Stilistische Bemerkung**: Schiller constrói 3+ frases consecutivas em Konj. II irrealis. Função estilística-narrativa (eingeschobene Reflexion do narrador, lamento, postura moral)?
7. **Comparação registros**: reescreva o trecho em **registro coloquial DE moderno**, com würde-Umschreibung onde norma escrita gehoben usa direto. Compare a perda de density e gravidade.

## 5. Erweiterungen und Verbindungen

- **02-01 Subordination** (prereq): Konditionalsätze são Subjunktor-Sätze (`wenn`); comparação é Subjunktor-Sätze (`als ob`).
- **02-02 Konjunktiv I**: substituição Konj. I → Konj. II quando Konj. I coincide com Indikativ.
- **01-03 Verbalsystem**: Stammformen do Prät. são base para Konj. II.
- **01-07 Modalpartikeln**: `doch` em Wunschsatz; `wohl` em Höflichkeit.
- **03-04 Pragmatik**: Höflichkeit é Sprechakt-Modulation morfológica.
- **03-07 Wissenschaftliches Schreiben**: Konj. II usado em hedge acadêmico.
- **04-05 Formale Semantik**: Konditionalsätze irrealis têm Wahrheitsbedingungen contrafactuais; tópico de semântica modal.
- **PT comparativo**: PT mantém modos morfologicamente distintos no subjuntivo (presente/imperfeito/futuro). DE colapsou em Konj. II único + perífrases. Mapeamento PT-DE: subjuntivo PT → Konj. II DE em irrealis, mas com nuances tempora distintas.
