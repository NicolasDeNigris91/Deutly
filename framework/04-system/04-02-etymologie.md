# 04-02, Etymologie und Wortgeschichte

## 1. Sprachliches Problem

Etimologia é **a arqueologia do léxico**. Cada palavra alemã carrega história — Idg., Germânica, Ahd., Mhd., Frnhd. — documentável em **Pfeifer** e **Kluge**. Sem aparelho etimológico, leitura de filosofia (Heidegger, Adorno), recepção de textos canônicos (Goethe, Schiller, Nietzsche), e construção de Begriffsanalyse no Capstone-4 ficam superficiais.

Aprendizes adultos travam em:

- **Tratar palavras como sincronicamente isoladas**: ignorar a trajetória diacrônica.
- **Confundir Erbwort com Lehnwort**: assumir que palavra é "alemã pura" sem investigar.
- **Não usar Pfeifer / Kluge**: argumentar etymologia por intuição.
- **Não reconhecer Heidegger-Etymologisierung**: ler como decoração estilística.

Sem este módulo, **04-08 Korpuslinguistik + 04-10 Hermeneutik + CAPSTONE-4** não operam.

## 2. Harte Theorie

### 2.1 Komparative Methode — fundamentos

#### Principios

- **Lautgesetze regulares**: mudanças sonoras operam sistematicamente, sem exceções não-explicáveis.
- **Cognatas**: palavras de línguas distintas que descendem da mesma forma proto.
- **Reconstrução**: forma proto- (marcada com **) inferida pela comparação.
- **Família indo-européia**: Sanskrit, Grego, Latim, Germânico, Báltico, Eslavo, Celta, Hitita, Tocariano.

#### Exemplo de reconstrução

Cognatas para 'pai':

```
Sanskrit:    pitar-
Grego:       patēr
Latim:       pater
Gótico:      fadar
Mhd.:        vater
Nhd.:        Vater
```

Aplicando Erste Lautverschiebung (Idg. *p → Germ. *f) e outras Gesetze, reconstrói-se:

```
Idg. *ph₂tér- ('pai')
   ↓ Erste Lautverschiebung (*p > *f)
Germ. *fadēr-
   ↓ vocalismo Ahd.
Ahd. fater
   ↓ ortografia
Mhd. vater
   ↓ ortografia + capitalização Frnhd.
Nhd. Vater
```

### 2.2 Erbwort vs. Lehnwort

#### Erbwortschatz (núcleo Idg./Germ. herdado)

Núcleo conceitual primário:

```
Parentesco:    Vater, Mutter, Bruder, Schwester, Sohn, Tochter, Mann, Weib
Corpo:         Kopf, Hand, Fuß, Auge, Ohr, Mund, Herz, Knochen, Haar, Bein
Natureza:      Tag, Nacht, Sonne, Mond, Stern, Wasser, Feuer, Erde, Himmel, Wind
Números:       eins, zwei, drei, vier, fünf, ..., zehn, hundert
Verbos básicos: sein, haben, werden, gehen, kommen, sehen, hören, essen, trinken, schlafen
Adjetivos:     gut, böse, alt, jung, groß, klein, hoch, lang
```

Estes lexemas têm cognatas claras em Sanskrit, Grego, Latim — todos descendem do Idg.

#### Lehnwortschatz (empréstimos)

##### Latim (cristianização ~600-1200; Humanismus séc. XV-XVI)

```
Fenster        ← lat. fenestra
Wein           ← lat. vinum
Mauer          ← lat. murus
Strasse        ← lat. (via) strata
Schule         ← lat. schola
Kirche         ← gr. kyriakē (via lat.)
Bischof        ← gr. episkopos (via lat.)
Schreiben      ← lat. scribere
Schule         ← lat. schola
Philosophie    ← gr. philosophia (via lat.)
```

##### Französisch (séc. XVII-XVIII; nobreza, cortesã, gastronomia, moda)

```
Etage          ← franc. étage
Etikette       ← franc. étiquette
Restaurant     ← franc.
Hotel          ← franc.
Bonbon         ← franc.
Marmelade      ← franc. marmelade ← port. marmelada
Moment         ← franc. moment ← lat. momentum
Saison         ← franc. saison
Bibliothek     ← franc. bibliothèque ← gr.
```

##### Englisch (séc. XX-XXI; tecnologia, mídia, comportamento)

```
Computer       ← engl. computer
Internet       ← engl.
Lockdown       ← engl.
Smartphone     ← engl.
Software       ← engl.
chillen        ← engl. chill (Jugendsprache)
liken          ← engl. like (Mídia social)
googeln        ← engl. (germanizado: googelte, gegoogelt)
```

##### Empréstimos sistemáticos: vocabulário científico greco-latino

```
Phänomen       ← gr. phainomenon
Logos          ← gr. logos
Methode        ← gr. methodos
Theorie        ← gr. theōria
Praxis         ← gr.
Hermeneutik    ← gr.
Etymologie     ← gr.
Phänomenologie ← gr. (composto)
```

Subset central da terminologia geisteswissenschaftlich (cf. 03-09).

### 2.3 Reconstrução etimológica — workflow

Para um Lemma DE atual, aplicar:

1. **Pfeifer / Kluge**: consultar entrada.
2. **Identificar Stufen documentadas**: Frnhd. → Mhd. → Ahd. (se possível).
3. **Identificar Erbwort vs. Lehnwort**: cognatas IE? ou empréstimo?
4. **Cognatas IE**: Sanskrit, Grego, Latim, Gótico — buscar paralelos.
5. **Bedeutungsverschiebung**: significado atual ≠ significado primário?
6. **Análise morfológica**: prefixo + raiz + sufixo, cada parte com etymon.

### 2.4 Etymologia de Begriffe filosóficos centrais

#### Aufklärung (f.)

```
Análise: auf- (Präfix Erbwort, Idg. *upo 'em cima, sobre') + 
         klären (verbo Erbwort, Mhd. klæren < Ahd. *kleron 'tornar claro' < 
                  Adj. klar Erbwort, Idg. *kelh₁- 'gritar, chamar' → 'visível, claro') + 
         -ung (sufixo nominalizador Erbwort)

Cadeia diacrônica:
  Idg. *kelh₁- (raiz)
  → Germ. *klēriz (forma derivada)
  → Ahd. (h)lūttar 'klar'  
  → Mhd. klār 
  → Frnhd. klar
  → Nhd. klar

Bedeutungsverschiebung de aufklären → Aufklärung:
  séc. XVII: 'tornar claro, esclarecer'
  séc. XVIII: metonímico, 'movimento iluminista' (Christian Wolff, Kant)
  hoje:       ambos significados convivem
```

#### Geist (m.)

```
Análise: Erbwort, Idg. *ǵʰeysd- 'agitar, encantar'

Cadeia:
  Idg. *ǵʰeysd-
  → Germ. *gaistaz 'demônio, espírito'
  → Ahd. geist 'demônio, alma'
  → Mhd. geist 
  → Nhd. Geist

Bedeutungsverschiebung:
  Origem: agente assustador / demônio / espírito não-corpóreo
  Cristianização: Heiliger Geist (Espírito Santo)
  Hegel séc. XIX: Geist filosófico (mente coletiva, autoconsciência histórica)
  Hoje: 'mente, espírito, coragem' (Adj.: geistig)

Cognatas IE: Sanskrit hēṣ- 'apavorar'; Avesta zōiš- 'tremor'.
```

#### Sein (n.) [Heidegger-Begriff]

```
Análise: Erbwort, suppletiv (3 stems)
  Idg. *h₁es- 'ser, existir' → bin/ist (Präsens)
  Idg. *bʰuH- 'tornar-se, crescer' → bin (1.Sg.); was (Prät.)
  Idg. *wes- 'permanecer, habitar' → war/gewesen

Cadeia:
  Ahd. wesan, sîn → Mhd. wesen, sîn → Nhd. sein
  Substantivierung do Inf. (vivem ahd.; institutionalizada Nhd.)

Bedeutungsverschiebung:
  Verbal: 'existir, ocorrer' → cópula 'ser X'
  Substantivierung filosófica: Wesen (Ahd. lex.); Sein (filosofia moderna)
  Heidegger: Sein vs. Seiende — diferença ontológica fundamental
```

#### Wahrheit (f.)

```
Análise: wahr (Adj. Erbwort) + -heit (sufixo nominalizador)

  Idg. *weh₁- 'verdadeiro, fiel'
  → Germ. *waraz 'fiel, certo'
  → Ahd. wâr
  → Mhd. wâr
  → Nhd. wahr → Wahrheit

Cognatas IE: lat. verus (verdadeiro); irl. fír; vels. gwir.

Heidegger explora gr. ἀ-λήθεια (a-letheia, 'des-encobrimento') — distinto da etymologia germânica wahr/Wahrheit. Recurso filosófico (não filológico estrito).
```

#### Bildung (f.)

```
Análise: bilden (Verbo Erbwort < Mhd. bilden 'criar imagem' < Ahd. biladôn) + -ung

  Ahd. bilad-i 'imagem, forma'
  → Mhd. bilde 'imagem, forma, figura'
  → Frnhd. Bildung 'formação' (com sufixo)
  → Nhd. Bildung

Bedeutungsverschiebung:
  Mhd.: 'formação física, criação de imagem'
  Humboldt séc. XIX: 'formação intelectual-cultural' (Bildung como Begriff humboldtiano)
  Adorno: 'Bildung' criticada vs. Halbbildung (pseudo-formação)

Cognatas IE: incertas (formação germânica específica).
```

### 2.5 Heideggers Re-etymologisierung — método e crítica

#### Estratégia heideggeriana

Heidegger argumenta:
1. Termos filosóficos perderam **significado original** na evolução semântica.
2. Recuperar etymon = recuperar **pensamento esquecido**.
3. Etymologia não é apenas filológica, mas **filosoficamente reveladora**.

#### Exemplos canônicos

```
Wahrheit
  Etymon DE: Erbwort wahr (Idg. *weh₁- 'verdadeiro')
  Heidegger: prefere etymon GREGO ἀ-λήθεια ('a-lētheia' = des-encobrimento)
  Operação: traduzir conceitualmente Wahrheit → Unverborgenheit (= alemão composto que reproduz o grego)
  
Logos
  Etymon: gr. λέγειν 'colher, reunir, dizer'
  Heidegger: 'das Sagen, das Versammeln' (substantivierter Inf. + verbal noun)
  
Phänomen
  Etymon: gr. φαίνεσθαι 'mostrar-se'
  Heidegger: 'das Sich-zeigen' (Phrase-Substantivierung hyphenada)
  
Aletheia (verdade)
  Mesma etymon que Wahrheit; Heidegger explora 'ἀ-' privativum + 'λήθεια' (lethē = ocultação)

Sein
  Etymon: Erbwort 3-stem suppletiv (cf. supra)
  Heidegger: foco em Sein vs. Seiende (Differenz, Vergessenheit des Seins)
```

#### Crítica filológica

Heideggers Re-etymologisierung é **controversa**:
- **Fachfilologia germânica**: etymologia descritiva de Pfeifer ≠ argumento filosófico.
- **Defensores Heidegger**: o método é fenomenológico, não filológico estrito.
- **Posição saudável**: etymologia como **inspiração heurística**, não prova.

Em CAPSTONE-4: **manter rigor filológico** (Pfeifer/Kluge como autoridade) + **registrar heideggerianas re-etymologisierungen** como objeto de análise crítica.

### 2.6 Diagnóstico — pipeline para etymologia operacional

Quando lendo:
1. **Identificar Lemma central** do texto.
2. **Consultar Pfeifer / Kluge** (online: https://www.dwds.de/d/wb-etymwb).
3. **Mapear cadeia** Idg./Germ./Ahd./Mhd./Nhd.
4. **Diagnosticar Bedeutungsverschiebung**.
5. **Identificar Erbwort/Lehnwort**.
6. **Anotar Cognatas IE** se relevantes.
7. **Reconhecer** se autor (Heidegger, Adorno) usa Re-etymologisierung como estratégia.

Quando escrevendo (Capstone-4):
1. **Ancorar Begriffsanalyse** em Pfeifer.
2. **Documentar** cadeia diacrônica para o *Begriff*.
3. **Distinguir** etymologia descritiva de Re-etymologisierung filosófica.
