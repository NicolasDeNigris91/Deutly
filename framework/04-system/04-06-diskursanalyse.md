# 04-06, Diskursanalyse — Foucault, kritische Diskursanalyse, Dispositiv

## 1. Sprachliches Problem

Diskursanalyse é **a análise de unidades supra-frasais** com foco em poder + ideologia + produção de subjetividades. Foucault (em DE via Suhrkamp) é referência fundadora; KDA (Wodak, Jäger) operationaliza. Sem este aparelho, leitura crítica de Bundestagsdebatten, jornalismo populista, propaganda institucional fica plana.

Aprendizes adultos travam em:

- **Tratar texto como unidade isolada**: ignorar contexto discursivo + dispositivo institucional.
- **Não dominar terminologia foucaultiana**: Diskurs, Dispositiv, Wissen, Macht-Wissen-Komplex.
- **Não aplicar KDA**: não reconhecer marcadores linguísticos de ideologia/poder.

Sem este módulo:
- Leitura crítica de discurso político inviável.
- Capstone-4 (Begriffsanalyse) carece de aparelho discursivo.
- Análise de mídia populista superficial.

## 2. Harte Theorie

### 2.1 Foucault — fundamentos terminológicos

#### Diskurs (m.)

> *"Conjunto de enunciados regulados que produzem o objeto de conhecimento, as posições de sujeito, os conceitos, as estratégias. Diskurs não é simplesmente fala ou texto; é prática regulada que produz Wissen e estabelece Macht-Beziehungen."*

(Foucault, *Archäologie des Wissens*, 1973 — tradução DE de *L'archéologie du savoir* 1969.)

#### Dispositiv (n.)

> *"Ensemble heterogêneo: discursos, instituições, arquiteturas, leis, procedimentos administrativos, enunciados científicos, propostas filosóficas e morais. Tudo isso constitui o dispositivo. Dispositive responde a uma 'urgência histórica' e tem função estratégica predominante."*

(Foucault em entrevista 1977; tradução DE em *Dispositive der Macht*, 1978.)

Exemplos:
- **Sexualität-Dispositiv**: discurso médico + leis + arquitetura confessional + práticas pastorais (Foucault *Sexualität und Wahrheit* / *Histoire de la sexualité*, 1976).
- **Disziplinar-Dispositiv**: prisões, escolas, hospitais, fábricas + arquitetura panóptica + cronometria + protocolos disciplinares (*Überwachen und Strafen*, 1975/77).
- **Bio-politik-Dispositiv**: estatística populacional + saúde pública + epidemiologia + medicina + intervenções estatais (modernidade séc. XVIII-XX).

#### Macht-Wissen-Komplex

```
Macht ↔ Wissen
Macht produz Wissen; Wissen legitima Macht. Bidirecional, inseparável.
Não há "verdade pura" fora de Macht-Beziehungen.
```

#### Genealogie / Archäologie

- **Archäologie**: análise de **estratos** discursivos histórico-arquivais; descobre regras-de-formação de Diskurs.
- **Genealogie**: análise de **trajetórias** de poder; descobre como verdade-regimes se constituem historicamente.

### 2.2 Kritische Diskursanalyse (KDA) — operacionalização

#### Premissas (Wodak, Jäger)

1. Discurso é **socialmente constitutivo + socialmente constituído**.
2. Discurso codifica **ideologia, poder, desigualdade**.
3. Análise discursiva tem **dimensão crítica e interventiva**.
4. Combina **métodos linguísticos sistemáticos + crítica ideológica**.

#### Pipeline KDA típico

```
1. Selecionar corpus (corpus de Bundestagsdebatten, jornalismo, propaganda).
2. Identificar Diskursstrang (= cadeia temática transversal a vários textos).
3. Análise micro: lexikal, sintática, retórica.
4. Análise meso: estrutura argumentativa, citation, intertextualidade.
5. Análise macro: ideologia, poder, função social.
6. Crítica + intervenção (engajamento ativo).
```

#### Marcadores linguísticos analisados em KDA

##### Lexikalische Auswahl

```
'Asylant' vs. 'Geflüchteter' vs. 'Migrant' vs. 'Schutzsuchender'
   → cada lexikalische Auswahl codifica posicionamento ideológico.
   
'Maßnahmen' vs. 'Eingriffe' vs. 'Repression'
   → mesmo referente, valoração distinta.

'Reform' vs. 'Verschlechterung' vs. 'Anpassung'
   → escolha lexical = posição política implícita.
```

##### Pronome 'wir' / 'sie'

```
'Wir Deutschen / Wir Bürger / Wir alle'    (in-group inclusivo, identificação)
'Sie / die anderen / die Migranten'        (out-group, exclusão)
```

Pronome inclusivo recruta legitimidade; pronome out-group cria distância.

##### Topikalisierung estratégica

Cf. 02-08. Cada Vorfeld-choice codifica frame:
- Topikalizar 'die Wirtschaft': frame econômico.
- Topikalizar 'der Mensch': frame humanístico.
- Topikalizar 'die Sicherheit': frame securitário.

##### Konjunktor strategy

```
'aber, jedoch, indessen, gleichwohl'   (concessivo: reconhece + minimiza)
'denn, weil'                            (causal: assume causa específica)
'sondern'                                (contraste: redirige)
```

Encadeamento de conectivos lógicos = arquitetura argumentativa.

##### Modalpartikeln pragmatik

```
'doch'      (retomada como pressuposto compartilhado)
'eigentlich' (questionar pressuposto subjacente)
'wohl'      (inferência epistêmica + distância)
```

##### FVG e Substantivierungen burocráticas

Apagamento de agente, distanciamento, opacidade institucional.

##### Konjunktiv I em Reportativ

Distância vs. endorsement editorial.

### 2.3 Análise de Bundestagsdebatten

#### Estrutura típica de discurso parlamentar

```
1. Anrede ritualizada:        "Frau Präsidentin, sehr geehrte Damen und Herren"
2. Selbstpositionierung:       "Wir Sozialdemokraten / Christdemokraten / ..."
3. Gegnerpositionierung:       "Die Oppositionsparteien / Die Regierung..."
4. Argumentation:               These → Beleg → Schluss
5. Implikatur ideologisch:     "Es kann nicht sein, dass..."
6. Schluss ritualizado:        "Vielen Dank für Ihre Aufmerksamkeit"
```

#### Sprechakte parlamentares

Cf. 03-04. Tipos:
- **Selbstdarstellung**: estabelece autoridade.
- **Gegnerangriff**: deslegitima oposição.
- **Programmverkündung**: anuncia política.
- **Beschwörung**: invoca valores comuns.

#### Diskursstränge políticos contemporâneos

- **Migrationsdebatte**: lexical (Asylant, Geflüchteter, Migrant); polarização wir/sie; topicalização (Sicherheit vs. humanitäre Pflicht).
- **Klima-Diskurs**: lexical (Klimawandel, Klimakatastrophe, Klimakrise); urgency-marking; científico vs. político.
- **Wirtschaftsreform**: lexical (Reform, Verschlechterung); FVG burocrático; agente apagado.

### 2.4 Foucault vs. Habermas — debate metodológico

#### Foucault — perspectiva

- Diskurs/Macht ubíquos.
- Razão é histórica, não atemporal.
- Verdade é regime, não correspondência.
- Análise: genealogische Kritik negative.

#### Habermas — perspectiva

- Comunicação racional como base de legitimidade.
- Distorção sistemática de comunicação por poder/colonização.
- Universal pragmatik: pretensões de verdade, correção, sinceridade reconstruíveis.
- Análise: rekonstruktiv-normativ.

#### Síntese KDA

KDA frequentemente **combina** Foucault (macro-análise discurso/poder) + Habermas (micro-análise validade comunicativa) + métodos linguísticos sistemáticos.

### 2.5 Diagnóstico — pipeline de análise discursiva

Quando lendo discurso (parlamentar, jornalístico, propaganda):

1. **Identificar Diskurs/Diskursstrang** transversal.
2. **Análise micro**: lexical, sintática, retórica.
3. **Identificar marcadores**: Wir/Sie, Topikalização, Modalpartikeln, FVG.
4. **Análise meso**: argumentação, citation, intertextualidade.
5. **Análise macro**: ideologia, poder, função social.
6. **Posicionamento crítico**: engajamento ou distância.
