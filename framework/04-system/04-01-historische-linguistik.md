# 04-01, Historische Linguistik — Idg., Ahd., Mhd., Frnhd., Nhd.

## 1. Sprachliches Problem

DE moderno é resultado de **2500+ anos de evolução** desde o Indogermanisch. Cada Sprachstufe deixou camadas: lexicais, morfológicas, sintáticas. Sem reconhecê-las, leitura de textos canônicos pré-Nhd. é impossível, e leitura de Nhd. moderno permanece superficial — porque cada palavra carrega **história documentável**.

Aprendizes adultos travam em:

- **Não reconhecer ortografia Mhd./Frnhd.**: tratar `wîp, lîp, dâ` como erros de escrita.
- **Confundir cognatas** entre Stufen: ler `Weib` Nhd. como sinônimo neutro de `wîp` Mhd.
- **Ignorar Lautverschiebungen**: não diagnosticar Hochdeutsch vs. Niederdeutsch.
- **Não localizar autores**: ler Walther como contemporâneo de Goethe.

Sem este módulo, **04-02 Etymologie + 04-10 Hermeneutik klassischer Texte** não operam.

## 2. Harte Theorie

### 2.1 Periodização — 5 Sprachstufen + 1

| Sprachstufe | Período | Marca distintiva | Textos canônicos |
|---|---|---|---|
| **Indogermanisch (Idg.)** | ~3500-2500 a.C. | Reconstrução; sem documentos diretos | (sem textos; reconstrução comparativa) |
| **Germanisch (Germ.)** | ~500 a.C. - 500 d.C. | Erste Lautverschiebung (Grimm); separação do Idg. | Runeninschriften, Codex Argenteus (gótico) |
| **Althochdeutsch (Ahd.)** | 750-1050 | Zweite Lautverschiebung; cristianização | Hildebrandslied, Otfrid *Evangelienbuch*, Tatian |
| **Mittelhochdeutsch (Mhd.)** | 1050-1350 | Literatura cortesã; Minne; Klassik | Walther, Wolfram, Gottfried, *Nibelungenlied* |
| **Frühneuhochdeutsch (Frnhd.)** | 1350-1650 | Imprensa; Reformation; Lutherbibel | Luther, Reformation, Hans Sachs |
| **Neuhochdeutsch (Nhd.)** | 1650-presente | Standardisation; Goethezeit | Goethe ao presente |

### 2.2 Lautverschiebungen — eventos foneticos centrais

#### Erste Lautverschiebung (Germânica) — Grimm, ~1500 a.C.

Distingue germânico de outros indo-europeus:

```
Idg. *p, *t, *k       → Germ. *f, *θ (= th), *h
Idg. *b, *d, *g       → Germ. *p, *t, *k
Idg. *bh, *dh, *gh    → Germ. *b, *d, *g
```

Pares sistemáticos comparativos:

```
Lat. pater   = Germ. *fadar   = Mhd. vater   = Nhd. Vater
Lat. tres    = Germ. *thrīz   = Nhd. drei
Lat. cor     = Germ. *hertan  = Nhd. Herz
Lat. duo     = Germ. *twai    = Nhd. zwei
```

#### Zweite Lautverschiebung (Hochdeutsch) — ~6.-8. Jh.

Distingue alto-alemão (Hochdeutsch) de baixo-alemão (Niederdeutsch). **Apenas o sul** sofreu:

```
Germ. *p, *t, *k → Ahd. *pf, *ts, *kh (em ataque silábico após vogal: ff, ss, ch)
```

Pares Niederdeutsch (norte) vs. Hochdeutsch (sul):

| Niederdeutsch | Hochdeutsch | Significado |
|---|---|---|
| Appel | Apfel | maçã |
| Pund | Pfund | libra |
| dat | das | isso |
| Tîd | Zeit | tempo |
| maken | machen | fazer |
| ik | ich | eu |
| water | Wasser | água |
| open | offen | aberto |

A **Benrather Linie** (linha geográfica norte-sul) marca a fronteira maken/machen → Hochdeutsch ao sul; Niederdeutsch ao norte.

### 2.3 Mittelhochdeutsch — convenções editoriais e leitura

#### Ortografia editorial moderna (Lachmann, ~1820–1850)

**Vokallänge marcada por circunflexo** ^:

```
Mhd. 'wîp'    [vi:p]      = Nhd. 'Weib' [vaɪp]   (mulher)
Mhd. 'lîp'    [li:p]       = Nhd. 'Leib' [laɪp]   (corpo)
Mhd. 'sîn'    [zi:n]      = Nhd. 'sein' [zaɪn]   (ser)
Mhd. 'hûs'    [hu:s]      = Nhd. 'Haus' [haʊs]  (casa)
Mhd. 'mîn'    [mi:n]      = Nhd. 'mein' [maɪn]   (meu)
Mhd. 'tac'    [tak]        = Nhd. 'Tag' [ta:k]   (dia)
```

#### Diphthongierung (Mhd. → Nhd.)

Vogais longas Mhd. tornaram-se ditongos Nhd.:

```
Mhd. î   →   Nhd. ei   (wîp → Weib; lîp → Leib; mîn → mein; sîn → sein)
Mhd. û   →   Nhd. au   (hûs → Haus; mûs → Maus; lût → laut)
Mhd. iu  →   Nhd. eu/äu (liut → Leut; tiur → teuer; hiute → heute)
```

#### Monophthongierung (Mhd. → Nhd.)

Ditongos Mhd. tornaram-se vogais longas Nhd.:

```
Mhd. ie  →   Nhd. ie [iː]   (lieb → lieb; brief → Brief)  (já era longa)
Mhd. uo  →   Nhd. u [uː]   (bruoder → Bruder; muoter → Mutter)
Mhd. üe  →   Nhd. ü [yː]   (grüen → grün; brüeder → Brüder)
```

#### Léxico Mhd. canônico

```
wîp (n.)        = Weib / Frau (mulher)
lîp (m.)        = Leib / Körper / Leben
mîn             = mein (meu)
sîn             = sein (ser; também: seu)
ouch            = auch (também)
dâ              = da (lá)
hôch            = hoch (alto)
hêr             = hehr (sublime, gehoben)
minne (f.)     = Liebe (amor cortês)
muot (m.)      = Mut, Gemüt (coragem, ânimo)
ahte (f.)      = Acht, Achtung (atenção, honra)
tiusch          = deutsch (alemão)
ritter (m.)    = Ritter (cavaleiro)
helt (m.)      = Held (herói)
```

### 2.4 Frühneuhochdeutsch (Frnhd., 1350-1650)

#### Eventos sociolinguísticos centrais

- **Imprensa** (Gutenberg ~1450): standardização gradual.
- **Reformation** (Luther 1517-): consolidação do alemão escrito.
- **Lutherbibel** (NT 1522, AT 1534): texto fundador.
- **Kanzleisprachen**: chancellaria saxônica como base do escrito.
- **Humanismus**: latim influenciando.

#### Lutherbibel — modelo lingüístico

```
Mhd. 1200:    "got der almehtige sî gelobet"
Frnhd. 1545:  "Gott der allmechtige sey gelobet"  (Luther)
Nhd. 2017:    "Gott der Allmächtige sei gelobt"
```

Diferenças:
- Mhd. /a/ + ehtic / Frnhd. /a/ + echtig / Nhd. /a/ + ächtig (Umlaut sufixado).
- Mhd. /sî/ → Frnhd. /sey/ (transitional ortographic) → Nhd. /sei/.
- Capitalização: Mhd. minúscula → Frnhd. maiúscula em substantivos (parcial) → Nhd. maiúscula obrigatória.

#### *Sendbrief vom Dolmetschen* (Luther 1530)

Lutero defende sua tradução: "dem Volk auf das Maul sehen" — falar como o povo. Estabelece princípio de tradução como **interpretação ativa, não transcrição literal**. Texto fundador da tradução-teoria DE.

```
"Denn man muß nicht die Buchstaben in der lateinischen Sprache fragen, 
wie man soll Deutsch reden... sondern man muß die Mutter im Hause, die 
Kinder auf der Gassen, den gemeinen Mann auf dem Markt drum fragen."
```

### 2.5 Bedeutungsverschiebung — termos viajando entre Stufen

#### Pejorativização

```
wîp (Mhd. neutro: 'mulher') → Weib (Nhd. pejorativo coloquial; gehoben em Bibel/lit.)
                              → substituído por 'Frau' em registro neutro

dirne (Mhd. neutro: 'jovem mulher') → Dirne (Nhd. arcaico/pejorativo: prostituta)
                                       → substituído por 'Mädchen, junge Frau'

geliebter (Mhd.: amante cortês) → Liebhaber (Nhd. quase neutro)
```

#### Generalização / restrição

```
ahd. fugil → Mhd. vogel → Nhd. Vogel (= ave; significação estável)
ahd. tier → Mhd. tier → Nhd. Tier (= animal; especificou — antes era 'animal selvagem')
ahd. sahha → Mhd. sache → Nhd. Sache (= coisa; antes 'processo jurídico, disputa')
```

#### Empréstimos e Verdrängung

```
Mhd. minne (= amor cortês) → Verdrängt por Liebe (Nhd.) em registro neutro
                              minne sobrevive apenas em registros gehoben/literário
                              
Mhd. muot → Mut (= coragem); Gemüt (= temperamento, ânimo) — desdobramento
```

### 2.6 Diagnóstico — pipeline para leitura diacrônica

Quando lendo texto Ahd./Mhd./Frnhd.:

1. **Identificar Stufe** pelo aparelho ortográfico (â, ê, î, ô, û = Mhd.; sey, sehy = Frnhd.).
2. **Aplicar Diphthongierung** mental: Mhd. î → Nhd. ei; û → au; iu → eu/äu.
3. **Aplicar Monophthongierung**: Mhd. ie → Nhd. ie; uo → u; üe → ü.
4. **Reconhecer Bedeutungsverschiebung**: termo antigo pode ter conotação distinta em Stufe atual.
5. **Consultar Lexer** (*Mittelhochdeutsches Handwörterbuch*) ou **DWB Grimm** para Wortgeschichte.

## 4. Sprachliche Aufgabe

### Texto-âncora

**Walther von der Vogelweide — *Under der linden*** (Mhd., ~1200), estrofe 1.

> *"Under der linden  
> an der heide,  
> dâ unser zweier bette was,  
> dâ muget ir vinden  
> schône beide  
> gebrochen bluomen unde gras.  
> Vor dem walde in einem tal,  
> tandaradei,  
> schône sanc diu nahtegal."*

(Edição canônica: *Walther von der Vogelweide, Sämtliche Lieder*, Hg. Friedrich Maurer, 1955.)

**+ Texto Frnhd.**: Luther, *Sendbrief vom Dolmetschen* (1530), trecho:

> *"Wir suchen nicht der Buchstaben in der Sprache, sondern die Sache selbst. Denn man muß nicht die Buchstaben in der lateinischen Sprache fragen, wie man soll Deutsch reden, wie diese Esel tun, sondern man muß die Mutter im Hause, die Kinder auf den Gassen, den gemeinen Mann auf dem Markt drum fragen."*

### Tarefa

Análise escrita, **800-1000 palavras** em PT-BR.

1. **Walther — análise filológica**: para cada palavra Mhd. distintiva (`linden, heide, dâ, muget, vinden, schône, beide, gebrochen, bluomen, unde, walde, tal, sanc, diu, nahtegal`): forma Mhd. + forma Nhd. + tradução PT.
2. **Diphthongierung detectada**: identificar todos os Mhd. î/û/iu→Nhd. ei/au/eu (e.g., `mîn → mein`).
3. **Bedeutungsverschiebung**: 'minne' não aparece, mas qual seria o termo Mhd. para 'Liebe' do trecho? E como teria sido tratado em Nhd.?
4. **Aparelho ortográfico Mhd.**: marca-se circunflexo, ortografia diferente. Análise.
5. **Luther — Frnhd.**: identificar diferenças de Frnhd. vs. Nhd. moderno (formas verbais, capitalização, sintaxe). Reescrever em Nhd. moderno.
6. **Princípio de tradução de Lutero**: o que significa 'die Mutter im Hause ... drum fragen'? Como Lutero define tradução? Compare com a tradição filológica posterior.
7. **Bedeutungs-Begriffsanalyse**: tomar 1 palavra do trecho Walther (e.g., `schône, gebrochen, ahte`) e reconstruir cadeia diacrônica Idg.→Germ.→Ahd.→Mhd.→Nhd. via Pfeifer (consulta indicada).

Após terminar, peça o **Praktisches Tor**.
