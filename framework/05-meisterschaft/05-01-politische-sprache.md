# 05-01, Politische Sprache — Bundestagsdebatten, Parteiprogramme

## 1. Sprachliches Problem

Politische Sprache em DE é **registro saturado de retórica + ideologia + ritualizações**. Aprendiz adulto que ignora análise política não pode ler Bundestagsdebatten, comentários jornalísticos sobre política, Parteiprogramme, propaganda. Stage 5 ativa **análise crítica madura** combinando 03-04 (Pragmatik) + 03-08 (Journalistischer Stil) + 04-06 (Diskursanalyse).

Aprendizes adultos travam em:

- **Não diagnosticar Sprechakte ritualizados**: ler fórmulas como decoração.
- **Não identificar Implikaturen ideológicas**: assumir conteúdo literal.
- **Não dominar Stilfiguren retóricas**: perder Pathos / Ethos.
- **Não reconhecer Polarisierung lexical**: tratar 'Asylant' / 'Geflüchteter' como sinônimos.
- **Não dominar léxico político especializado**: termos institucionais.

Sem este módulo, leitura crítica de mídia política, participação em debate, escrita de Kommentar político — todos sofrem.

## 2. Harte Theorie

### 2.1 Estrutura canônica do discurso parlamentar DE

#### Macroestrutura

```
1. Anrede ritualizada (~5-10 segundos)
   "Frau Präsidentin, sehr geehrte Damen und Herren!"
   "Sehr geehrte Frau Bundestagspräsidentin, liebe Kolleginnen und Kollegen,
    sehr geehrte Damen und Herren..."

2. Selbstpositionierung (~30 segundos a 2 minutos)
   "Wir Sozialdemokraten / Christdemokraten / Grüne / Liberale glauben..."
   "Als Vertreter der ... Fraktion möchte ich..."

3. Hauptargumentation (5-10 minutos)
   - These → Belege → Konsequenzen
   - Citação de Primärquellen, dados, Forschungsstand
   - Konj. I em transmissão de oposição (cf. 02-02)
   - Stilfiguren retóricas

4. Gegnerpositionierung
   - "Die Opposition / Regierung argumentiert, dass... [Konj. I]..."
   - Refutação ponto-a-ponto

5. Apelo coletivo
   - Anapher 'Wir wollen ... Wir kämpfen für...'
   - Pathos calibrado

6. Schluss ritualizado
   "Vielen Dank für Ihre Aufmerksamkeit."
   "Ich danke Ihnen für die geschätzte Aufmerksamkeit."
```

### 2.2 Sprechakte parlamentares ritualizados

Cada Sprechakt em parlamento é **convencionalizado**:

| Sprechakt | Função | Realização típica |
|---|---|---|
| **Anrede** | Estabelecer face-respect institucional | "Frau Präsidentin..." (cf. 03-04) |
| **Selbstdarstellung** | Estabelecer Ethos | "Als Sozialdemokrat..." |
| **Gegnerangriff** | Deslegitimar oposição | "Die Opposition irrt, wenn sie behauptet [Konj. I]..." |
| **Programmverkündung** | Anunciar política | "Die Regierung wird... [Futur I + Modalverb]" |
| **Beschwörung** | Invocar valores comuns | "Im Namen der deutschen Demokratie..." |
| **Antrag** | Solicitar ação | "Ich beantrage hiermit, dass..." |
| **Erklärung** | Posicionar-se publicamente | "Ich erkläre hiermit..." |
| **Schluss** | Fechamento ritual | "Vielen Dank für Ihre Aufmerksamkeit." |

### 2.3 Aristotélica retórica — Logos, Ethos, Pathos

#### Logos (lógica argumentativa)

- **Premisas explícitas**.
- **Evidência empírica** (dados, Statistik, Belege).
- **Conclusões válidas**.
- **Konjunktionaladverbien** acadêmicos para encadeamento (cf. 02-09).

```
"Erstens, die wirtschaftliche Lage zeigt, dass... Zweitens, die Statistik weist 
darauf hin, dass... Folglich müssen wir..."
```

#### Ethos (caráter do orador)

- **Selbstpositionierung** (filiação partidária, biografia, expertise).
- **Credibilidade demonstrada** (citações, Forschungsstand).
- **Höflichkeitsformeln** (cf. 03-04).
- **Konj. I em Reportativ** sobre fontes (cf. 02-02).

```
"Als langjähriger Bildungspolitiker / als Wirtschaftsexperte / als Vertreter der..."
```

#### Pathos (apelo emocional)

- **Stilfiguren retóricas**: Anapher, Klimax, Metapher, Antithese.
- **Modalpartikeln estratégicas**: 'doch', 'eigentlich', 'gerade'.
- **Wir-Inklusiv**.
- **Apelo a valores compartilhados**.

```
"Wir wollen mehr Gerechtigkeit. Wir wollen mehr Demokratie. Wir wollen mehr Zukunft."
                        ↑ Anapher + Klimax + Pathos
```

#### Equilíbrio dos três

Discurso parlamentar de qualidade equilibra os três. Discurso populista superestima Pathos (e.g., Bildzeitung-Stil parlamentar). Discurso técnico superestima Logos (e.g., relatório de comissão).

### 2.4 Polarização semântica + Begriffspolitik

Cada partido elege **Begriffe definitorios** e os topicaliza sistematicamente.

#### Mapeamento partidário (esquema simplificado)

| Partido | Begriffe centrais |
|---|---|
| **CDU/CSU** | Heimat, Sicherheit, christliche Werte, Familie, Verantwortung, Mittelstand, Stabilität |
| **SPD** | Gerechtigkeit, Solidarität, Arbeit, Bildung, Mindestlohn, Sozialstaat, Chancengleichheit |
| **Grüne** | Klimaschutz, Nachhaltigkeit, Vielfalt, Menschenrechte, Energiewende, Bio, Ökologie |
| **FDP** | Freiheit, Eigenverantwortung, Marktwirtschaft, Innovation, Steuerentlastung |
| **AfD** | Heimat (sentido distinto), Volk, traditionelle Familie, Identität, Migration (negativo), Souveränität |
| **Linke** | Soziale Gerechtigkeit, Umverteilung, Frieden, Antikapitalismus, Solidarität |

#### Polarização lexical em par

Cada Begriff tem **par concorrente** em outro partido:

```
Heimat (CDU/AfD - positivo, tradicional)  ↔  Vielfalt (Grüne - inclusivo, plural)
Sicherheit (CDU - lei e ordem)            ↔  Freiheit (FDP - liberal)
Klimaschutz (Grüne - prioridade)          ↔  Wirtschaftswachstum (CDU/FDP - prioridade)
Migration (positivo: Grüne; negativo: AfD)
Sozialstaat (SPD/Linke - expandir)        ↔  Steuerentlastung (FDP - reduzir)
```

Análise KDA: identificar **lexical Auswahl** revela posicionamento ideológico (cf. 04-06).

#### Frame-Building

Cada Begriff ativa **frame conceitual** conforme tradição partidária:

```
'Heimat' frame CDU/CSU:    nação histórica, valores tradicionais, segurança cultural.
'Heimat' frame Grüne:       lar pessoal, comunidade local, ecologia regional.
'Heimat' frame AfD:         identidade etno-nacional excludente.

Mesmo Begriff, frames distintos. Análise = mapear frames + reconhecer agenda implícita.
```

### 2.5 Discurso ritualizado vs. Spontanrede

#### Ritualizado

Discursos preparados (Reden, Pressekonferenzen, formais Statements):
- Sintaxe hipotática controlada.
- Stilfiguren cuidadas.
- Konj. I em Reportativ.
- Modalpartikeln calibradas.
- Schluss ritual.

#### Spontanrede

Debates ao vivo, perguntas dos jornalistas, intervenções espontâneas:
- Sintaxe mais paratática.
- Modalpartikeln coloquiais frequentes ('halt', 'eben', 'doch').
- Ellipsen, Aposiopesen.
- Stilbruch ocasional.

Análise política = comparar ritualizado (preparado) com spontan (revelador). Spontanrede frequentemente mais autêntico, ideologicamente revelador.

### 2.6 Manipulationsstrategien — leitura crítica

#### Maximen-Verletzungen frequentes

(Cf. 03-04 §2.3 Grice).

```
Quantität-Verletzung:
   Político A: "Sind Sie für die Reform?"
   Político B: "Lassen Sie mich das ausführen..." (excesso → evasão)
   
Relation-Verletzung:
   A: "Was sagen Sie zur Korruption?"
   B: "Wir müssen über das Wachstum sprechen..." (tema-shift → evasão)
   
Qualität-Verletzung:
   "Diese Reform wird allen Bürgern dienen." (afirmação categórica sem evidência)
   
Modalität-Verletzung:
   "Wir setzen uns für eine bessere Zukunft ein..." (ambigüidade estratégica)
```

#### Detecção: análise pragmática sistemática

Cada Maxime-Verletzung gera **Implikatur** detectável. Análise crítica = cataloga Maximen-Verletzungen + interpretar agenda política.

### 2.7 Diagnóstico — pipeline de análise política

Para discurso parlamentar / Parteiprogramm:

1. **Identificar Sprechakte ritualizados**: Anrede, Selbstpositionierung, Schluss.
2. **Mapear Logos / Ethos / Pathos**.
3. **Identificar Begriffe-chave** + frames associados.
4. **Identificar Stilfiguren retóricas**.
5. **Detectar Maximen-Verletzungen** + Implikaturen ideológicas.
6. **Mapear polarização lexical** (Wir/Sie; in-group/out-group).
7. **Posicionamento ideológico** revelado.
8. **Crítica + auto-crítica** (KDA engajada vs. distância analítica).

## 4. Sprachliche Aufgabe

### Texto-âncora

**Bundestag Plenarprotokoll, Generaldebatte recente** (selecionar de https://www.bundestag.de/protokolle).

**Modelo composto** (representativo):

> *"Frau Präsidentin, sehr geehrte Damen und Herren! Wir Sozialdemokraten stehen heute vor einer Entscheidung von historischer Tragweite. Es geht um Gerechtigkeit. Es geht um Solidarität. Es geht um die Frage, ob wir uns als Gesellschaft die Würde aller Bürger gegenseitig garantieren. Die Opposition behauptet, eine solche Reform sei verfehlt. Mit Verlaub: Diese Behauptung ist nicht nur kurzsichtig — sie ist gefährlich. Wenn wir nicht jetzt handeln, wann dann? Wenn wir nicht eine gerechtere Wirtschaftsordnung gestalten, wer dann? Wir wollen, dass jeder Bürger eine reale Chance auf Bildung, auf Arbeit, auf Würde hat. Vielen Dank für Ihre Aufmerksamkeit."*

(Composto a partir de fragmentos canônicos da retórica parlamentar DE.)

### Tarefa

Análise escrita, **800-1100 palavras** em PT-BR.

1. **Estrutura canônica**: identificar Anrede, Selbstpositionierung, Argumentation, Gegnerpositionierung, Apelo, Schluss.
2. **Aristotélica tríade**: Logos (argumentos identificados), Ethos (Selbstpositionierung), Pathos (Stilfiguren).
3. **Stilfiguren**: Anapher ('Es geht um... / Wenn wir nicht... / Wir wollen, dass...'); Antithese ('kurzsichtig — sie ist gefährlich'); apelo emocional via repetição.
4. **Begriffspolitik**: Begriffe centrais (Gerechtigkeit, Solidarität, Würde, Reform). Como cada um se posiciona ideologicamente?
5. **Konj. I em Reportativ**: 'die Opposition behauptet, ... sei verfehlt' — análise pragmática (cf. 02-02 + 03-04).
6. **Maximen-Verletzung detectada**: 'Wenn wir nicht jetzt handeln, wann dann?' — falsa dicotomia? Implikatur?
7. **Wir-Inklusivo + Sie-Excluindente**: 'Wir Sozialdemokraten' vs. 'Die Opposition'. Polarização.
8. **Crítica retórica**: o discurso é predominantemente Logos? Ethos? Pathos? Equilíbrio?

Após terminar, peça o **Praktisches Tor**.
