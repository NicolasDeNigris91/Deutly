## Strategische Prinzipien

### 1. Inhalt > Form

Konzentration auf inhaltliche Tiefe + Quellenkritik. Keine Migration zu fancy Plattformen (LMS, App), die Form über Inhalt stellen.

### 2. Markdown + Git als Foundation

Markdown-Dateien in Git-Repos sind dauerhaft, remixable, lokal lesbar, transparent versioniert. Diese Wahl ist nicht-revidierbar.

### 3. CC BY-NC 4.0

Lizenz bleibt Creative Commons Attribution-NonCommercial 4.0. Framework darf adaptiert werden, **nicht kommerzialisiert**.

### 4. Quellenkritik

Jede Aussage in Anhängen + Modulen muss mit Akademie-Ausgabe / Standard-Wörterbuch / IDS-Grammis verankert sein. **Pseudo-Erudition** zugunsten populärer Verständlichkeit ist unerlaubt.

### 5. Lernerorientierung

Jede Erweiterung muss konkreten Lerner-Nutzen demonstrieren. Reine theoretische Verfeinerung ohne Lerner-Bezug wird nicht implementiert.

### 6. Mentor + Peer + Self-Mentor

Framework setzt auf 3-Modus-Praxis (cf. MENTOR.md §0). KI-Mentoring kann Modus C ergänzen, nicht ersetzen.

### 7. Long-term Sustainability

Framework wird über 5-10 Jahre kontinuierlich gepflegt. Cadência ~1-2 Releases pro Jahr nach v2.0; vor v2.0 möglicherweise schneller (wegen frühem Wachstum).

## Wer kann beitragen?

### Auf welche Weise

```
1. Issues melden:   Tippfehler, broken links, Quellen-Korrekturen,
                    Vorschläge.

2. PR submitten:    Korrekturen direkt; neue Module / Anhänge / Templates.

3. Fork:            eigene Adaption erstellen für andere L2 (z.B.
                    FATHOM-Französisch, FATHOM-Russisch).

4. Peer-Review:     Linguisten / Germanisten / Romanisten (für PT-DE-
                    Kontrastive) willkommen.

5. Mentoring:       Lerner können andere Lerner betreuen — Trilha D
                    (Stage 6) etabliert dies systematisch.

6. Forschung:       Studien zur Wirksamkeit der Methodologie willkommen
                    — gemäß CC BY-NC 4.0 Lizenz.
```

### Worum gebeten wird

```
- Akademisches Niveau in Beiträgen (Quellenkritik, präzise Belegung).
- CC BY-NC 4.0 Lizenz respektieren.
- CODE_OF_CONDUCT.md beachten.
- Geduld: Reviews dauern, Maintenance ist langsam.
```

## Was NICHT geplant ist

### Wontfix (cf. SPRINT-NEXT.md)

```
- Konversion zu LMS / proprietärem System (CC BY-NC 4.0 verbietet).
- Gamifizierung (Badges, Achievements) — pedagógico Anti-Pattern für
  Erwachsenen-DaF.
- AI-Tutor-Integration als Ersatz für menschliches Mentoring.
- Streaming-Plattform-Migration (YouTube, Twitch).
- Premium-Subscription-Modell (CC BY-NC ausgeschlossen).
```

### Open Questions

```
- Stage 6 Track-Erweiterung: weitere Tracks möglich (Theologie?
  Philosophie spezialisiert? Linguistik vs. Germanistik trennen?)
  Entscheidung in v2.0 geplant.

- Stage 7 (Beitragender-Stage): Konzept reifen lassen; Entscheidung
  in v3.0 geplant.

- Andere L2 als Forks oder als Abkömmlinge eines generalisierten
  FATHOM-Frameworks: Diskussion in Comunidade.
```
