# FATHOM-Deutsch

> A rigorous framework for German language acquisition from A1 structural to **C2+ World Class**. Same analytical discipline as Fathom (the parent Software Engineering framework), applied to *Sprache*.

## Who is this for

Adult learners who want to reach **C2+ World Class** in German by treating the language as a **logical system to deconstruct**, not a repertoire to memorize. The framework integrates:

- **Canonical primary sources** — Eisenberg, Helbig/Buscha, Engel, Duden, IDS-Grammis (grammatical canon).
- **Empirical corpora** — DWDS, COSMAS II for diachronic + synchronic concept analysis.
- **Philosophical-philological tradition** — Kant, Hegel, Heidegger, Habermas, Adorno, Mann, Bernhard, Walther von der Vogelweide as anchor texts.
- **Cognitive science of L2 acquisition** — Krashen, Swain, Bjork, Karpicke/Roediger, Ericsson on deliberate practice.

The output trajectory: from **first parsed sentence in Stage 1** to **published article in a German-language journal in Stage 5**.

## Structure

```
5 Stages × 44 modules + 5 Capstones (Erkenntnisprojekt v0→v4)
```

### The 5 Stages in one sentence each

1. **Stage 1, Fundamente** (Topological Field Model + Case System + Verb System + Nominal Flexion + Pronouns + Word Formation + Negation/Modal Particles + Phonetics + Basic Vocabulary) — A1→A2 structural.
2. **Stage 2, Struktur** (Subordination + Konjunktiv I/II + Passive Constructions + Infinitive Clauses + Functional Verb Constructions + Modal Verbs + Topic-Focus + Operational Lexis) — B1→B2 complex syntax.
3. **Stage 3, Stil** (Nominal vs. Verbal Style + Register + Idiomatik + Pragmatics + Modal Particles + Stylistic Figures + Academic Writing + Journalistic Style + Humanities Lexis) — B2→C1 stylistics.
4. **Stage 4, System** (Historical Linguistics + Etymology + Variation + Generative Syntax + Formal Semantics + Discourse Analysis + Text Linguistics + Corpus Linguistics + PT-DE Contrastive + Hermeneutics) — C1→C2 metalinguistics.
5. **Stage 5, Meisterschaft** (Political Language + Scientific Language + Translation Theory + Eigene Stimme + Public Output + Mentoring + Goethe C2 optional) — C2+ output and mentoring.

## The Capstones — Erkenntnisprojekt

A **single Begriff** (concept) chosen at the start of Stage 1 evolves through all 5 Capstones in increasing depth:

| Capstone | Stage | Output | Volume |
|---|---|---|---|
| **CAPSTONE-1** | 1 — Fundamente | *Glossar v0* — phonetic-structural lexicon | 30 entries |
| **CAPSTONE-2** | 2 — Struktur | *Aufsatz v1* — argumentative essay | ~1500 W |
| **CAPSTONE-3** | 3 — Stil | *Aufsatz v2* — academic essay with primary sources | ~5000 W |
| **CAPSTONE-4** | 4 — System | *Begriffsanalyse v3* — corpus-based concept analysis | ~30 pp. |
| **CAPSTONE-5** | 5 — Meisterschaft | *Veröffentlichung v4* — publication in a DE/AT/CH journal | published |

The Begriff (e.g., *Aufklärung*, *Bildung*, *Geist*, *Wahrheit*, *Macht*, *Sein*, *Sprache*) is the **single sustained object** through years of work — modeled on the Begriffsgeschichte tradition (Brunner/Conze/Koselleck).

## Method — The 6-Section Module

Each module has 6 sections:

1. **Sprachliches Problem** — why the module exists; what fluency gap it covers.
2. **Harte Theorie** — dense, with primary references; no padding.
3. **Schwelle der Meisterschaft** — what you must explain **without consulting**.
4. **Sprachliche Aufgabe** — non-trivial production/analysis on authentic text.
5. **Erweiterungen und Verbindungen** — connections to other modules.
6. **Quellen** — grammars, papers, corpora, canonical authors.

After Theorie + Aufgabe, you request the **Tor** (gate):

- **Konzeptuelles Tor** — 5–8 randomized questions requiring syntax trees, counterexamples, internal mechanism explanations.
- **Praktisches Tor** — mentor applies full **Refinement Loop** (Grammar → Lexis → Style → erudite native ear) on German output, with 5 justification questions.
- **Verbindungstor** — connections to 2–3 prior modules.

All 3 gates must pass for module completion. Failing is part of the process.

---

## The Refinement Loop (4 layers)

Every German output passes through **explicit chain-of-thought** in 4 layers (detail in [MENTOR.md](MENTOR.md) §1):

1. **Grammatik** — morpho-syntactic error with rule reference (Eisenberg §X).
2. **Lexikalische Präzision** — more exact synonyms, collocational fit (DWDS).
3. **Stil** — adequate register, nominal vs. verbal balance, no Stilbruch.
4. **Native erudite ear** — final version "as Habermas would have written it."

Without this loop, L2 study stagnates at "fluent tourist" and never reaches C2+.

## Non-negotiable principles

1. **System before use.** You don't use before understanding the grammatical system that governs the use.
2. **No leniency.** Wrong sentences get corrected with chain-of-thought (grammar + lexis + style + nuance), not with "good enough."
3. **Primary sources.** Eisenberg, Duden Grammatik, Helbig/Buscha, IDS-Grammis (online), DWDS, COSMAS II. No "Learn German Fast" blogs.
4. **Texts before exercises.** Each module's entry point is an authentic high-complexity text (Kant, Hegel, Habermas, Adorno, Sloterdijk, Bundestag, FAZ-Feuilleton). Exercises are instruments; texts are territory.
5. **Regular German output.** From module 01-02 onward, all student output passes through the Refinement Loop.
6. **Nominal vs. verbal style.** You know when to use each, and why.
7. **Chained Capstone.** The Erkenntnisprojekt evolves through all stages.

## Time investment

Don't ask how long it takes to reach C2+. It takes what it needs.

Rough order of magnitude (depends on hours/week, prior background, native speaker contact):

| Stage | Typical range (hours) |
|---|---|
| 1 — Fundamente (9 modules + Capstone) | 250–500 |
| 2 — Struktur (9 modules + Capstone) | 400–800 |
| 3 — Stil (9 modules + Capstone) | 400–900 |
| 4 — System (10 modules + Capstone) | 500–1200 |
| 5 — Meisterschaft (7 modules + Capstone) | 600–1500 |

**Total: ~2,000–5,000 hours of guided immersion.** Cutting corners here is cutting mastery. There's no shortcut.
